# Failures and Boundaries

- Native Zag compilation/execution is blocked by missing official `znc` binary in the active sandbox. This is BLOCKED_ENV, not PASS or FAIL.
- Prior R27-completion 0% changed-view identity test was structurally invalid because targets were unseen identities.
- Static relational core candidate solves viewpoint permutation in reference tests but not occlusion.
- Temporal persistence improves occlusion but can become too sticky and miss true identity switches.
- Multi-view set and contextual hybrid attempts traded off occlusion versus switching; hybrid was rolled back.
- Learned memory policy rationally becomes EXACT_ALL when storage is cheap; selectivity only emerges under real resource pressure.
- Two local-credit PAM Foundry learners underperformed random generation; whole-graph evolution replaced them.
- No-VAD speech is near-perfect on nominal synthetic motifs but falls to ~71% under harder duration/noise/blending.
- Adaptive Master teaching helps early but should withdraw/diversify later.
- Sibling interactive transfer reached ~98% in reference testing, not 100%.
- No unrestricted camera vision, natural human continuous speech, teenager/adult English, AHI, human superiority, open-ended RSI, or production TNN claim is established.
