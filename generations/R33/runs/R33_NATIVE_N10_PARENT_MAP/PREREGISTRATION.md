# R33-N10 — native inert accepted-parent map and exact reconstruction

Identity `r33-native-n10-inert-parent-map-v1`. One sole primary; nine supervised
native children. This is a new non-training engineering artifact-mapping lane,
not a rerun of the historical R27 verifier, N02A or the previous Python inventory.
The known parent inventory is explicitly reused as an engineering comparison.
No original class/module/reducer is imported, resolved, instantiated or called.

## Motivation and exact allowed changes

The accepted parent bytes are available, but original behavior and semantic
digest implementation remain missing. A native flat descriptor map can preserve
the actual serialized literals, memo identities, ordered container/BUILD
instructions, external references and all original bytes without requiring the
missing legacy runtime. This advances inspectable byte/structure custody only.
It cannot recover an absent method implementation or qualify native learning.

New authored sources: inert.zag, mapio.zag and driver.zag. Frozen IO_V1, SHA256_V2
and PROCESS_V3 imports unchanged. Ordinary shell/compiler/hash/copy operations
are operational only. No Python interpreter, Python package import, hidden
subprocess, alternative-language evaluator or replacement learner is used.
Installed CPython source is read/copied as inert reference text, never executed.

Forbidden: edits to the original accepted parent or any historical primary,
semantic-digest substitution, invoking a pickle reducer/class/global/persistent
loader, reconstructing a newborn, changing learned fields or implicit nulls,
activating historical graph/BPE/VAD capabilities, or claiming behavioral parity.
Flat relation/memo tables describe serialization references; they are not a
graph cognitive substrate or an activated legacy graph model.

## Input, format and data-structure contract

Exact source: Research/R33_PARENT_RECOVERED_V1/parent-r27-accepted-state.pkl,

This is the raw file identity, NOT historical semantic digest562aaa...73b04.
The source opens read-only and is hashed natively before and after scanning.

The scanner accepts a bounded binary subset of protocols2..5: frames, primitive
binary integers/booleans/None/floats, literal Unicode/bytes/bytearray payloads,
list/tuple/dict/set/frozenset construction, ordered container modifications,
memo puts/gets, GLOBAL/STACK_GLOBAL, NEWOBJ/NEWOBJ_EX/REDUCE/BUILD, extensions and
binary persistent/out-of-band buffer descriptors. It refuses unsupported legacy
text opcodes, wrong protocol, invalid frame/length/stack, undefined or redefined
memo entries and exhausted configured capacity. A failed scan has no usable root.
This is deliberately narrower than every possible pickle accepted by Python.

Every reference-bearing instruction becomes an inert descriptor. Literal raw
spans preserve encoded bytes, including floating sign/payload bits and arbitrarily
long encoded integers. Integers larger than signed64 refuse convenience numeric
conversion, preserving their original bytes rather than truncating. Encoded UTF8
bytes are retained, not normalized, interpreted as learner tokens or advertised
as a complete Unicode validator. Memo gets point to the same native descriptor;
self-references do not recursively expand. Implicit Python interning/singletons
and arbitrary reducer/container methods are not emulated. Ordered dict updates
remain recorded operations; general Python key-equality semantics are not invented.

Node table:10 signed32 wire words, with kind, source opcode offset, raw span,
three reference/value fields and first/last/count of operation relations. Native
integer storage is8 bytes, wire words4. Relation table:4 words for operands,
next relation and operation. Separate memo, unique-global and opcode-count tables.
Callbacks are never invoked. External descriptors remain explicit unresolved
references, not fabricated buffer contents or runtime dependencies.

Maxima:16MiB input,524288 descriptors,1048576 operation relations,262144 memo
slots,131072 stack/mark entries,1024 unique globals,4194304 opcode occurrences.
The complete native bundle includes all tables AND every original source byte,
split into pages of at most240064bytes. Each64-byte page header binds kind,
ordinal, contiguous row offset/count, word width and source SHA. A final manifest
binds counts/identity and SHA256 of every page, at most256 entries. It is written
only after all pages succeed; no cleanup erases failed partial artifacts.

Fresh reload verifies the exact separately retained manifest hash, all page
hashes/headers/order/coverage and reconstructed whole-source SHA, then descriptor
invariants. It reparses those reconstructed bytes in a fresh native model and
compares every node/relation/memo/global/opcode table word, plus all original
bytes. A changed page or wrong manifest identity exposes no usable mapped root.
These are artifact checksums, not signatures or human authority.

## Sole prospective schedule and exact criteria

1. Invalid mode: exit2, no output.
2. Scalar controls: None, booleans, unsigned8/16 and signed32 boundary values,
   signed/empty long, protocol2/4 controls, valid frame, negative-zero IEEE bytes,
   >64bit integer preservation, opcode-shaped opaque byte payload, bytearray and
   retained UTF8 bytes. No normalization/truncation/embedded-code interpretation.
3. Structural controls: cyclic self-list, shared tuple references, sparse memo,
   stored dict/null fields, deliberately nonexistent global/class/reducer,
   NEWOBJ and BUILD descriptors, list/set/frozenset operations, unresolved
   NEXT_BUFFER/READONLY_BUFFER, persistent ID and extension descriptors. The
   nonexistent module is never imported; missing fields are not initialized.
4. Refusals: unsupported protocol/text opcode, missing STOP/trailing bytes, empty
   stack, undefined/duplicate memo, odd dictionary pairs, wrong container/BUILD,
   malformed or oversized byte lengths, short/nested/straddled frames, and
   descriptor/relation/memo/stack capacity. Exact source-pinned negative codes
   required, root0 after every refusal.
5. Synthetic native-map roundtrip: all table words and original bytes exact;
   changed manifest identity refuses. This is an authored small artifact.
6. Real accepted-parent map: verify exact input SHA; parse without execution;
   match inherited known inventory protocol5,175954 memo entries,585 NEWOBJ
   descriptors,64 unique globals and14 root BUILD-field entries. Root symbol
   r27_experiments.R27State, encoded development_step60423/newborn_restarts0,
   formatTNN_PRE_V1_R27_GENERAL_LEARNING and explicit null affordance_model/
   speech_motif_decoder must remain exact. These are known metadata controls,
   not fresh scientific findings or the historical33-check behavioral verifier.
   Record all global symbols/root-field descriptor references and opcode counts,
   rehash unchanged source, and emit self-contained native map plus manifest pin.
7. Fresh map reload: verify/reconstruct all pages and original bytes, repeat the
   known identity fields, independently reparse reconstructed bytes, and compare
   every emitted table word. No legacy execution or historical primary rerun.
8–9. Separate synthetic map corruption writer/replay: retain complete node-page
   preimage, corrupt one byte under this new fixture root, then fresh reload must
   refuse-8813 with root0 and no exposed raw output. Original parent untouched.

Any unexpected assertion, signal, nonempty stderr, missing counter/terminal,
incomplete capture or limit violation fails this primary and stops later modes.
No post-exposure oracle edits or same-primary retries. Preserve exact failures.
Expected original field counts are inherited comparisons; all newly discovered
node/relation/opcode counts and resource/table-comparison totals are measured,
not guessed. Long/unprintable names are explicitly shown as RAW_SPAN_NODE IDs;
their complete bytes remain addressable in the bundle, never silently truncated.
