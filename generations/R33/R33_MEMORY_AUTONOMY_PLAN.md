# R33 memory autonomy

Status: prospective M1 qualification; prototype protected-LRU fallback and
historical codebook/payload integrity must be resolved first.

The learner may choose exact/compressed/both representation, hot/working/cold
tier, retrieval, rehearsal, candidate chunk revision and permitted eviction.
The architecture supplies generic storage and protected constraints; LRU is a
subordinate control/mechanic, not the learner's representation policy.

## Continuing-life battery

One branch learns competencies whose relevance returns after distractors,
contradictory evidence, context changes and memory pressure. Future relevance
is hidden from the learner. Compare learned policy with keep-all where feasible,
FIFO, LRU, fixed compression, random selection and fixed rehearsal under equal
resource envelopes. Report infeasible keep-all arms instead of granting them
unlimited memory in a matched-budget claim.

Cross pressure levels with delays and changing abstraction usefulness. Preserve
near-twin raw details that later become important; test reinterpreting earlier
events under a revised hypothesis. Freeze the original raw record or a proven
lossless encoding and retain the codebook version used to encode it. A mutable
chunk dictionary must not retroactively change remembered experience.

## Measurements

Useful retrieval per query/byte/operation; exact reconstruction; false matches;
lost/rescued prior successes; delayed retention; interference; regret from
eviction; archive/reload cost; policy updates and their supporting events;
memory-specific and whole-brain resource cost. Count auxiliary indices,
provenance and rollback copies, not only content bytes.

Candidate policies learn from ordinary delayed consequences, never evaluator
future-relevance labels. Replay selection based on a held-out failure list is
evaluation leakage, not learner-owned memory.

## Safety and falsification

M1 requires refuse/spill behavior when all candidates are protected, capacity
and reconstruction checks before mutation, reversible edits, versioned ancestry,
and fresh-process continuation. Silent truncation or protected-data eviction
fails the gate. A lower memory footprint accompanied by worse retention,
robustness or traceability is not an efficiency win.

The claim is bounded memory-policy competence. It does not establish natural
autobiography, complete lifetime retention or consciousness.
