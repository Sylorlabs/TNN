# R32 → R27 Dominance Program

Date: 2026-08-29
Status: ACTIVE RESEARCH PROGRAM
Canonical remains: R27 step 60,423

## Objective

R32 does not replace R27 because it has more mechanisms or a better average score. Promotion requires **Pareto-style capability dominance**: preserve the accepted R27 substrate and regression battery, add general capabilities R27 lacks, and demonstrate that the improvements survive fresh native qualification without evaluator leakage, newborn restart, or researcher-written domain policy.

The optimization target is not “make R32 look good.” It is to make the continuing TNN learner increasingly responsible for representation, architecture, memory, inquiry, and adaptation while protected infrastructure supplies only generic primitives, resource/accounting boundaries, provenance, rollback, and an external verifier.

## Hardcoding boundary

### Protected / human-supplied substrate allowed

Humans may supply generic equivalents of biological/machine substrate:

- raw sensory I/O and action ports;
- arithmetic, storage, timing/order and resource accounting;
- integrity/provenance/rollback primitives;
- generic plastic state cells, local transforms, recurrence, gates and routing primitives;
- a generic Foundry execution/search substrate;
- external teacher interfaces;
- evaluator-only truth and delayed outcome scoring;
- safety/resource ceilings;
- the root verifier.

### Learner-owned decisions required

TNN should increasingly decide:

- what reusable chunks/constructions to recruit;
- what evidence is independent or redundant;
- what hypotheses to retain;
- when additional observation is worth its cost;
- what memory to preserve/compress/archive/retrieve;
- what non-core PAM topology to create, specialize, combine or delete;
- what contexts/regimes require distinct models;
- what questions to ask teachers/siblings;
- when a learned mechanism should be rolled back after regret.

### Disallowed shortcuts

- evaluator mode/truth/ambiguity labels or hidden membership as learner features;
- hard-coded answer tables, task/category detectors, mode-specific routes;
- positive UNKNOWN reward solely to make ambiguity metrics rise;
- fixed confidence cutoffs or fixed observation counts tuned on validation;
- human-written word/phoneme/VAD/chunk boundaries as cognition;
- newborn restart used to hide interference;
- promoting Python/reference behavior as native TNN capability;
- researcher selecting a candidate architecture after looking at sealed validation.

Every experiment should keep a hardcoding ledger separating protected substrate, researcher experimental control, TNN-selected structure, teacher information and evaluator-only information.

## Experimental sequence

### Phase 1 — Epistemic action-value geometry

Already executed in this agent run:

- **E51A:** historical sequential controller diagnostic. Removing continuation-training gating and hand-authored continuation wrapping did not repair terminal safety. Valid native negative.
- **E51B:** frozen safer E50 batch terminal controller + learned delayed-utility CONTINUE action. It reduced no-unique wrong commits in both models but lost known success and net utility. Valid native negative with causal leverage.

Next:

- **E51C learner-owned continuation Foundry.** Give the learner only generic sparse composition primitives. On development delayed utility/regret, TNN selects whether to add nonlinear feature interactions/topology to the continuation head and freezes them before fresh validation. Compare terminal-only, E51B linear continuation and Foundry continuation. No validation-driven architecture selection.
- If sparse compositions fail, expand the Foundry grammar one generic primitive class at a time (piecewise gate, recurrence, small state cell) under matched compute. Do not hand-engineer an “ambiguity feature.”

Exit criterion: continuation improves no-unique safety and net delayed utility without known-resolution regression; then execute sealed confirmation.

### Phase 2 — Native dual-route perception

Fresh native factorial battery:

1. raw high-fidelity route only;
2. endogenous chunk route only;
3. raw + chunk route;
4. raw + chunk + learner-owned arbitration.

Run acoustic and visual/temporal variants under matched experience, corruption and compute. Chunks may compress/index/reuse but cannot erase raw evidence. Replicate across fresh seeds; carry exact regressions forward.

Exit criterion: dual route is natively non-inferior to raw hard grounding, strictly better on at least one transfer/near-twin/resource dimension, and preserves compression gain.

### Phase 3 — Memory autonomy under delayed relevance

Give one continuing learner finite memory and experiences whose future relevance is not predictable from task labels. Compare learner policy against keep-all (when feasible), FIFO, LRU, fixed compression and fixed phase schedules.

TNN chooses exact/compressed/both, hot/cold/archive, retrieval/rehearsal and eviction based on learned delayed utility/regret.

Exit criterion: higher long-horizon retained capability per resource with no evaluator-visible relevance labels.

### Phase 4 — Persistent entity and changing-world state

One brain encounters identity, occlusion, disappearance/reappearance, real replacement, reversals, context shifts and recurring regimes. Require multiple unresolved hypotheses rather than forced merge/overwrite.

Exit criterion: beat R27 retained identity/state baselines across changed view, occlusion, true switch, return-to-old-regime and long-delay tests.

### Phase 5 — Active causal intervention

Worlds contain hypotheses indistinguishable passively but distinguishable through actions. TNN must learn which intervention has expected information/utility value and when not to spend it.

Controls: passive only, always-inspect, random inspect, fixed budget, learner-owned action value.

Exit criterion: better correctness/regret per intervention cost on fresh causal worlds, including misleading and genuinely underdetermined cases.

### Phase 6 — Natural continuous multimodal grounding

Move beyond synthetic/eSpeak-only evidence. Keep high-fidelity temporal audio/video primary; endogenous constructions are side channels. Test held-out speakers, rates, backgrounds, coarticulation, occlusion, novel objects and cross-modal grounding.

Exit criterion: robust transfer on natural media without supplied word/phoneme/VAD/object-boundary cognition.

### Phase 7 — Master withdrawal and independent siblings

Use independent mutable brains. Sources carry lineage. Test correct teaching, stale information, disagreement, correlated repetition, deliberate false testimony, discriminating questions and teach-back.

The Master adapts curriculum but is removed before qualification.

Exit criterion: receiver competence remains after withdrawal; repeated dependent claims do not masquerade as independent evidence.

### Phase 8 — Autonomous non-core PAM Foundry

Give TNN generic executable primitives and a protected shadow environment. TNN must use its own failure/regret ledger to:

1. diagnose a plateau/failure cluster;
2. allocate architecture-search budget;
3. generate candidate structures;
4. train them;
5. shadow-test them on development experience;
6. promote or reject them before sealed validation;
7. preserve causal ancestry and rollback;
8. later reuse lessons from prior architecture attempts.

Exit criterion: repeated new capability gains in distinct domains without a researcher translating each failure into a named architecture.

### Phase 9 — Cross-domain transfer in the same brain

Sequentially introduce unrelated domains. Measure learning curves versus from-scratch controls and versus ablations with prior abstractions unavailable.

Exit criterion: prior learned machinery accelerates genuinely novel domains without catastrophic regression.

### Phase 10 — Long integrated native life

Only after components stabilize, continue one native Zag brain through >=250k events if curves justify. Include recurring regimes, resource pressure, teacher withdrawal, sibling disagreement, natural media, active interventions, Foundry revisions, long delays and save → new process → reload → continued learning.

No newborn restart.

### Phase 11 — R27 vs R32 final dominance battery

Freeze R27 and the candidate R32 before final seeds are exposed. Run:

- every retained R27 verifier/regression;
- the new R32 capability families above;
- matched-resource comparisons;
- adversarial combinations of previously separate dimensions;
- post-win challenge seeds after any nominal perfect score;
- independent clean-room build/extraction/reproduction.

Promotion requires R32 to meet every inherited floor and the preregistered strict-gain requirements. Otherwise R27 remains canonical and the exact regression is localized by ablation.

## Agent operating rule

For each failure:

`training dose → teaching/curriculum → memory → routing → representation → learner-owned non-core Foundry → protected-core change only if evidence proves a core information bottleneck`

Do not jump directly to a larger architecture because a benchmark moved. Negative results narrow the causal frontier and remain preserved.
