# Communication as coordinated action - microprobe prereg

Date2026-10-06. Private fast/method-identifiability. New exploratory fixture,
not canonical TNN or human language demonstration. Write before code.
QUESTION: can token meanings learned from interaction execute unseen ordered messages,
and is the improvement actually supplied by source composition rather than learned syntax?
H-transfer: retained meaning map supports unseen combinations; H-router: generic
source executor supplies all composition/order competence, not learned conventions.

WORLD
Three opaque tokens map by observed one-token effects to add1, add2, multiply2;
six bijections of token IDs0..2 to these operation identities. Training initial
states0 and1 for each single token (6 observations), no two-token observations.
Listener infers each meaning by matching the finite primitive menu against both
effects. Message semantics fixed by world: execute tokens left-to-right. Test all9
ordered pairs on states3..5 =27 effect goals per permutation,162 total.
Independent hand arithmetic law for each pair; learner receives only observed
single-token initial/final values, not permutation/world label.

FORKS
1. Learned dictionary + source serial composition executes all heldout pairs.
2. Phrase cache over observed whole messages only: cannot execute any unseen pair.
3. Dictionary erased: abstain. Wrong cyclic dictionary token meaning shuffle: errors.
4. Flat learned token->operation table + generic interpreter: expected identical to
   dictionary learner; do not claim graph/program structure necessary.
5. Reversed source interpreter using same acquired meanings: predicted pair effects
   differ for noncommuting operations. Five commuting ordered pairs (self pairs and
   add1/add2 pairs) x3 states=15 correct per permutation. The four ordered add/mul
   pairs x3 states fail all states3..5; correct15/27.
6. Alternative world convention right-to-left, identical single-token training:
   left-to-right executor cannot know convention. Correct15/27 per permutation;
   disagreement for remaining12. Learner should express ambiguity before paired
   evidence if claiming learned convention. This probe reports baseline failure,
   not implements a syntax learner. Any success labeled known source convention.

BARS
Dictionary source-LTR and flat rival162/162; cache and erase0/162 abstentions;
wrong dictionary <162; reversed interpreter90/162; alternate-convention world
same90/162 using supplied LTR executor. Zero train/test whole-message overlap.
All6 ID bijections identical aggregate, no world ID to learner. Report known
semantics versus learned meanings separately. Human concepts/semantic modes not added.

RUN
Standalone pure-Zag driver using existing allocation/output helper prefix.
Artifacts PREREG.md, driver.zag, protocol.zag, run.sh, REPORT.md, environment.txt,
provenance.txt, compile1..3.txt, run1..3.txt. Fresh build gates each execution,
nonempty output, repeated raw hashes; exit1 on measured discrepancy. No numeric
scientific computation outside Zag. Generated binary ignored.
WHAT IT KILLS
Necessity of phrase memorization for this tiny protocol; claim that learned token
meanings alone establish experience-owned syntax or human-like language understanding.
WHAT IT DOES NOT KILL
Language learning broadly; compositional representations; predicting as one useful tool.
