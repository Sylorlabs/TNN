# PREREG: LIFETIME-METALEARN-3 (LM3)
## Cross-family lifetime learning: retention, interference control, transfer, meta-learning

**Status:** PREREGISTERED (frozen kill bars below). No implementation exists yet.
**Lane:** `docs/lab/research-lead/overnight-20260928/lifetime_metalearn/`
**Date:** 2026-10-03. Non-ledger task (claim minting paused).

## 1. Research question

Can a single continuing learner, with one domain-blind mechanism and no
task labels, no process reset, and no recompilation, (a) retain earlier
tasks after learning conflicting later tasks, (b) control negative
transfer (interference), (c) show positive transfer on repeated
structure, and (d) learn faster (fewer errors) with experience?

Prior work (lifetime_meta, lifetime_meta2) demonstrated meta-learning
(examples-to-criterion decrease) WITHIN one task family (biased-coin
bias). LM3 extends to ACROSS-FAMILY lifetime learning with retention
and interference control, which no prior lane has tested.

## 2. Experimental design

### 2.1 World (hidden from learner)

17 episodes, one frozen binary, one sequential run per condition. Every
trial: learner receives query bytes (q0,q1), emits answer byte, world
returns correctness. The learner NEVER receives an episode index, family
label, or task name. Episodes are numbered E01..E17 (opaque).

Families (researcher-known, learner-opaque):
- F-A "map": 16 queries (q0 in 0..15, q1=0) -> answer from frozen
  skewed multiset permutation. Instances m1..m4 with DIFFERENT
  permutations and DIFFERENT skews (m1: 0-heavy, m2: 1-heavy,
  m3/m4: mixed). m2 CONFLICTS with m1 (same queries, 13/16 answers
  differ). m3, m4 are novel instances.
- F-B "cycle": query = current symbol (q0 in 0..3, q1=0) -> next
  symbol in frozen cycle. c1 and c2 are DIFFERENT cycles (all 4
  answers differ): c2 CONFLICTS with c1.
- F-C "parity": (q0,q1) in 0..5^2 -> (q0+q1)%2. Query sampling
  skewed P(even)=0.7. One fixed rule (no instances).
- F-D "compare": (q0,q1) in 0..5^2 -> 1 if q0>q1 else 0. Uniform
  queries. One fixed rule.
- F-E "sum3": (q0,q1) in 0..5^2 -> (q0+q1)%3. Uniform queries.
  Novel family appearing late (E12).

Episode schedule (kind: C=criterion K=8 consecutive, max 200 trials,
min 64 trials; F=fixed 160 trials; P=probe, no state updates):
- E01 F-A m1 (C) | E02 F-B c1 (C) | E03 F-C parity (F) | E04 F-A m2 (C,
  CONFLICT) | E05 PROBE m1 (P, 24 trials) | E06 F-D compare (F) |
  E07 F-B c2 (C, CONFLICT) | E08 PROBE c1 (P, 16) | E09 F-A m3 (C) |
  E10 F-C parity REPEAT (C) | E11 F-D compare REPEAT (C) |
  E12 F-E sum3 (F, NOVEL) | E13 PROBE m1 (P, 24) | E14 PROBE c1 (P, 16) |
  E15 PROBE parity (P, 36) | E16 PROBE compare (P, 36) | E17 F-A m4 (C)

Query streams: pre-generated by LCG (seed 20261007), IDENTICAL across
conditions (paired comparison). Hidden permutations via Fisher-Yates
with world PRNG; conflict strengths asserted (m1/m2 differ on 13/16).

### 2.2 Learner (one mechanism, all episodes, all conditions)

Associative slots: (key=(q0,q1), value, strength, regime-id). Global
answer base-rate prior (8 bins, Laplace init 1). Learner-owned
deterministic guess PRNG (seed 777) for prior ties.

Per episode:
- Orientation (6 trials): guess via global prior; build no slots.
- Regime selection (slot-evidence ONLY): for each existing regime,
  count slot hits and correct hits on the 6 orientation queries.
  A regime qualifies if hits>=3 AND correct>=0.8*hits. Select the
  qualifying regime with max correct (tie: lowest index). If none
  qualifies, allocate a new regime. (No fingerprint, no labels;
  decision uses only observed (query, answer) pairs.)
- Trials: exact key match in active regime -> stored value; else
  prior argmax guess.
- Observe (learning episodes): prior counts the revealed answer.
  If correct and slot exists: strength++. If correct and NO slot:
  CREATE slot (first-encounter storage; ensures complete coverage
  for retention). If wrong and slot exists in active regime:
  SPLIT (allocate new regime, corrected slot there; old slot
  untouched). If wrong and no slot: create slot (evict global
  weakest-oldest if 224 slots full).

Conditions (experimental, not learner cognition):
- T (treatment): continuing learner, regimes enabled, never reset.
- R (reset): identical mechanism, state wiped between episodes.
- S (shared/ablation): continuing, but regime machinery disabled
  (single store, overwrite on contradiction). Expected to show
  catastrophic interference.

### 2.3 Metrics

- etc: trials to 8 consecutive correct (criterion episodes).
- errors: wrong guesses in fixed episodes (160 trials).
- acc: probe accuracy in hundredths (no state updates).
- splits, evictions, caphits (etc>max), genfail (sanity).

## 6. Domain-blindness statement

The learner's regime selection uses only the predictive accuracy of
stored (query->answer) slots on observed orientation trials. It
contains no family names, no task labels, no domain classifier, no
router, no mode. Renaming the families (or permuting their episode
positions) changes nothing in the learner's code path: selection
depends only on observed statistics. The conflict response (split)
is triggered by prediction error, not by identity. This satisfies:
"Would the same frozen architecture still know how to learn/use
this if humans had never named the domain or capability?" Yes:
there is nothing in the mechanism that names one.

## 7. Honest boundaries (pre-registered)

- The substrate is associative (L1-ish): slots + base-rate prior.
  Claims are about LIFETIME DYNAMICS (retention, transfer,
  interference), not representational invention (not L3).
- The prior, estimator, regime machinery, and update rules are
  researcher-supplied; the learned quantities are slot contents,
  regime partitions, and base rates.
- One frozen seed; generalization to other task orders/seeds
  untested (follow-up work).
- Probes use no state updates (pure retention read).
- The split backstop did not fire in the pilot (clean separation);
  it remains as a safety mechanism, not a demonstrated path.
