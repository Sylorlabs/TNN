# PREREG: OpScope Step 5 Baseline Comparison (frozen before implementation)

## Purpose

Pipeline step 5 for OpScope. Compare the learner's sealed-evaluation
pattern (S1 14/14 NEG, S2 7/7 controls, from `7ca508cd0`) against simple
non-learning baselines that use only the frozen training data
(episodes 0-99). If a simple baseline reproduces the learner's pattern,
the sealed result is explainable without a discovered operation.

## Training data (frozen)

Episodes 0-99 generated by the frozen world
`opscope_rebuild/opscope_world.zag` (commit `837c02c59`), seed
123456789, via `gen_episodes`. Each training episode provides a
word-id sequence U (from `world_recover_U`) and a target mask T
(from `world_T`). The baseline implementation extracts these pairs
verbatim using the frozen world code. No training episode is modified.

## Baselines (frozen definitions)

### B-MEM (exact memorization)

For each sealed episode with word-id sequence Us, search training
episodes 0-99 for an episode with identical word-id sequence Ut == Us
(same length, same ids in order). If found, output its target T.
If not found, output -1 (abstain; scored as wrong).

Rationale: tests whether sealed items are solved by verbatim recall.

### B-NN (nearest neighbor, word-set overlap)

For each sealed episode with word set S (set of word ids in Us),
compute overlap_i = |S intersect T_i| for each training episode i
with word set T_i (set of word ids in Ut). Select the training
episode with maximum overlap_i. Tie-break: lowest episode id.
Output its target T.

Rationale: tests whether sealed items are solved by copying the
most similar training episode. This is the strongest simple
baseline; training contains "tak not grn" (overlap 2 with
"tak not X") and "tak ..." affirmatives.

### B-CONST (constant {tak})

Always output T=1, regardless of input.

Rationale: tests whether the NEG pattern is trivially solved by a
constant predictor; controls discriminate.

## Scoring (frozen)

For each baseline, run all 21 sealed items. A prediction is correct
iff pred == T. Compute:
- S1 = correct / 14 on NEG ids 200-213
- S2 = correct / 7 on control ids 214-220

Per-item (pred, tgt, ok) logged for all 21 items per baseline.

## Verdict rule (frozen)

- OPSCOPE-BASELINE-PASS iff NO baseline achieves (S1 >= 12 AND
  S2 == 7). The learner's sealed pattern is not reproduced by
  memorization, nearest-neighbor copying, or constant prediction.
- OPSCOPE-BASELINE-FAIL iff at least one baseline achieves
  (S1 >= 12 AND S2 == 7). The sealed result is explainable by a
  simple non-learning rule; the discovered-operation claim is
  weakened.

The bars (12/14, 7/7) match the sealed-evaluation pass bars.

## Honest scope

This is pipeline step 5 of 11. It tests only whether three specific
simple baselines reproduce the sealed pattern. It does not test all
possible simple rules. A PASS means the pattern survives these three
attacks; it does not prove the learner discovered the operation, and
it claims no L3 and no SURVIVES. Steps 6-11 remain open.

## Implementation plan (not yet built)

1. Include frozen world code verbatim (for `gen_episodes`,

2. Generate training episodes 0-99; store (U, T) pairs.
3. Hardcode the 21 sealed (U, T) pairs above.
4. Implement B-MEM, B-NN, B-CONST per frozen definitions.
5. Score S1/S2 per baseline; emit per-item results and verdict.
6. Build with repo znc; run 3x; verify byte-identical.
