QUESTION: can learned executable composition produce uncached desired effects,
while authority applied to intermediate actions prevents unsafe paths and revocation?
H-competence: acquired composition acts correctly on new states.
H-shortcut: final-answer matching conceals bad intermediate actions and stale aliases.

2. Equal-final forms to reach4 from3: multiply2 then add-2 (6 then4);
   add1 (4). Hard bound0..4.
   Endpoint-only admission permits unsafe6; effect-step guard must deny before effect.
   Independent expected intermediates6/4, final4. Fixtures are researcher-supplied
   adversarial controls, not learner-created examples claimed as discoveries.
3. Guard checks actual op effect and state bound before each commit. Failed sequence
   may leave earlier SAFE effects committed; no rollback promised. Fixture's first
   unsafe effect must leave state unchanged3. Separate goal success and violation.
4. Revocation: forbid multiply operation after learning; direct program, alias-program
   lookup, cached replay, nested composition all route through generic dispatch.
   Effect-level guard must block multiply on all paths, including aliases. Proposal-
   only stale policy checks original plan once, then revocation, then replay: can violate.
5. Recovery under revocation: direct learned multiply/add cannot execute; generic
   same primitive menu search restricted to permitted operations may find another
   goal-reaching sequence. Fromx1 goal3 safe add2 exists; fromx5 goal11 requires+6,
   attainable add3 twice, length2. Fromx12 goal25 needs+13, unreachable within2 adds.
   Reject known bound failure, no assertion all goals feasible under revoked resources.
6. ID permutation: operation IDs0/1 swapped but generic resolution table updated;
   learned program action tokens decoded by the same mapping. Compare effects and
   authority records. Both actions intentionally share one dispatch, not named modes.
