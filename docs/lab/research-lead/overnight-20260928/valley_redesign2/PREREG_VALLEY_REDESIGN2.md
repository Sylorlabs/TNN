## 1. Redesign rationale (frozen)

The v1 failure was structural: canonical prefixes opened with
[PUSH 0, ...] or [IN0, ...], so short IN0-led solvers sat within 2
edits of early prefixes. This redesign keeps full GENEXEC2 and the
V1-V5 gates but changes instance construction:
(a) canonical full length L is at most 11, so the V3 2-edit check over
proper prefixes (k <= 10, neighbors to length 12) is COMPLETE: passing
V3 PROVES minimum edit distance 3 from every proper prefix to every
solver outside the canonical path;
(b) canonical paths open with a PUSH-led inert prologue, keeping every
proper prefix at least 3 edits from any IN0-led short solver;
(c) targets require coordinated multi-point changes (two-input AND,
mod-m, scaled linear), defeating single-comparison shortcuts;
(d) V4 calibrators are redefined as runnable mechanisms (section 3).

## 3. Acceptance gates V1-V5 (frozen)

V1 (score profile): every non-empty op-level proper prefix of F=P0+O
scores <= s0; at most one ties s0; at least d-1 score strictly below

V2 (greedy fails): frozen REF-GREEDY (strict improvement only,

V3 (no shallow shortcut): exhaustive check. For every proper prefix,

prefixes of F (canonical completion is not a shortcut). Every L <= 11
so all proper prefixes satisfy k <= 10 and the enumeration is
complete: a V3 pass is a PROOF of minimum 3-edit distance.
V4 (myopic calibration): both calibrators must FAIL to solve.
(a) Frozen hyp_a residual-construction algorithm: decision logic copied
verbatim from hyp_a.zag (commit 21d838921; BUILD-FAIL, A-F1 fires;
13-op straight-line VM, 31-symbol choice set, identical loop), with
only the episode table substituted for the hardcoded T0-T5 tasks.
(b) GREEDY-2: strict greedy with 2-op lookahead over the 34-symbol
alphabet; by construction it never takes a score-decreasing step. If
either solves a d>=1 instance, the instance is miscalibrated and
dropped. Rationale: hyp_a is falsified as myopic by verdict; GREEDY-2
