## Mission

Extend the DDES-integrated continuing learner (DDES-INTEGRATION-PASS
f843188ad; prereg c3fecd3c8; implementation d9f3871c5) so causal
ambiguity triggers ADAPTIVE multi-step intervention plans: each
subsequent experiment is derived conditioned on the previous outcome.
Bounded L2. NOT L3. Explicitly NOT arena C9 re-entry.

## Background (committed evidence this builds on)

- DDES integration resolves single-frontier ambiguities with one-shot
  plans ([S, W..., O(V*)]): ambiguity -> construct one plan from
  derived (V*, t*, schema) -> execute once -> eliminate -> resolve.
- The derivation core (compute_arrivals, compute_frontier from
  ddes/ddes.zag 56db8d606; eff_waits, synthesize_plan_gen, predict_gen,
  world_step_gen from ddes_generalize/ddes_gen.zag 843c45fee) already
  handles arbitrary rule graphs. Missing piece: a planner that chains
  frontiers, recomputing arrivals conditioned on the surviving
  hypothesis set after each real outcome, within the same
  AMBIGUOUS-entry trigger.
- The integration worker's recommended next step (adopted): multi-step
  discriminating intervention plans inside the continuing learner.

## Chaining planner design (frozen)

One continuing process holds a persistent causal ledger across
sequential experiences. Ledger stride extended to 544 bytes per entry:
+0 status (0=EMPTY,1=ACTIVE,2=AMBIGUOUS), +4 winner, +8 n_vars,
+12 n_cands (2 or 3), rule blocks at +16+k*128 for k=0..3
(h0, h1, h2, sealed true). Rule block layout unchanged: +0 nr, +4
src[8], +36 dst[8], +68 delay[8].

Feed protocol per entry: the learner receives n_cands hypothesis rule
graphs plus one passive observation (var, t, outcome). Each hypothesis
is checked against the passive observation with the analytic predictor
(arrival <= eff_waits(t), schema=1). All consistent and a disagreement
frontier exists over the candidate set -> entry AMBIGUOUS with n_cands
candidates. Exactly one consistent -> ACTIVE with that winner.

Derivation core provenance: compute_arrivals, compute_frontier,
eff_waits, synthesize_plan_gen, predict_gen, world_step_gen are copied
verbatim from the frozen sources (56db8d606, 843c45fee). New: the
round loop, the n-candidate frontier generalization, and the
termination guards. The derivation algorithm itself is unchanged.

Modes:
- MODE=BASE: AMBIGUOUS entries stay ambiguous; queries emit WITHHOLD.
- MODE=ONESHOT: the original one-shot logic generalized to n
  candidates: single frontier over the full candidate set, exactly one
  plan, exactly one execution, resolve iff exactly one survivor;
  otherwise ONESHOT-RESOLVE-FAIL. This mode exists to demonstrate
  one-shot insufficiency on the frozen multi-step cases.
- MODE=ADAPT: the chaining planner. Round loop, r = 1..BUDGET:
  (i) compute the earliest disagreement frontier over the CURRENT
  SURVIVOR SET (arrivals recomputed per surviving hypothesis; this is
  the conditioning step: the target is derived from the reduced set,
  which is determined by the previous round's real outcome);
  (ii) synthesize exactly one plan from (V*, t*, schema);
  (iii) execute it exactly once against the sealed true world;
  (iv) predict each survivor at (V*, t*, schema); eliminate mismatches.
  Termination: exactly one survivor -> ACTIVE with winner, emitting
  rounds=R; zero survivors -> ADAPT-RESOLVE-FAIL (world-outside-set);
  a round eliminating zero candidates -> ADAPT-RESOLVE-FAIL
  (no-progress); r exceeds BUDGET=3 -> ADAPT-RESOLVE-FAIL (budget).
  BUDGET=3 is frozen. It bounds ROUNDS, not plan length: each round's
  plan is still assembled from a derived target with no length bound
  in the derivation path, and with n candidates at most n-1
  eliminations can occur, so the budget can only stop early, never
  enumerate.

Emitted line formats (frozen):
- ADAPT eN ROUND r survivors=[h..] TARGET V*=v t*=t schema=s
- ADAPT eN ROUND r PLAN [...] built=1
- ADAPT eN ROUND r EXEC real=o
- ADAPT eN ROUND r PRED h0=p0 h1=p1 [h2=p2] ELIM/SURVIVE lines per
  candidate
- ADAPT eN RESOLVED winner=hN rounds=R
- ADAPT eN ADAPT-RESOLVE-FAIL reason
- ONESHOT eN TARGET/PLAN/EXEC/PRED lines (same shapes)
- ONESHOT eN RESOLVED winner=hN rounds=1
- ONESHOT eN ONESHOT-RESOLVE-FAIL survivors=K

## Frozen cases (all values frozen here)

Variables: X=0, Y=1, Z=2, n_vars=3. Sealed true world per entry.

P1 (e0, unambiguous probe): h = [(X->Z,2),(Z->Y,0)] (n_cands=1,
h0==h1 loaded). Passive: (Y,2) = 1. Queries: (Y,2) -> 1.

P2 (e1, unambiguous probe): h = [(X->Y,3)]. Passive: (Y,2) = 0.
Queries: (Y,2) -> 0; (Y,3) -> 1.

M1 (e2, frozen 2-step ambiguity): h0 = [(X->Y,1)], h1 = [(X->Y,2)],
h2 = [(X->Z,2),(Z->Y,0)]. Passive: (Y,2) = 1 (all three consistent:
arrivals 1, 2, 2 all <= eff_waits(2) = 2). Sealed true world: h2.
- MODE=BASE: query (Y,1) -> WITHHOLD (ambiguous).
- MODE=ONESHOT: TARGET V*=1 t*=1 schema=1; PLAN [S,W,O(1)] built=1;
  EXEC real=0; PRED h0=1 h1=0 h2=0; ELIM h0; SURVIVE h1 h2;
  ONESHOT-RESOLVE-FAIL survivors=2.
- MODE=ADAPT: ROUND 1 survivors=[h0,h1,h2] TARGET V*=1 t*=1 schema=1;
  PLAN [S,W,O(1)] built=1; EXEC real=0; PRED h0=1 h1=0 h2=0;
  ELIM h0; ROUND 2 survivors=[h1,h2] TARGET V*=2 t*=2 schema=1;
  PLAN [S,W,W,O(2)] built=1; EXEC real=1; PRED h1=0 h2=1;
  ELIM h1; RESOLVED winner=h2 rounds=2.
  Post queries: (Y,1) -> 0; (Y,2) -> 1.

M2 (e3, frozen 2-step ambiguity, second family): h0 = [(X->Y,1)],
h1 = [(X->Z,1),(Z->Y,1)], h2 = [(X->Z,2),(Z->Y,0)].
Passive: (Y,2) = 1 (arrivals 1, 2, 2 all <= 2). Sealed true: h1.
- MODE=BASE: query (Y,1) -> WITHHOLD (ambiguous).
- MODE=ONESHOT: TARGET V*=1 t*=1 schema=1; PLAN [S,W,O(1)] built=1;
  EXEC real=0; PRED h0=1 h1=0 h2=0; ELIM h0;
  ONESHOT-RESOLVE-FAIL survivors=2.
- MODE=ADAPT: ROUND 1 survivors=[h0,h1,h2] TARGET V*=1 t*=1 schema=1;
  PLAN [S,W,O(1)] built=1; EXEC real=0; PRED h0=1 h1=0 h2=0;
  ELIM h0; ROUND 2 survivors=[h1,h2] TARGET V*=2 t*=1 schema=1;
  PLAN [S,W,O(2)] built=1; EXEC real=1; PRED h1=1 h2=0;
  ELIM h2; RESOLVED winner=h1 rounds=2.
  Post queries: (Z,1) -> 1; (Z,2) -> 1.

A (e4, one-shot regression): h0 = [(X->Y,1)], h1 = [(X->Y,2)]
(n_cands=2). Passive: (Y,2) = 1. Sealed true: h1.
- MODE=BASE: query (Y,1) -> WITHHOLD (ambiguous).
- MODE=ONESHOT: TARGET V*=1 t*=1 schema=1; PLAN [S,W,O(1)] built=1;
  EXEC real=0; PRED h0=1 h1=0; ELIM h0; RESOLVED winner=h1 rounds=1.
  Post queries: (Y,1) -> 0; (Y,2) -> 1.
- MODE=ADAPT: must RESOLVE winner=h1 with rounds=1 (single round,
  no chaining needed). Post queries: (Y,1) -> 0; (Y,2) -> 1.

Expected base probe outputs (all P1/P2 FEED, ENTRY, Q lines) must be
byte-identical across MODE=BASE, MODE=ONESHOT, and MODE=ADAPT runs
(verified by shell diff on the extracted sections).

Termination evidence: M1 and M2 resolve in exactly 2 rounds (budget
never binds); A resolves in 1 round. The no-progress and budget guards
are coded and frozen; a dedicated trigger case is not frozen because
the derivation math guarantees at least one elimination per round
whenever the true world is inside the candidate set (at the frontier
(V*,t*), predictions always split: the min-arrival side predicts 1,
the other side predicts 0, and the real outcome matches at least one
side). The guards exist as backstops.

## Classification

Bounded L2. NOT L3. Researcher still owns: hypothesis format, the
frozen case set, the derivation algorithm, action vocabulary, the
