## Causal interpretation

**R1:** The repair does not make delay attribution smarter; it makes
it humbler. At support=1 the learner cannot distinguish a genuine
delay from a positioned confounder, so it records the hypothesis
without acting on it. This is the correct epistemic posture for a
single correlational data point. Confirmation requires the
correlation to repeat, which genuine causal structure does and
one-off confounders do not. The contest machinery is still
suppressed for explained variables (preserving K-CV3), but the
suppression is now safe because the suppressing hypothesis is inert
until confirmed.

**R2:** The threshold is now genuinely invented from data. The
fewest-cells preference selects THR over EQ because the data (three
distinct s0 values straddling the boundary) makes THR strictly more
compact. The researcher-supplied tie-break is retained in code but
provably idle on this world (ablation). The old world is kept as a
regression with the tie-break honestly labeled as a representational
preference.

## Boundaries and non-claims

- Provisional rules are never retracted; an unconfirmed provisional
  is inert provenance. Refutation-driven retraction is future work.
- A provisional rule does not block a later conflicting ACTIVE rule
  on the same variable (not tested here).
- The delay-before-contest priority structure is unchanged; only
  the actionability of unconfirmed rules changed.
- Bounded L2. Not L3. The EQ/THR vocabulary, conjunction search,
  delay machinery, and split phases remain authored; the learner
  selects from them using data.
