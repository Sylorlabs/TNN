## Quoted Hypothesis D specification (review 18be93c3e, section 4)

"Core mechanism: the standard quality diversity baseline from the
evolutionary computation literature. An archive is indexed by a
behavioral descriptor (discretized output vector on the train
episodes). Candidates are generated by mutating archive members
(append, replace, or delete a single op, in deterministic order). A
candidate is retained if its niche is empty or its exact match score
beats the niche elite. Fixed evaluation budget. Retention is per
niche; there is no global top K ranking."

"How it differs from beam search: retention is per behavioral niche
rather than global score rank, so behaviorally diverse stepping
stones survive regardless of score."

Predictions: "2x+1: SOLVE. mod3: SOLVE. parity: SOLVE. abs: FAIL.
nested abs: FAIL. fragment composition: FAIL. adversary function:
SOLVE if and only if T6 is straight line synthesizable within budget."

Control validity: "F1: D fails 2x+1. The control is misconfigured. It
must be fixed before serving as a baseline." "F2: D solves nested abs
or fragment composition. Invalidate and fix."

Committed implementation (2500fd02b, hyp_d_v2.zag): niche =
(length_bucket, score_norm, behavior_hash), behavior_hash = rolling
trit hash mod 256 over train outputs; per-niche cyclic mutation order
over M = nt + (nt+1)*pl templates (append, then replace, then delete);
round-robin parent selection over occupied niches; 1,000,000
evaluations per task. Fidelity to the quoted spec is verified by
inspection in the review (analysis R0).

## Review questions

Q1. Is the predicted 8-op parity solution real? I.e., does
[IN0, IN1, ADD, PUSH 2, MOD, PUSH 1, SWAP, SUB] score 25/25 on the
frozen T3 train episodes and 39/39 held-out?
Q2. Where did the search break? The solution needs the chain
P5=[IN0,IN1,ADD,PUSH 2,MOD] (0/25) -> P6 (append PUSH 1, 13/25) ->
P7 (append SWAP, 0/25) -> P8 (append SUB, 25/25). Which link was
never inserted into the archive, and for the first missing link,
was a suitable parent present in the archive?
Q3. For the first missing link: was the child generated but evicted
(same niche occupied by a higher scorer) or never generated?
Q4. Mechanism: given round-robin selection over O occupied niches
and per-niche mutation cycles of length M = 31 + 32*pl, what
fraction of each niche's single-mutation neighborhood is explored
within 1M evals? Does the arithmetic explain the miss?

## Analyses (all pure Zag)

R0. Fidelity audit: map each quoted spec sentence to the committed
code location. Report any deviation.
R1. Theory check: independent straight-line full-VM evaluator;
score the 8-op program on frozen T3 train (25) and held-out (39).
Q1 is answered YES iff 25/25 and 39/39.
R2. Log parser: parse committed HYPD_V2_RAW_1/2/3.txt T3 sections;
report insertion status of P5, P6, P7, P8 and of every
single-mutation predecessor of P8. Q2 is answered by the first
missing link in the chain.
R3. Niche audit: recompute niche_of for P5/P6/P7; scan the parsed
log for same-niche insertions with strictly higher score. If one
exists, the link was evicted; else it was never generated. Answers Q3.
R4. Dilution arithmetic: from the log, occupied-niche count over
time on T3; selections per niche; per-niche cycle length M for the
relevant parent lengths; fraction of the mutation cycle completed
by the median niche. Answers Q4.
R5. Junk-niche share: fraction of occupied niches holding
degenerate (score 0, constant-output) programs; quantifies
round-robin dilution by non-contributing niches.

## Explanation criteria

The anomaly is EXPLAINED iff R1 confirms the solution is real AND
R2/R3 locate the broken link AND R4 shows the selection/mutation
arithmetic makes that break expected (not a fluke). It is PARTIALLY
EXPLAINED if the link is located but the arithmetic does not
clearly predict it. Otherwise UNEXPLAINED, and the review
recommends the concrete next instrument.
