## Implementer decisions

1. GW id range. FW used [30000,39999]. GW uses [40000,49999], disjoint per
   world in 100-id blocks (GWn owns [40000+100*(n-1), 40099+100*(n-1)]).
   Answer values are small integers outside the GW range.
2. GW3 uses the value 100 as a subject id in two triples
   (OBSERVE 100 40214 40203 and QUERY 100 40217 300). This is deliberate:
   the level-2 chain traverses the level-1 VALUE as a subject, which is
   the cross-level reuse under test. Id hygiene treats 100 as an event
   value (in [-2,1000]), consistent with the FW hygiene rule.
3. GW5 is multi-phase with a single-stage responder contract (simpler
   than FW6's two-stage contract, because phase A contains exactly one
   ACT line, so any "CHOICE 30" is the inquiry act).
4. Each GW world is specified to run with FRESH learner state, so worlds
   are independent. GW5's phases share state within the world (the
   responder contract requires it).
