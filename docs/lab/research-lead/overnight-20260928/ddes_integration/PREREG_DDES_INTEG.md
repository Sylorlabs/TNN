## Mission

Integrate DDES discriminating-experiment synthesis into the continuing
learner's causal path so that an AMBIGUOUS causal entry triggers a
constructed intervention, executed once, whose outcome resolves the
entry, instead of the entry remaining withhold-only. Bounded L2
integration. NOT L3.

## Integration design (frozen)

One continuing process holds a persistent causal ledger (state buffer).
Experiences are fed in sequence: e0, e1 (unambiguous probes), e2 (frozen
ambiguity case). Variables: X=0, Y=1, Z=2, n_vars=3. Hypotheses are rule
graphs in DDES format: parallel arrays (n_rules, src, dst, delay).

Feed protocol per entry: the learner receives two hypothesis rule graphs
(h0, h1) plus one passive observation (var, t, outcome). The learner
checks each hypothesis against the passive observation with the analytic
predictor (arrival <= eff_waits(t)). Both consistent and hypotheses
differ -> entry status AMBIGUOUS with 2 candidates. Hypotheses identical
-> entry ACTIVE, winner h0.

Query protocol: query(entry, var, t). ACTIVE -> analytic prediction from
the resolved hypothesis. AMBIGUOUS -> behavior depends on mode.

Mode 0 (BASE, un-integrated learner): AMBIGUOUS entries stay ambiguous;
queries emit WITHHOLD (ambiguous).

Mode 1 (INTEG, integrated learner): when an entry becomes AMBIGUOUS at
feed time, the learner's causal path triggers DDES synthesis copied
verbatim from the frozen sources: try schemas set-X (1) then null (0);
compute_arrivals per hypothesis; compute_frontier for earliest (V*, t*);
synthesize_plan_gen assembles exactly one plan [S] + W x eff_waits(t*)
+ O(V*); execute the plan exactly once against the sealed true world;
read the real observation; compute each hypothesis's analytic prediction
at (V*, t*); eliminate mismatches; require exactly one survivor; set the
entry ACTIVE with the survivor as winner. Post-resolution queries answer
from the survivor.

Provenance of copied derivation core (verbatim from frozen commits):
compute_arrivals, compute_frontier from ddes/ddes.zag (56db8d606);
eff_waits, synthesize_plan_gen, predict_gen, world_step_gen from
ddes_generalize/ddes_gen.zag (843c45fee). Integration glue (ledger,
feed, query, emit) is new and frozen-case specific by design; the
derivation core is unchanged and generic.

SURVIVE h1; RESOLVED winner=h1; post queries (Y,1) -> 0, (Y,2) -> 1.

## Classification

Bounded L2 integration. NOT L3. Researcher still owns: hypothesis
format, rule-graph authority, frozen case set, action vocabulary, the
