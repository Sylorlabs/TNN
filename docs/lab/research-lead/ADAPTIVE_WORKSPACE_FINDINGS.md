# Adaptive workspace findings: consolidated, dated evidence

Date2026-10-07. This document collects current interpretation of the workspace
research wave; historical REPORT/PREREG files stay unchanged and authoritative for
their own runs. Scope gates in NESTED_WORKSPACE_SCOPE.md. Current interface is the
frozen TNN-2 reference plus isolated prototypes; canonical production learner remains
unestablished, so no production-equivalence claim anywhere in this wave.

## What is established

1. **Persistent allocation after rejected search** (PERSISTENCE_REPORT.md).
   Direct rejected trials leave42 live nodes each (20 instructions +22 scratch).
   Query-miss wrapper additionally creates inquiry FACT nodes. Engineering defect,
   not cognition. No causal-use or leak-asymptotics claim.

2. **Transactional rejection under a retained-state budget** (ROLLBACK_REPORT.md).
   Full-workspace rollback preserves prior executable/cache in32/32 conditions with
   no dangling edges; later acquisition6/8 retained vs8/8 rollback, advantage only at
   one budget (80), ties at48/64/96. Scratch exceeds commit budget; no memory/time
   claim. Snapshot isolation is not an undo journal or production repair.

3. **Hand-built nesting is representable but inert** (REGION_REPORT.md).
   42 trials total (2 renames x 7 topologies x 3 feedback modes) over seven
   GROUP/MEM topologies: identical candidate paths and work.
   Licensing-fact lesion changes results, so the assay is sensitive. The existing
   frozen proposal path scans FACTs, not region structure. N0 capacity only;
   N1 causal region use is absent in this fixture.

4. **Experience-built executable objects are causally reused** (OBJECT_REPORT.md).
   Same source acquires A,B then C,D; 192/192 heldout answers in two encodings.
   Learned library lowers acquisition to97 candidate tests (including prior training)
   vs fresh155, erased165. Method root erasure fails; facts erasure does not.
   Revision8/8 with unrelated method retained8/8, old object bytes unchanged.

## What failed the attacks

- **Flat executable library ties exactly** (97 tests, same effects). Nesting/references
  are not necessary for this advantage; the gain is learned macro reuse.
- **Supplied affine interpolation matches accuracy16/16** in every arm. A simple
  researcher-authored rule covers these laws; no incompressibility of methods shown.
- **The preregistered "misleading" prior is useful**, not adversarial (110 vs fresh155).
  Genuine conflict/negative transfer is UNTESTED by that condition. Future misleading
  priors must be defined by measured conflict, not by a label.
- **Irrelevant prior inflates search** (742 tests). Library growth can hurt; no
  "learner improves with age" claim.
- **Search grammar, shortest-first order, verification and promotion are
  researcher-written.** Source enumeration is fully disclosed and bounded
  (two primitive effects, composition length<=6, 4096-test cap). No L3, no
  representation invention, no self-chosen applicability.

## Central remaining gap

The researcher still owns the possibility space and the search. Evidence-built
organization that changes HOW future methods are generated has not been shown;
what has been shown is that experience-built methods become reusable tokens.
That is necessary but not sufficient for the user's "free-roaming adaptive
workspace" target.

## Next decisive tests (executed in CONFLICT_REPORT.md)

1. True negative transfer: a short attractive prior token that is WRONG for the
   target must not be promoted and its cost must be measured.
2. Library pollution scaling: wrong composite tokens K=0..32; measure work growth.
3. Honest abstention under ambiguity: with one training point multiple programs fit
   and disagree on heldouts; a constructor that answers is overclaiming. Enumerate
   all fits, count distinct outcomes on fixed probe inputs, abstain when >1.
   Adding a distinguishing witness must restore a unique answer.

No TNN/LLM comparison is established here; the pasted GitHub scaling figures were
not freshly replicated in this wave.

## Conflict round outcome (CONFLICT_REPORT.md, 2026-10-07)

1. **True negative transfer is safe but taxed.** Wrong short token [add1,double]=
   2x+2 is enumerated then rejected; target 2x+1 still 8/8; candidate tests5->7.
   Flat execution ties7, so no nesting claim. The wrong token is never promoted.
2. **Pollution cost is predictable.** Candidate tests =2K+5 (linear in number of
   distractor composites); primitive effects grow superlinearly12->1164 at K=32.
   Correctness never lost. A polluted library taxes every later acquisition.
3. **The constructor can know when it does not know.** One training point yields6
   distinct fitting behaviors; it abstains. Two or more points yield a unique fit,
   8/8 heldout. Distinguishing witness resolves the ambiguity.
4. **Honesty is expensive here.** Full enumeration for ambiguity detection is126
   candidates vs5 for first-fit, about25x. A cheaper uncertainty estimate is an
   untested hypothesis, not a free improvement.
