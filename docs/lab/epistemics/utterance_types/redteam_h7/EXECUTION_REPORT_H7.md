## Method (driver fidelity)

The learner source (`crew2/learner/h7_main.zag`) is a monolithic curriculum-runner with no external ingest API. The red-team driver (`evidence/driver/h7_rt_driver.zag`) was built by taking the mechanism source **byte-verbatim** (23,688 bytes, asserted by the generator) and replacing only `main()` with the battery driver. The driver uses exclusively the learner's real internal functions:

- **Training:** identical Phase 2a (`know_teach` × 5 concepts) + endorse pool (20 facts + 20 calib, lowered) + Phase 2b FL2 loop (5 concepts × 32 exemplars, same step schedule 2/4/8/16/32, `learn_exemplar` + `calibrate`). The probe-set scoring (`score_set`) was omitted — it never mutates marker state (`ment` passed by value), verified by signature.
- **Fidelity check:** the mechanism's *original* main was compiled and run to completion (`AUDIT|9902`, `H7_FAILURES,1`, matching the crew's committed evidence). Its RULEDUMP emitter reported the same marker state as the driver's digest (see below).
- **Ingest routing (raw text only, fresh state per item):**
  - TEACH turns → `belief_install` (the real Phase-1 teacher path).
  - ATTACK turns (enabled) → `predict()` on the raw bytes (empty ctx/spk — the turns carry no separate fields); WITHHOLD → `typed_write` (typed partition); ENDORSE → nothing installed (there is no auto-install path in this build; mirrors the mechanism main's probe handling).
  - ATTACK turns (disabled) → `belief_install` (every utterance treated as sincere).
- **Recall:** `belief_recall` over belief slots joined as the response (the learner has no semantic query engine and no query-time type filter; none was invented). `belief_dump.txt` and `belief_dump_naive.txt` both export belief slots via `belief_recall` — in this build the unfiltered path structurally cannot address the TYPED arena, which is exactly what CTRL-NAIVE tests.
- **Exports:** the six interchange files per HARNESS_SPEC §1.2–1.5; `payload_map.txt`/`item_kinds.txt` generated by mechanical transform from the frozen registries (parser: `evidence/driver/parse_registries.py`).
