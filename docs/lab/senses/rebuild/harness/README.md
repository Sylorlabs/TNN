# Senses-rebuild harness (HARNESS-CREW)

## Files
- `gen.py` — deterministic fixture generator (master seed 20260921; see
  `FIXTURE_SOURCES.md`). Regenerating yields byte-identical fixtures.
- `run.py` — runner. Waits for `../a_raw/DONE` and `../b_percept/DONE`
  (12h timeout, 30s poll), then sweeps every (approach, task, variant, fixture):
  runs `sense <task> <fixture>`, validates required keys + judgment vocabulary,
  records judgment/confidence/ops + truth. Determinism check (KB5): first 10
  primary fixtures per task per approach, 3 runs each, byte-identical stdout
  required. Writes `results/raw_results.json`. `--no-wait` skips the wait.
  `SENSE_A`/`SENSE_B` env vars override binary paths (used for stub testing).
- `score.py` — scorer. Accuracy per task/variant, mean primary accuracy (equal
  weights), ops totals, noise/adversarial mean accuracy, and the SHARED
  deliberate-memory rule (`apply_memory_rule`, one code path for both
  approaches; streams per (approach, task), all variants in sorted-path order).
  Writes `results/metrics.json`.
- `assemble.py` — reads `results/metrics.json`, writes `RESULTS.md`: full
  tables + computed per-kill-bar evaluation (KB1–KB5). Does NOT write VERDICT.md.
- `FIXTURE_SOURCES.md` — per-batch photographic vs procedural documentation.
- `fixtures/` — 925 fixtures + 925 `.truth` files; `_photos/` = 170 real photos.
- `results/` — `raw_results.json`, `metrics.json` (generated by runs).

## Typical flow
```
python3 run.py            # waits for crews, sweeps, writes raw_results.json
python3 score.py          # -> results/metrics.json
python3 assemble.py       # -> RESULTS.md
```
