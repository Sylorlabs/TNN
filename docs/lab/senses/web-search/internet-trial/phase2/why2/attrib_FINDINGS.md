## Method

1. **Faithful re-simulation of the R-CORR pipeline.** Reimplemented `ht2_add → ws_add_result → ws_decide → ht2_end` exactly as in `phase2/src/` (per-query fresh fact cycle, relevance=1 for all results, dedup on (domain,answer), 6-entry cap, plurality with first-listed-side tie-break, IRRELEVANT entries counted, known-prior branch requiring unanimous AFFIRM). The simulator reproduces **every** observed final disposition on the frozen tags, including all 14 failures — so the counterfactuals below are grounded, not speculative.
2. **M1 counterfactual:** re-tagged each installing query's 6 results by reading title+snippet against the claim text (conservative: only changed tags clearly wrong on the snippet's face; robustness checks noted). Re-ran the simulator. M1 = NECESSARY if the decision flips or the tags are demonstrably inverted on the decisive (plurality-forming) results.
3. **M2 counterfactual:** compared the deliberation's actual query against the frozen baseline query in `fixtures/course.json`. M2 = NECESSARY only if the baseline query itself produced (or would plausibly produce) a balanced/withholding set while the used followup manufactured the one-sided set. Marked CON where the query was loaded but the baseline check is vacuous or unprovable.
4. **M3 counterfactual:** per the brief's definition — claim type in {CONTESTED, AMBIGUOUS, EVOLVED, SKEPTICISM} under the *frozen* course labels, where a withhold-before-count gate prevents the install regardless of tags/queries.
5. **M4 counterfactual:** 3-tier reliability weights applied to the *frozen* tags (3 = official/institutional/academic: who.int, cancer.org, whitehouse.gov, science.org, edu.au, guinnessworldrecords…; 2 = established editorial/reference: britannica, wikipedia, theconversation, sciencealert, webmd, …; 1 = UGC/commercial/advocacy/fringe: youtube, tfes.org, flatearthdave.com, auricmedia.net, …). Weighted plurality with the same tie-break. M4 = NECESSARY iff the weighted winner flips the decision.
6. Deterministic throughout: sorted iteration, no RNG, no new web runs.

## (c) Causal stories

**M1 — the stance classifier inverts negation and mistakes topic for endorsement (9 NEC, 2 CON).** This is the largest single cause of damage and the only mechanism implicated in all three failure classes. Its signature is keyword co-occurrence read as endorsement: "Coffee *doesn't* cause cancer" → AFFIRM (C7); "Mauna Kea is the world's *tallest* mountain" → AFFIRM of "Everest is tallest" (C12); "the Sahara is the *third-largest*" → AFFIRM of "Sahara is largest" (C13); a rain-sounds video → AFFIRM of "chocolate cures insomnia" (C16); medical pages about clots in general → AFFIRM of "fruit dissolves clots" (C15). On C7 the web was *correct* — who.int, cancer.org, theconversation all denying — and the classifier alone manufactured the 3–1 AFFIRM majority that installed a falsehood. On C15/C16 the classifier conjured corroboration out of irrelevant listicles (the domain-dedup rule is the only thing that saves C15 in the corrected world: both surviving AFFIRMs are the same youtube spam domain). On C12/C13 the inversions are load-bearing: correcting them flips INSTALL→REJECT, which is why M1 is jointly NECESSARY there alongside M3.

**M3 — no claim-type gate: contested and ambiguous claims go straight to corroboration counting (6 NEC).** C5 (CONTESTED) is the pure case: the tags were honest, the sources genuinely split the way the 2026 web does, and *no* tag correction flips the decision — under R-CORR even a balanced 2–2 set installs via the order tie-break. The only mechanism that prevents the install "regardless of tags/queries" is refusing to count votes on a contested claim in the first place. C12/C13 (AMBIGUOUS) show the joint-causation pattern: M1's inversions explain why *this* install happened (corrected tags give REJECT), but M3's absence explains why *any* decisive disposition was reachable — the oracle answer for all three is WITHHOLD, which the pipeline cannot produce on a contested/ambiguous claim except by accident (vote fragmentation). Note the boundary: M3 as defined does not cover the FALSE/SPAM installs (C7/C8/C11/C15/C16), so it scores zero on K1 — its damage is concentrated entirely in the K2 contradiction-trial wipeout (0.000 both arms).

**M2 — affirm-seeking followups manufacture one-sided corroboration (3 NEC, 4 CON).** The deliberation loop's "try harder" behavior is the engine: on C8 the verbatim baseline query ("the earth is flat evidence") returned a balanced set and WITHHELD (2 AFF/1 DEN/3 IRR); the followup "…systematic review" returned flatearthdave.com, tfes.org ×2 and "5 Real-World Flat-Earth Proofs" → INSTALL. On C11 two queries withheld, then "…latest evidence" installed on a 3–3 tie broken by result order. The helper arm proves the damage is structural, not informational: on C8 the helper correctly denied on q12 and the decision held WITHHOLD — then the q13 followup's manufactured set steamrolled it into INSTALL with no further consult (consults only fire on WITHHOLD). C5/C15 are CON rather than NEC: C5's query dropped the baseline's "vs natural origin" balance, and C15's query *is* the spam's own marketing copy ("doctors hate it") — but in both cases the baseline check is vacuous or unprovable from frozen evidence, so M2 shaped the outcome without being but-for.

**M4 — source reliability not weighted (1 NEC).** The narrowest footprint under the frozen-tags counterfactual: only C11 solo flips, and only via the 3–3 tie — reliability weighting lets the lone wikipedia IRRELEVANT (weight 2) outvote three fringe AFFIRMs (weight 1 each) → WITHHOLD. Everywhere else the weighted winner matches the unweighted winner. But the count understates M4's real role because of **masking by M1**: in C7, C8, C12 and C13 the *highest-reliability* sources were exactly the ones M1 mistagged AFFIRM (who.int, cancer.org, wikipedia, britannica, guinnessworldrecords, geology.com) — reliability weighting over corrupted tags cannot help, since the votes it would weight most are the corrupted ones. The combined counterfactual (correct tags + weighting) changes nothing beyond correct-tags-alone in this battery, which cuts both ways: M4 is not a substitute for fixing M1, and M1's repair is a precondition for M4 to matter. C8 is the cleanest separation: even with perfect tags *and* reliability weights, the manufactured one-sided set still installs — that failure belongs to M2 alone.

## (d) Anomaly notes (not bar failures)

**C3 — settled TRUE ("Earth orbits the Sun") REJECTED in both arms.** Query was the neutral baseline verbatim. Frozen tags: DEN=3 (youtube conspiracy video "EARTH does NOT REVOLVE around the SUN" — genuine; wikipedia "Earth's orbit" whose snippet literally says "Earth orbits the Sun at 149.60M km" — inversion; tiktok "Why Does Earth Orbit The Sun and Not Jupiter" — inversion), AFF=3. The 3–3 tie was broken by result order, electing DENY because the conspiracy video was rank 0. Corrected tags: AFF=5, DEN=1 → INSTALL. Same M1 signature as the failures (two inversions turned a 5–1 affirm into a tie), compounded by a rank-order tie-break with no seniority/discounting of rank-0 junk. Not a bar failure (M1/K1 count only FALSE_SET), but it shows the machinery fails symmetrically.

**C1/C14 — settled TRUE (boiling point; 8 planets) WITHHELD ×3 in both arms, even with helper affirmation — over-conservatism, not a bar failure.** Both are known-prior candidates (P1/P2), and the known branch of `ws_decide` requires *unanimity*: a single non-AFFIRM entry forces HOLD_INSTALLED → WITHHOLD. Each withhold traces to M1 mistags tripping the veto: C1 q0 — smithsonianmag's *freezing-point* article and usatoday's boiling-point article both tagged DENY; C14 q6 — theplanetstoday ("not as simple as you might have thought") tagged DENY; q7 — wikipedia's "Solar System" article ("most prominently its eight planets") tagged DENY, a clear inversion; q8 — nineplanets.org tagged DENY on a Pluto-nostalgia snippet. The helper's correct AFFIRM observations could not override the veto (they add one AFFIRM entry; the mistagged DENYs remain). This is M1's mirror image: the same classifier errors that install falsehoods also veto truths, and the unanimity rule amplifies a single mistag into a permanent withhold. The asymmetry is stark: installing a falsehood needs only a mistagged *plurality*; keeping a truth needs mistag-free *unanimity*.

**Contrast — correctly handled:** C9 (moon landings) REJECTED both arms; C10 (5G) WITHHELD; C6 (eggs, EVOLVED) REJECTED both arms against a WITHHOLD oracle — wrong but not a bar trip; A1–A3 all REVISED correctly through the deliberate-revision path (M4 bar 3/3). The intake machinery, not the revision machinery, is broken.

## Caveats for the coordinator

1. **Skepticism rule (post-trial standing rule, 2026-09-22):** Micah's rule excludes genuinely debatable claims (flat earth, chemtrails named explicitly) from true/false scoring. Under it, C8/C11 leave K1's denominator entirely — a sibling crew is rescoring. This changes bar math, not causality: M2 still manufactured those installs. Attribution above uses frozen prereg labels throughout.
2. **Spam-gate gap:** C15/C16 are SPAM type with a frozen expectation of "REJECT+SPAM-FLAG", but no spam/content-farm detector exists in the pipeline — the helper's own responses name the pattern ("classic content-farm pattern", "AI-generated content-farm spam") yet the sense cannot act on it. M3's definition excludes SPAM; consider a fifth mechanism or an M3 extension.
3. **M1↔M4 entanglement:** M4's NECESSARY count of 1 is measured over frozen (M1-corrupted) tags; several high-reliability votes were inverted. Fix-ordering implication: M1 repair first, then M4 has clean votes to weight.
4. **Query strings** are the deliberation binary's best-effort reconstructions per CONTRACT.md (prereg froze claims, not query text); the M2 analysis compares them against the frozen baseline queries, which *are* frozen.
5. **C7's bar status:** label FALSE but excluded from K1's FALSE_SET (region-2 controversy); its INSTALL moves no bar directly, but it is the cleanest single-mechanism (pure M1) failure in the battery.
