# R2-11 build notes — replay vs generative emission head-to-head

Seed: **20260923**. Toolchain: `~/workspace/tnn-lab/toolchain/bin/znc_linux_x86_64_abed8aa1`.
Both forks are pure Zag, zero RNG. The percept pipeline is shared and byte-identical.

## 1. Shared percept pipeline (`zag/percept.zag`)

Integer math only. Fills a 64-byte percept record (all multi-byte LE):

```
[0]=task_id (1..6)  [1]=judgment code  [2..3]=confidence 0..1000
[4]=disposition (0=INSTALL 1=NOTE 2=DISCARD)
T1: [5,6,7]=meanA rgb  [8,9,10]=meanB rgb  [11..14]=d2 u32
T2: [5..6]=pearson r x1000 (i16 signed)  [7]=meanlumA  [8]=meanlumB
T3: [5..6]=cx x16  [7..8]=cy x16  [9..10]=radius  [11]=rot octant
    [12..13]=area_ratio x1000  [14..17]=area u32
T4: [5..8]=f0 mHz  [9..12]=f1 mHz
T5: [5..6]=hf_ratio x10000  [7..8]=zero_cross
T6: [5]=win shift  [6..7]=best sadn  [8..9]=still sadn
```

Judgment codes: T1 0=SAME 1=DIFFERENT; T2 0=SAME_SURFACE 1=DIFFERENT;
T3 0=CIRCLE 1=SQUARE 2=TRIANGLE; T4 0=SAME 1=HIGHER 2=LOWER;
T5 0=PURE 1=BRIGHT 2=DARK 3=RICH; T6 0..7=N NE E SE S SW W NW, 8=STILL.

Disposition gate (frozen): INSTALL iff confidence >= 600; NOTE iff >= 300;
else DISCARD. Calibrated on the frozen 370 primary: 155 installed, 0 false.

### Task mechanisms (all calibrated against `src/calib.py`, integer ports)

- **T1 colordisc** (128x64 RGB, 8-byte header): left vs right 64x64 mean-RGB
  squared euclidean distance d2; SAME iff d2 < 40.
  conf = 1000*|d2-40|/(|d2-40|+40).
- **T2 colorconst** (128x64 RGB): two-pass grayscale Pearson r x1000 between
  panels; SAME_SURFACE iff r >= 900. conf = 1000*|r-900|/(|r-900|+100).
- **T3 shapetrans** (96x96 RGB): largest 4-connected component of gray>=150;
  shape = nearest anchor of area_ratio = A/(pi*R^2) x1000
  (CIRCLE 1000, SQUARE 637, TRIANGLE 414); rotation octant from second
  moments; conf from distance to the midpoint boundary of the two nearest
  anchors, scale 200.
- **T4 pitchdisc** (16kHz PCM, tone 6400 + gap 1280 + tone 6400): f0 per tone
  by autocorrelation on the stationary middle (lags 16..100), strong
  subharmonic division, parabolic interpolation; SAME iff |f1-f0|*200 < f0.
- **T5 timbredisc** (16kHz PCM, 12800 samples): high-frequency energy ratio
  x10000 + zero-cross count; PURE/BRIGHT/DARK/RICH by ratio bands.
- **T6 motiondir** (8 frames 64x64 RGB, 12-byte header): frame-0 vs frame-7
  SAD over 8 directions x 9 shifts; STILL iff best-shift SAD within 10% of
  the still SAD.

Ops are counted explicitly (`op_add`) per task; the counter is part of the
trial record (B3).

## 2. Fork A — replay/witness emission (`zag/emit.zag`, `zag/main_a.zag`)

The emitter re-presents the EXACT cited source bytes. Cited spans (payload
only, headers excluded):

- T1/T2: whole RGB payload [8, blen)
- T3: whole RGB payload [8, blen)
- T4: tone1 [8,12808) + tone2 [15368,28168) — the 0.16 s gap is excluded
- T5: tone [8,25608)
- T6: all frames [12, blen)

Two deliberately separate copy loops (`emit_cited` = the witness copy,
`emit_build` = the emission) so the KB-E1 byte-equality check is not
vacuous. `equal=1` in the TSV means artifact bytes == cited bytes.
Artifacts are written with the fixture's container header (T4 header patched
to count=12800, tones concatenated).

## 3. Fork B — generative renderer (`zag/render.zag`, `zag/tables.zag`, `zag/main_b.zag`)

The renderer sees ONLY the 64-byte percept + static integer LUTs
(`tables.zag`, generated by `src/gen_tables.py`, byte-identical regen
verified). It never sees fixture bytes.

- T1: uniform 128x64 panels from stored meanA/meanB.
- T2: uniform gray 128x64 panels from stored mean luma (chroma discarded).
- T3: re-rasterized canonical shape (circle/square/triangle) at stored
  centroid/radius/octant on mid-gray; triangle = apex-up equilateral rotated
  by octant*45deg from `tric`/`tris` tables.
- T4: two 6400-sample tones at estimated f0 (mHz), canonical harmonic
  profile [1000,300,150], 20 ms raised-cosine ramps, phase-accumulator
  synthesis from the 256-entry sine LUT. Tones concatenated (no gap).
- T5: 12800-sample 440 Hz tone with the canonical harmonic profile of the
  judged class (`tmb_init`: PURE/BRIGHT/DARK/RICH x1000 amplitudes).
- T6: black 8x64x64 frames + moving 8x8 white square along the judged
  direction with the stored winning shift (STILL = static centered square).

Divergence is measured by `div_diff`: RLE of (start u32, len u32) runs where
the render differs from the cited source bytes; reported as
div_runs/div_bytes/div_first_start/div_first_len in the TSV. Every divergent
byte is declared in the human briefs (KB-E7).

## 4. Trial driver, TSV, ledger

`main_a.zag` / `main_b.zag` (`main_b` derived from `main_a` by
`src/derive_b.py`; the percept path, truth handling, and ledger are
identical). Modes: single trial or `batch mixed <list>` (lines are
`task lab/relative/path`, resolved against the lab-root argv). `emit` runs
the emitter/renderer; `noemit` runs the percept only — the percept bytes are
identical either way (B4/KB-E5).

TSV (fork A, 15 cols): trial seq task fixture truth judgment conf disp
correct percept_hex ops cited_sha artifact_sha equal ledger_hash.
TSV (fork B, 17 cols): ... ops render_sha div_runs div_bytes div_first_start
div_first_len ledger_hash.

Ledger: per trial, `hash = sha256(seq\ttask\tfixture\tjudgment\tconf\tdisp
\tpercept_hex\tprev_hash)`; appended with the hash. Verified with
`src/verify_ledger.py` (chain + recomputation).

## 7. Lessons (znc)

- `_zag_strcmp` on non-NUL-terminated `[]u8` is unreliable; byte-compare hex
  digests in a loop (caught: KB-E1 `equal` read 0 on identical hashes).
- `tables.zag` ramp LUT: raised-cosine denominator is 320, not 319
  (round(1000*(1-cos(pi*i/320))/2)); verified byte-identical regen.
- Batch line parsing must not index `lb[n]`; restructure loops instead of
  relying on `&&` short-circuit.
