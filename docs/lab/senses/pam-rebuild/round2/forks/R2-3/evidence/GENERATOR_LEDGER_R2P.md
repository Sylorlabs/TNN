## Scope note

R2A (r2n_/r2a_) is generated by a parallel crew with their own frozen-seed
generator in the same directory. This generator covers R2P only (stream 600+),
which no other crew generates. No byte overlap.

## Per-task designs (all verified at generation time)

Every pair is verified against the naive front-ends in
`forks/R2-3/src/mirror/judge.py` (the exact algorithms the Zag reference gate
ports): **fooled** = naive(F) != truth, **clean** = naive(G) == truth.
Corruptions are deterministic or rejection-sampled in fixed order. A pair that
cannot be verified is never written (generator asserts).

### T0 colordisc (200 pairs, 60 frames 16x8)
- mode 0 (truth DIFFERENT): F = metamer patch pair (RGB eucl < 15, ΔE ≥ 2.3)
  → naive SAME. G = same base, second patch RGB eucl ≥ 40 → DIFFERENT.
- mode 1 (truth SAME): F = same base, left d65 / right warm → naive DIFFERENT.
  G = identical d65 patches → SAME.

### T1 colorconst (200 pairs, 60 frames 16x8, 8x8 panels)
- mode 0 (truth DIFFERENT): F = two different photo crops, both under the SAME
  extreme illuminant (xblue or xred, 0.55 exposure), rejection-sampled until
  panel-mean d2 < 900 → naive SAME_SURFACE. G = same crops under d65 →
  DIFFERENT (verified in the search loop).
- mode 1 (truth SAME_SURFACE): F = same photo, panels under xblue/xred 0.55 →
  naive DIFFERENT. G = same photo d65/d65 → SAME_SURFACE.

### T2 shapetrans (200 pairs; F 96x96 full frame, G 48x48 quadrant)
- Canonical pose (rot 0, centered), flat gray backgrounds.
- **Documented deviation from R2_FIXTURE_SET.md "occlusion/distractor":**
  those families do not reliably flip a template-matching front-end
  (occlusion fools 2/3 classes at 13-20%/try; distractor blob 0-5%/try;
  triangle never flips under horizontal bars). **Tonal inversion**
  (photographic negative: mode 0 bg200/fg10, mode 1 bg255/fg0) fools 3/3
  classes deterministically by attacking the brightness-threshold feature
  band. Empirical basis recorded here; the ≥90% withhold bar is unaffected.
- F = inverted target → naive misclassifies (verified). G = clean target on
  flat gray 60 → naive correct (bit-identical to prototype).

### T3 pitchdisc (200 pairs, 2.0s @16kHz)
- F = toneA (steady f0, 0-0.9s) + gap + toneB (glide f0→f0×1.008 or ×0.992,
  0.98-2.0s) → zero-crossing front-end reads SAME (fooled).
- G = toneA + gap + toneB' (steady f1) → HIGHER/LOWER (clean).
- Truth: mode 0 HIGHER, mode 1 LOWER.

### T4 timbredisc (200 pairs, 2.0s @16kHz)
- mode 0 (truth DARK): F = DARK with 3rd harmonic ×4.5-7.0 → brightness crosses
  227 into RICH (fooled). G = clean DARK → DARK.
- mode 1 (truth BRIGHT): F = BRIGHT with harmonics k≥3 ×0.3-0.5 → brightness
  drops below 346 into RICH (fooled). G = clean BRIGHT → BRIGHT.
- (Calibration: weakening the fundamental *increases* brightness; cutting highs
  decreases it. Thresholds [186,227,346], order PURE<DARK<RICH<BRIGHT.)

### T5 motiondir (200 pairs, 50 frames 24x24)
- mode 0 (truth = dir): F = reversed clean video → naive reports opposite
  (fooled). G = clean video → dir.
- mode 1: F = dim base (0.30 contrast) + dominant ghost (different photo,
  1.6 contrast, alpha 0.80, different dir) → naive reports ghost dir
  (fooled; base-alone at 0.30 verified 20/20 correct, so the ghost causes it).
  G = clean video → dir.

## Determinism

All randomness from the frozen splitmix64 streams. Numpy used only for
vectorized arithmetic in the harness import, never for randomness. Re-running
the generator reproduces byte-identical fixtures (verified by MANIFEST).

## Files

- `r2p_<task>_<idx:03d>.pair` — 64-byte header + F bytes + G bytes.
- `r2p_<task>_<idx:03d>.pair.truth` — truth=<value>, family, scene, note.
- `MANIFEST.r2p.sha256` — SHA256 of all pair bytes.
