## Phase-0 diagnosis (frozen input to this design)

White-box analysis of FS-E2's independent implementation
(`forks/FS-E2/src/fs2_form.zag`, `f_shapetrans`: 96x96 bbox fill-ratio ->
class, bins CIRCLE>=700, SQUARE in [550,700), TRIANGLE<550, default SQUARE)
on the frozen r2n shapetrans set (n=1296):

| error mode | count | mechanism |
|---|---|---|
| SQUARE -> CIRCLE | 113 | near-axis-aligned squares: bbox fill >= 700 |
| SQUARE -> TRIANGLE | 139 | near-diagonal squares: bbox fill < 550 |
| CIRCLE errors | 0 | fill in [750,825], rotation-invariant |
| TRIANGLE errors | 0 | fill in [461,548], rotation-invariant |

Root cause: the bbox fill-ratio feature is **rotation-variant for squares**.
Measured fill over the 432 square fixtures spans **[499, 1000]**
(median 588): a rotated square's bbox area grows as
(|cos theta|+|sin theta|)^2 while its area is fixed, so no single fixed
bin captures squares at all rotations. Circles (fill ~= 0.785, bbox always
the circumscribed square) and triangles (fill ~= 0.5) are rotation-invariant
under this feature, hence 432/432 each.

Note: R2-16's CH-SHP-2 (central-moment challenge) achieved 0 FI on
shapetrans — the CHALLENGE layer is solved. This crew's layer is formation
(first-pass percept judgment), a different problem; the fix below is a
formation-layer change only.

## The improved formation rule (FROZEN — exact specification)

Replace the rotation-variant fill-ratio feature with the rotation-invariant
normalized second central moment

    phi1 = (mu20 + mu02) / mu00^2

(Hu's first invariant; mu are the standard central moments of the
foreground mask). Integer-exact formulation, no floating point:

`f_shapetrans_v2(img, fo) -> judgment id` (0=CIRCLE, 1=TRIANGLE, 2=SQUARE):

1. Foreground mask: pixel value > 180 over the 96x96 frame at f_off
   (threshold UNCHANGED from FS-E2).
2. Accumulate over mask pixels, x,y in [0,96), all i64:
   m00 = count; sx = SUM(x); sy = SUM(y); q = SUM(x^2+y^2).
3. If m00 < 200 -> return 2 (SQUARE). Default UNCHANGED from FS-E2.
4. num = m00*q - sx*sx - sy*sy; den = m00^3 (den > 0 by step 3).
5. t5 = (num*100000)/den, integer division.
   Overflow audit: m00 <= 9216 (whole frame) -> num <= 1.53e12,
   num*100000 <= 1.53e17 < 2^63-1. No overflow for any input.
6. If t5 < 16218 -> return 0 (CIRCLE).
7. Else if t5 < 17798 -> return 2 (SQUARE).
8. Else -> return 1 (TRIANGLE).

Threshold derivation (frozen): phi1 measured on the FS-E2 Phase-0 r2n set
(n=1296, float prototype): CIRCLE max 0.15925; SQUARE [0.16512, 0.16789];
TRIANGLE min 0.18807. Cuts at bin midpoints 0.16218 and 0.17798, x1e5 ->
16218 / 17798. t5 = floor(phi1*1e5); nearest class edge is >= 290 units
away, >> 1-unit truncation error. The integer rule scores 1296/1296 on the
Phase-0 set (analysis prototype; the Zag build is scored below).

The other five formation functions (colordisc, colorconst, pitchdisc,
timbredisc, motiondir) are carried over with byte-identical logic from
FS-E2's `fs2_form.zag` — no intended change.
