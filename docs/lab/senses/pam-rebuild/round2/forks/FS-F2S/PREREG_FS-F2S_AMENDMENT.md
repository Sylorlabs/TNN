# PREREG_FS-F2S_AMENDMENT.md — generator citation correction (PRE-RESULTS)

**Date:** 2026-09-24. **Status:** FROZEN. Committed before ANY eval results
exist (no fresh-draw fixture has been scored; the only scored data so far
is the no-regression + consistency re-runs on frozen sets, which this
amendment does not touch).

## What changes

PREREG_FS-F2S.md Bar (a) cites `fixtures/gen_r2a.py gen_shapetrans_normal`
as the fresh-draw generator. That file is the LEGACY harness generator; the
frozen R2A battery the controls come from (`forks/R2-7/fixtures_R2A/`,
measured by FS-E2 Phase 0) was built by the R2-7 generator. A fresh draw of
"shapetrans controls" must come from the same distribution as the controls.

**Corrected Bar (a) fixture spec:** fresh deterministic draw, n = 1296,
generated by the FROZEN R2A battery generator
`forks/R2-7/src/gen_r2a.py`:

- `rng = Rng(stream_seed(MASTER, STREAM_NORMAL + 2, i))`,
  MASTER = 20260923, STREAM_NORMAL = 400, task index 2 = shapetrans
- `(f, g, truth) = gen_shapetrans(rng, family=0, idx=i)` for
  i in **5000-6295** inclusive (disjoint from the 0-1295 Phase-0 indices;
  family 0 = normal; class = idx % 3, hence 432/432/432 balanced)
- packaged with the frozen `write_r2fx(path, task=2, index=i, family=0,
  f_bytes, g_bytes)` + `write_truth` (truth from the generator's returned
  truth string)
- output: `forks/FS-F2S/evidence/eval/fresh_shapetrans/r2n_shapetrans_<i>.r2fx`
  (+ `.truth` sidecars); SHA-256 manifest committed as
  `evidence/eval/fresh_shapetrans_MANIFEST.sha256`

## What does NOT change

The improved formation rule (exact spec), bars (a)/(b)/(c) thresholds,
method, and verdict rule from PREREG_FS-F2S.md are UNCHANGED. Only the
identity of the frozen generator used for the fresh draw is corrected.

## Reason this is pre-results, not a bar relaxation

No bar-(a) fixture has been judged or scored by any binary. The .img files
generated earlier from the legacy generator were never packaged as R2FX,
never listed, never scored, and are deleted unexamined. The correction is
mechanical (same distribution as the controls) and can only make the bar
fairer, not easier: the R2-7 family-0 distribution is exactly what the
85% bar was calibrated against.
