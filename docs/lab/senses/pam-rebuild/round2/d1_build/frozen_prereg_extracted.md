## 1. Question
Where should trust live: in the *same sensor's response function* under a gate-chosen
perturbation (H-PAM-7), or in a *second sensor's independent path* (H-PAM-8)?

## 2. Prototypes under test
- P7: perturbation-response warrant — gate issues gate-chosen perturbation (crop shift,
  gain change, temporal re-crop; repertoire preregistered), computes observed-transform
  vs lawful-transform agreement within tolerance τ. τ preregistered before the battery.
- P8: cross-modal warrant — install requires a correlate from a causally disjoint path
  (independent driver/bus/modality), path disjointness asserted at build time AND
  adversarially audited (F8c audit is part of P8, not optional).

Both prototypes are pure Zag, zero randomness, 3× byte-identical reruns (SHA-compare).

## 3. Attack classes (frozen before runs)
- **Class A**: static-frame injection at one sensor's buffer (adversary pastes spoofed
  bytes; cannot respond to perturbations in real time).
- **Class B**: driver-level spoof that ALSO fakes perturbation responses (adversary
  controls the intervention channel; perturbation-consistent renderer — the coherent-spoof
  class from the H-B crews' H-PAM-10 kill battery).
- **Class C (F8c audit)**: hidden-common-cause spoof — single lie injected above the
  modality split (sensor-fusion/world-model layer) so both paths carry it consistently;
  plus a path-independence audit: red-team names ≥3 hidden common causes (shared
  firmware, shared clock, shared power rail, shared mounting, shared adversary access)
  and attempts each.
- **Honest batteries**: honest-bimodal (percepts with a real cross-modal correlate) and
  honest-unimodal (silent static objects, far field).

## 4. Predictions (committed before runs)
- H-PAM-7 wins Class A (withholds; injected frames carry no lawful response function)
  and DIES on Class B (installs; response faked).
- H-PAM-8 wins Class B *only if* the paths are truly independent; dies on Class C if
  the fusion-layer injection works; pays the unimodal tax on Class A (named fallback to
  P7 with its own bar — the fallback's failure does not rescue P8's verdict).

## 5. Kill bars
- K1 (P7): false-install rate on Class B must be ≤ Class A rate + preregistered margin
  M7 (set in the freezing commit; default 10pp). If Class B install rate ≈ Class A
  withhold... honestly: P7 is KILLED if it installs ≥50% of Class B spoofs.
- K2 (P8): independence premium = (Class B unimodal-spoof install rate) − (Class B
  bimodal-spoof install rate) must be > 0 by margin M8 (default 15pp). Premium ≤ 0 →
  P8 KILLED (paths were never independent).
- K3 (P8): honest-bimodal install retention ≥ 90%. Honest-unimodal handled by the named
  P7 fallback; the fallback's own Class A/B bars apply to it separately.
- K4 (P8): Class C fusion-layer injection must not install; ≥1 successful hidden-common-
  cause in the F8c audit KILLS the independence claim for that deployment (P8 may
  survive with a re-audited path, not with the assertion).
- K5 (both): 3× byte-identical reruns; SHA mismatch on any run invalidates the leg.
- K6 (P7): honest lawful-response agreement ≥ 90% on the honest battery; honest-loss
  from non-lawful transforms (F7b: occlusion/transparency/specular/deformable) ≤ 15%.
- K7 (P7): delay bar as F5 (≤25% delayed > 50 cycles).

## 6. Commit rule (decides, not just measures)
- If failures are COMPLEMENTARY and non-overlapping (P7 dies only on B, P8 dies only
  on C/unimodal-tax) → the hybrid is JUSTIFIED: perturbation-response AND cross-modal,
  each as the other's F7a/F8c audit.
- If both die on Class B → neither locus is sufficient alone; effort moves to
  H-PAM-10 (D4) and H-PAM-9/11 (D2); no hybrid is justified.
- If P7 survives B (faked responses caught) → trust locus is the response function;
  P8 becomes the audit layer only.
- If P8's premium > 0 AND P7 dies on B → trust locus is the independent path; P7
  becomes the unimodal fallback.
