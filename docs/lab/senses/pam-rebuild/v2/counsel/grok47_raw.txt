The hole is not “low confidence.” It is that two organs can share one sustained wrong reading and both emit a high PASS, so agreement adds no new evidence. Trial 1145 and the zero-bit result already forbid deciding from the judgment pair. The 74.8% figure forbids fixing the miss of those 278 by moving the gate. Anything below has to read raw bytes again, on a schedule that is not a function of the candidate judgment, and it has to be historical.

1. Fixed disjoint stripes, agreement only across stripes.
(H) Split every input on a frozen offset rule into two non-overlapping byte stripes. Organ A sees only stripe 1; organ B only stripe 2. Neither receives the other’s judgment, confidence, or margin. A corroborating install requires both to PASS the same label. Same-stripe double PASS is not corroboration. Attention may later re-read, but the corroboration pair stays on the fixed partition.
(E) The six timbredisc wrongs agree because both looks consumed the same bytes. Ceiling (1) is respected: the predicate is over two raw views, not over a judgment and a function of that judgment. Ceiling (2) is respected: no trial is won by dominating conf, mrgF, strong, or agree. V2-B is not revived; nothing treats “flips under perturbation” as truth. Novelty weakness remains if a spoof is written into both stripes.
(K) Build a sealed set of 200 items in which each stripe alone is sufficient for the same wrong RICH label, plus a matched set of 200 where the truth is stripe-split. Kill if wrong dual-PASS install rate exceeds 5%, or if correct dual-PASS on the matched set falls below 70% of V2-D’s current correct installs.

2. Judgment-blind deliberate re-sense.
(H) On any candidate install, discard conf, mrgF, strong, and agree before the second look. A fixed attention map, a pure function of the raw bytes only, selects at most 64 offsets. A separate organ, trained and weighted apart from the first, re-reads only those offsets plus a frozen neighborhood and must emit the same label to install. If the map’s offsets have already been used by the first organ, force the complement. No install from two full-frame PASSes.
(E) This is the program-law move: the brain chooses what to re-inspect and will not install an untested percept. It does not use the interventional sensitivity V2-B showed an attacker can set. It also dodges ceiling (1), because the second percept is not a function of the first judgment. It does not claim trial 1145 loses a pointwise score fight; that trial never becomes installable on dominance.
(K) Freeze the attention map. On the 43 ACCEPT_INSTALL trials (the 9 false and the 34 others), replace unattended bytes with noise that preserves the attended span, and the reverse. Kill if the false-install rate on those 9, under span-preserving edits outside the attended set, stays above 2/9, or if correct installs among the 34 fall by more than 8.

3. Residual organ trained only where the primary was wrong.
(H) Keep the current sense as organ A. Freeze it. Train organ B only on raw bytes of trials A got wrong, with a diversity constraint: a joint wrong on the same label is a training failure even if each loss looks small. At runtime B never sees A’s judgment. Corroboration is “A PASS and B PASS,” and only B is allowed to move a repeated A error into install. B’s own sole PASS never installs.
(E) The timbredisc cluster is a shared error, not six independent witnesses. Ceiling (1) holds only when B is computed from A’s judgment; here B is fit to raw residuals. Ceiling (3) is untouched, so this hypothesis is not a claim about the 278. The 53% novelty result is the live risk: B can memorize A’s old mistakes and still miss a new family.
(K) Replay seq 10983–11192 and a 12-family sealed set disjoint from B’s training ids. Kill if more than 1 of those 6 wrong joint-PASSes survives, or if B’s joint-wrong rate on the sealed families exceeds 10%, or if RK-3 falls more than 3.0 points from 88.48%.

4. Context-diverse quarantine, not count of agreements.
(H) A PASS goes to a quarantine slot keyed by label plus a hash of a frozen “context” region that is not the region the sense used for the label. Install only after M=3 quarantined hits of that label whose context hashes are pairwise at least D bytes apart, and whose deliberate re-sense of one canonical window matches. Six identical high-conf PASSes on near-duplicate contexts count as one. A later hit that matches an already-installed raw prototype can revise only by the same rule, not by outscoring the incumbent.
(E) Directly targets the observed failure mode: six agreeing wrongs in one band (conf 701–718, mrgF 353–382). Repeating a spoof does not mint new evidence. Ceiling (2) is respected because nothing installs by beating the incumbent on a single trial’s axes. Historical, deterministic, byte-identical.
(K) Adversary battery: 100 labels × M contexts, each pair separated by ≥ D, each context independently producing the same wrong PASS at conf≥701. Kill if install rate on that battery exceeds 5%. Also kill if, on ordinary RK-3 recurring-correct items, install recall drops more than 10 points below the current corroboration rule.

5. New sense aimed at the 278, gate held fixed.
(H) Do not retune the PASS threshold. Add a heavy second-pass sense that runs only when the current sense is high-confidence but not PASS (the 278’s situation). It may use a wider window, a different byte grouping, or a prototype match against already-verified installs. It either emits PASS under the existing numerical bar or it abstains. It cannot raise confidence of an already-PASS item into install by itself; corroborated-wrong handling stays with hypotheses 1–4.
(E) Ceiling (3) is arithmetic about this sense: 824/1,102 never become PASS, so no gate reaches them, and 85% is unreachable by gate design. Changing the sense is the only legal way past that ceiling. It does not contradict the arithmetic. It also does not touch the zero-bit judgment channel.
(K) Freeze RK-3 and the current gate numbers. Kill unless at least 100 of the 278 become true PASS, the new false-PASS count on the 12 sealed families is at most 2 points above today’s false-PASS rate, and full RK-3 does not drop below 88.48%.

6. Historical joint-error bins, as a refusal only.
(H) Log every dual PASS by a coarse raw-byte bin (fixed hash prefixes, not conf). If a bin’s past joint-wrong rate exceeds 2%, corroboration in that bin is disabled until a deliberate re-sense from hypothesis 2 passes. No bin ever grants install by being historically clean; clean only means “not refused.”
(E) Explains the calibration lie: 0.6% claimed versus 20.9% false on 9/43 UNRESOLVED accepts. Refusal is historical, so trial 1145 cannot bully an install. This does not beat ceiling (3). Novelty is fatal if treated as a positive signal: the 53% novel-family result says a quiet bin is not evidence.
(K) Hold out the 12 sealed families entirely from the log. Kill if any “historically safe” bin still dual-installs a wrong novel at above 5% of that family’s trials. Also kill if refusal on the logged timbredisc band fails to block at least 5 of the 6 known wrong joint-PASSes.

7. Scope challenge to the ceilings, not a denial.
(H) Keep ceiling (1) and (2) as stated. The zero-bit proof covers predicates of a judgment and a deterministic transform of that judgment; it does not cover a second raw read. The dominance proof covers the axes actually logged (conf, mrgF, strong, agree); it does not say no future raw measurement can differ on trial 1145. The 74.8% ceiling covers the current PASS predicate only. The mechanism that uses this reading is already in 2 and 5: new raw evidence, never a richer function of the old judgment.
(E) This challenges the over-reading of the proofs, not the measurements. The six wrong joint-PASSes and the 9/43 false accepts stay explained: those paths were still judgment-side or same-view. V2-A, V2-B, and V2-C stay dead.
(K) If a builder smuggles the second look through the first judgment (any feature that is constant when the raw attended bytes change but the judgment stays), re-run the miniature Zag proof. Kill on the first predicate that still scores 0.0000 bits, or if trial 1145 installs on old axes alone.

Ranking. Highest expected value is 2, then 1: both attack the correlated-corroborator hole with evidence that is not a function of the bad judgment, and both match the conscious re-sense rule without reviving V2-B. Hypothesis 3 is next if training cost is acceptable; it is the only one that aims the second organ at the primary’s actual mistakes, but the 53% novelty figure can kill it. Hypothesis 5 is the only serious attempt on the gate ceiling and should run in parallel, not instead; it does not close the hole. Hypothesis 4 is worth a cheap battery because it specifically nullifies repeated near-duplicate wrongs, and it dies cleanly if an attacker can buy M diverse contexts. Hypothesis 6 is a safety interlock, not a path to 85%. Hypothesis 7 is a constraint on the others, not a build.
