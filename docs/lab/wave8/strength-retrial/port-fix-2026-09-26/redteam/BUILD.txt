# Building the blind red-team binary
Pinned toolchain: ~/workspace/tnn-lab/toolchain/bin/znc_linux_x86_64_abed8aa1

The driver `fix_rt.zag` does `@import("strength_checker.zag")`, which
resolves relative to the driver's own directory. To rebuild the blind
binary from this tree:

  mkdir build && cd build
  cp ../implementation/strength_core.zag .
  cp ../implementation/strength_checker.zag .
  cp -r ../implementation/substrate .
  cp ../redteam/fix_rt.zag .
  ~/workspace/tnn-lab/toolchain/bin/znc_linux_x86_64_abed8aa1 build fix_rt.zag -o fix_rt_bin

Run: ./fix_rt_bin G <tokens...>   (see BRIEF.md)
The binary is deterministic; run every sequence twice.
Do NOT commit the built binary or .zag-cache/ back to the repo.
