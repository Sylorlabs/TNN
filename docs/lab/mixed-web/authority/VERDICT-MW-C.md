## What was built

- `authority/src/mw_sense_c.zag` — pure-Zag PRIMARY mechanism (zero RNG, no timestamps):
  primary-domain detection (domain label == question token, len ≥ 4, exactly one
  distinct domain), newest-assertion selection (max recency, older same-domain
  assertions superseded), and the four frozen fire conditions. When PRIMARY does
  not fire, control falls through to the frozen `mw_deliberate` verbatim, so the
  ledger is byte-identical to arm B's. A structural no-override guard
  (`mw_b_probe`) runs the frozen arm-B logic on a scratch clone — w's ledger
  untouched — and if arm B would converge, arm B's verdict stands: PRIMARY can
  only ever convert a withhold, never override a convergence.
- `authority/src/mw_cases_c.zag` — generated by `authority/gen/gen_mw_c.py` from
  the frozen envelopes (`live/*.json`) and golds (`golds.json`); per-question
  feeds carry the same rows as arm B, deliberation is `mw_deliberate_c`.
- `authority/src/mw_trial_c.zag` — driver (`mw_trial_c c`).
- `authority/verify_mw_c.py` — independent oracle: fresh reimplementations of
  PREREG §4, the literal M1 PRIMARY rule, the PRIMARY citation format, and the
  hash-chained ledger head recomputation.
- `authority/src/mw_sense.zag`, `R33_NATIVE_SHA256_V2.zag`, `R33_NATIVE_IO_V1.zag`
  — byte-identical copies of the frozen mixed-web sources (sha256-verified at
  copy time), so the authority package builds standalone from its own `src/`
  with the pinned toolchain; the originals are untouched.

## The prereg's internal contradiction (M1 condition 4 vs M3 expectation)

M3 expected PRIMARY to fire exactly on R03. Applied literally to the actual
frozen envelope, M1's own condition 4 forbids it:

- R03: exactly one primary domain (`fifa.com`, label `fifa` == token `fifa`) ✓
- Its newest answered assertion: **Spain@2026**, recency 2026 ≥ 2000 ✓
- 2026 == global max recency over all candidates ✓
- Condition 4: **fails**. No other domain corroborates Spain, and
  `sofascore.com` asserts **Argentina@2026** — a DIFFERENT answer at that same
  max recency. The literal M1 i.e. ("no other domain asserts a DIFFERENT answer
  at that same max recency"), the stale-safety parenthetical ("a primary domain
  whose latest word is contradicted by equally-new evidence elsewhere does not
  fire"), and the "face no equally-new contradiction" summary all agree:
  PRIMARY does not fire on R03.

The M3 expectation rested on a misreading of the envelope: `golds.json`'s R03
rationale claims "Argentina answers are stale pre-2026 sources," but the frozen
envelope contains sofascore.com's Argentina assertion dated **2026**. The sealed
evidence rules, not the rationale. The rule was implemented exactly as frozen —
not weakened to rescue the expectation.
