# REPRODUCE.md — third-path trial (TP1)

## What this is

Frozen-corpus head-to-head of three third paths (T1 gated loose, T2
SUSPECT/defer, T3 one-brain deliberation) on the 220 envelopes reused
from round 3 (180 Block U + 20 S8 + 20 G2). Prereg
`44afdbefc168edddcae50e9dd91eac12cd9fa156` was committed before any trial
run; nothing below was edited after the runs.

## Layout

- `src/tp_trial.zag` — frozen trial logic: envelope state, shape
  classifier, T1/T2/T3 policies, 4 thresholds, SHA-256 chained ledger.
  Pure Zag, no RNG.
- `src/tp_cases.zag` — GENERATED (see `analysis/gen_tp_cases.py` note
  below): the 220 frozen envelopes as run functions + main. Do not
  hand-edit; regenerate from `evidence/tp_data.json`.
- `src/R33_NATIVE_SHA256_V2.zag`, `src/R33_NATIVE_IO_V1.zag` —
  byte-copies of the round-3 hash/IO substrate.
- `oracle/tp_oracle.py` — independent recomputation of every decision
  and ledger head from `evidence/tp_data.json`. Exit 0 = all 2,640
  decisions + 3 heads + shape counts verified.
- `analysis/tp_analysis.py` — EV / wrong-install / S8 / G2 / T2-frontier
  tables from `evidence/run0.log`.
- `evidence/tp_data.json` — the 220 frozen envelopes extracted from the
  round-3 `manifest_r3.txt` (twin/latent formulas re-verified: 0
  mismatches). `evidence/idmaps.json` — domain/answer id maps.
- `evidence/run0.log` — canonical run output (2,640 `P|` decision lines,
  3 `H|` ledger heads, shape/sequence counts). `evidence/SHA256SUMS` —
  hashes of all five runs (byte-identical).

## Reproduce

Toolchain: `~/workspace/tnn-lab/toolchain/bin/znc_linux_x86_64_abed8aa1`
(pinned build; `@import` resolves relative to CWD, so build from `src/`).

```sh
cd docs/lab/mixed-web/authority/third-path/src
~/workspace/tnn-lab/toolchain/bin/znc_linux_x86_64_abed8aa1 tp_cases.zag -o tp_run
for i in 0 1 2 3 4; do ./tp_run > run$i.log; done
sha256sum run*.log   # all five must equal d57fda225db8d54201ca443e6e39716aba4e5ca5a97683128a49ed61b432d1d9
```

Then, from `third-path/`:

```sh
python3 oracle/tp_oracle.py    # expect: ORACLE PASS
python3 analysis/tp_analysis.py
```

`tp_oracle.py` and `tp_analysis.py` resolve `evidence/` relative to the
`third-path/` working directory (see the `EV`/`HERE` header in each
script). `tp_cases.zag` was generated by
`~/workspace/third-path/gen_tp_cases.py` from `evidence/tp_data.json`;
`tp_data.json` was extracted from the frozen round-3 manifest (script:
`~/workspace/third-path/extract_tp_data.py` logic, twin/latent formulas
re-verified with 0 mismatches before generation).
