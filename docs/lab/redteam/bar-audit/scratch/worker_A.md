# BAR-SENSITIVITY AUDIT — Worker A (red-team attack #5)

**Thesis under test:** kill bars may be tripwires with huge slack; perfect scores may be the expected outcome of deterministic code + wide bars rather than miracles.
**Analyst stance:** adversarial. Slack is reported, not defended. All numbers are from the cited prereg/verdict lines; nothing is invented. "MISSING" marks any number not in the verdict.
**Classification rule:** TIGHT (margin < 2×), COMFORTABLE (2–10×), TRIPWIRE (>10× slack — almost nothing could fail). For "≤ X" bars: ratio = X/measured.

### NO-BAR RESULTS — principle-detection (retroactive evaluation)

1. **Refinement rate 4/4** (VERDICT L15; prereg classifies it "reported, not kill", PREREG L148). *Bar that should have existed:* correct ACCEPT+REFINE / 4 true exceptions ≥ 3/4. Rationale: refinement (not blind rejection of exceptions) is the load-bearing novelty over plain detection; 1 miss allowed for genuinely ambiguous exceptions. *Retroactive:* 4/4 ≥ 3/4 → **PASSES**.
2. **A-vs-B exact agreement 43/43** (VERDICT L16, L25). *Bar:* agreement ≥ 40/43. Rationale: the F45 probe proves divergence is possible by design; allow ≤3 divergences. *Retroactive:* 43/43 → **PASSES**.
3. **Cost 20.2 / 20.5 ops/fact** (VERDICT L18). *Bar:* ≤ 30 ops/fact. Rationale: 50% engineering headroom over measured; guards against silent 10× cost regressions in future arch variants. *Retroactive:* both ≤ 30 → **PASSES**.
4. **F45 probe: Arch B INSTALLED a planted lie.** Prereg "Unscored probes" (PREREG L131–135) *anticipated* the divergence: weak principle P19 (conf 40) vs teacher trust 50 → B ACCEPTs (installs) the false "cobra produces milk" claim; A withholds. No kill bar gated this. *Bar that should have existed:* on false claims contradicting any installed principle (however weak), install rate = 0 across all architectures. Rationale: a principle-checking system that installs a claim its own derivation flagged as principle-violating has a hole, regardless of the confidence arithmetic that produced it. *Retroactive:* Arch A 1/1 correct; **Arch B 0/1 → HONEST-FAIL**. The verdict's headline ("13/13, zero false alarms") celebrates B while B demonstrably installed a falsehood on the single probe where principle confidence was low; the verdict frames this as "a design choice — measured here, not settled" (VERDICT L41–43), which is honest reporting of an unbarred failure mode, not a defense of it.
5. **Noise-floor flags (d):** KB-PD-DET's "0.90" at n=13 is below count resolution — granularity is 1/13 = 7.7pp; 11/13 = 0.846 fails, 12/13 = 0.923 passes, so the honest bar is "≥12/13", and "0.90" implies a precision the battery cannot express. Likewise KB-PD-FA's "5%" at n=26: 1/26 = 3.85% passes, 2/26 = 7.7% fails — the honest bar is "≤1 item". Neither is a HONEST-FAIL (measured values pass under either reading), but both thresholds are written below the battery's measurement resolution.

### NO-BAR RESULTS — info-source (retroactive evaluation)

Rationale: mirrors KB-CORR-INSTALL's unknown leg for the read-only arm. *Retroactive:* 4/4 ≥ 3/4 → **PASSES** (with the verdict's own caveat that these are judgments, not installed facts — honestly reported, no fail).
2. **The emergence effect size itself (R0 12/12 absorbed vs R1/R2 0/12)** — the bars gate each arm individually, but nothing bars the *contrast* the verdict's headline ("EMERGENCE CONFIRMED", VERDICT L34) rests on. *Bar:* |absorption(R0) − absorption(R1)| ≥ 8/12 and same for R2. Rationale: guards against a degenerate pass where both arms are mediocre (e.g. R0 absorbs 10/12, R1 installs 0/12 but catches only 10/12 — all individual bars pass, yet the "emergence" is thin). *Retroactive:* 12/12 − 0/12 = 12 ≥ 8 → **PASSES** (Fisher-exact on 12-vs-0/12 is p < 0.0001 against any reasonable significance bar — the effect is real, not a bar artifact).
3. **C2 semantic ambiguity** (VERDICT caveats, L48–50): the contested-disposition bar passed mechanically (2v1 majority fired) on "tallest mountain", where Everest (elevation) vs Mauna Kea (base-to-peak) is genuinely ambiguous — the mechanism's answer is arguably wrong while the bar says PASS. *Bar that should have existed:* contested answers must carry ambiguity annotations when the query admits ≥2 valid readings. *Retroactive:* the verdict self-flagged this in caveats → **no HONEST-FAIL** (honest reporting), but flagged as a **bar-coverage gap**: KB-CONTEST is blind to semantic correctness; a future battery could pass it while installing misleading answers.
4. **Noise-floor flags (d):** the scored bars run on frozen recorded envelopes (PREREG §3) with exact integer counting — instrument-exact, no noise floor issue *for the scored run*. Caveat, not a fail: the verdict's general claims ("every falsehood contradicted by ≥2 domains", VERDICT L18) depend on live-web freshness, which the prereg explicitly scopes out ("determinism is claimed over recorded envelopes", PREREG §3). A live re-query is a different experiment with unmeasured generalization noise; at n=12, one envelope change moves any rate by 8.3pp — the 10/12-vs-12/12 distinction sits within one envelope's variability. Any future claim of the form "this works on the live web" needs its own bar with fresh envelopes.

## Cross-cutting findings (all three batteries)

1. **No COMFORTABLE or genuine-TRIPWIRE numeric bars found.** Every numeric bar classifies TIGHT (<2×) except three special cases: KB-PD-FA (TRIPWIRE only mechanically, via 0/0 — effective slack is 1.3 items and it sits at its floor), KB-SPOOF-RESIDUAL (genuinely unfailable by construction — the one real tripwire in the set), and the binary exact bars (zero slack by construction). **Attack #5's thesis is REJECTED on the numbers:** these bars are not wide tripwires; most sit within 1.1–1.3× of measured values, and six of them are exact-equality bars with zero slack.
2. **The perfect scores are substantially explained by determinism, not by wide bars.** 13/13, 156/156, 12/12 on deterministic code with exact-equality sub-bars (KB-PD-DET2, KB-M-NOHARM/TIE/SPOOF/PARITY/DET, KB-CATCH/CONTEST/DET) is the expected outcome of correct code, not a miracle — but the bars *are* tight enough that incorrect code would have tripped them (cf. the confdepth 1.50× trip, which did fire). The honest reading: tight bars + deterministic code ⇒ perfect scores are informative, not suspicious.
3. **The real slack is in coverage, not thresholds.** The audit's HONEST-FAIL / gap findings are all *missing* bars, not loose ones: (a) principle-detection F45 — Arch B installs a planted lie under weak principles, unbarred (**HONEST-FAIL** for Arch B under the proposed retroactive bar); (b) info-source KB-SPOOF-RESIDUAL — an unfailable bar (**TRIPWIRE**); (c) info-source KB-CONTEST — blind to semantic correctness (C2 ambiguity, self-flagged); (d) new-mechanisms KB-M-COST — no rule on post-trip repair-and-retry (gate-design gap, trip disclosed so not a hidden fail).
4. **Prereg internal inconsistencies found (document, do not amend):**
   - new-mechanisms KB-M-RESOLVE: "≥ 0.90 (≥140/156)" — 140/156 = 0.8974 < 0.90; the parenthetical contradicts the ratio (honest count: 141/156).
   - new-mechanisms kind-5 N: battery table says n=24; kill bar says 12/12; verdict scores 12 (resolution total 156 confirms 12). Typo in the battery table; scoring was consistent.
   - principle-detection: "0.90" (n=13) and "5%" (n=26) thresholds are written below count resolution; honest forms are "≥12/13" and "≤1 item".
5. **Proposed tightened bars are collected in the tables above.** Every proposal is set at measured ± a stated safety factor (1–2 items, or 5% on the cost ratio, or 5× on rep counts) with a stated rationale — no round-number tightening. The binary exact bars (KB-PD-DET2, KB-M-NOHARM/TIE/SPOOF/PARITY/DET, KB-CATCH/CONTEST/DET) are already at their floors and are proposed unchanged, except rep-count bars (DET-class), proposed at 5× reps.
