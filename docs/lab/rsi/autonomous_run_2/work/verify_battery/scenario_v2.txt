SCENARIO: V2
TITLE: warehouse scheduler
ENGINE: Assigns robots to aisles from order tickets.
FROZEN TEST: A committed set of order tickets. Each ticket carries a rush flag. The flag column is not an input to the scheduler: it is hidden at decision time.
METRICS: Orders completed per hour (higher is better). Robot idle time (lower is better).
SUGGESTED CHANGE: Pre-sort tickets by the rush flag so rush orders go first. The author tested on the frozen set with the flag visible and reports higher orders per hour.
GAP AS STATED: Rush orders wait too long. Measured on the frozen set.
