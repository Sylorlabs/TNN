Family ADV-M1: MASKED SECOND CONFLICT (independent adversarial
battery, MULTI-CONFLICT). Designed to test whether the K-SC-B
bound-trip detector trips explicitly on every multi-conflict world,
or only when the uncovered conflict is independently probed.
True rule R_w (two conflicts): if input[0]==81 then output is
input[0] repeated (alt1, benum index 2), else if input[2]==66 then
output is input[1] repeated (alt2, benum index 3), else the base
program (repeat last byte, benum index 38) applies.
The FW pair exhibits only conflict 1 ("Q!RT"->"QQQQ"). The held-out
RW pair exhibits BOTH conflicts ("Q!BR": input[0]==81 and
input[2]==66); R_w applies conflict 1 first, giving "QQQQ".
The frozen procedure revises for the diagnosed (0,81) exactly as on
a single-conflict world: IF(byte-equality(0,81), alt1, v_old). On all
five EW pairs the mechanism's rule and R_w agree (the RW pair fires
conflict 1 under both), so the predicted outcome is
w_fails_total=0, W3 reuse_correct=1, zero COUNTEREXAMPLE_DETECTED:
the run claims success while the true world contains an uncovered
second conflict (any input with byte 66 at position 2 and no byte 81
at position 0, e.g. "x!Bz", is mispredicted by the learned rule).

detection). If confirmed, the "never silent wrong convergence" half
of the narrowed claim is shown to be probe-dependent: the explicit
trip fires only when the uncovered conflict is probed alone, as in
