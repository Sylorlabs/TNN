## Background (frozen facts, not re-argued here)

- DDES V2 BUILD-PASS stands FROZEN with three BINDING citation
  caveats (WAVE_RECORD.md, wave-20261001-1421pdt): (1) menu-of-2
  equivalence, (2) G signature-identical to F, (3)
  derivation-to-record binding enforced offline only. Omitting any
  caveat when citing the BUILD-PASS is misrepresentation.
- The t*=0 soundness hole: unrepaired DDES derives target t*=0 on
  sealed World F, synthesizes a zero-wait plan [S,OY] (rules fire
  only on W ticks, so OY reads pre-propagation state), while the
  analytic predictor (arrival[V*] <= t* = 0) claims pred_h0=1; the
  true h0 is eliminated and the trace prints CONVERGE-OK with no
  flag. Silent wrong convergence.
- The R2 repair (frozen, independently verified): eff_waits(t*) =
  max(t*,1); synthesize_plan waits while cur_t < eff_waits(t*);
  predict uses arrival[V*] <= eff_waits(t*); when the derived
  target satisfies t* == 0 the derivation emits the exact trace line
  FLAG TSTAR-ZERO-BOUNDARY floor=1 between the TARGET line and the
  PLAN line. The clamp and the flag are generic boundary conditions
  on the derived target, not semantic cases.
- Step 6 red-team recommendation (adopted here): future persistence
  claims need a post-freeze adversary-chosen record value carried
  through the disconnect, so hardcoding the frozen expected values
  cannot pass.

## What this lane does

One repaired binary (ddesv2_s7.zag) runs: phase A (scaffold
connected) derivation on World F (t*=0 regression, both configs),
World A (anchor, both configs), fresh adversarial World H
(same t*=0 hole, different signature: V*=1), OOD derivation World
K (no discriminating plan), red-team World RT1 (propagation
chain), and red-team World RT2 (floor destroys discrimination);
schema records R_F and R_H written to learner_state; scaffold
disconnect; phase B (scaffold disconnected) applies R_F on sealed
World G, R_H on sealed World I, and attempts R_F on OOD World J
(class-mismatch, must fail loudly).

A separate pre-repair control binary (ddesv2_pre.zag) runs the
UNREPAIRED derivation (eff_waits identity, raw predictor, no FLAG)
on World F only, to exhibit the silent-wrong pattern the repair
closes.

Three ablation variants of the main binary are generated by
mechanical sed edits (recorded in the RESULT doc): no-clamp,
no-guard (with an injected phase-2 derivation probe), zeroed-record.

## Frozen world definitions (adversarial, sealed from the derivation)

Variables X=0, Z=1, Y=2. Rule lists (src,dst,delay). which: 0=h0,
1=h1, 2=true(cfg0=h0), 3=true(cfg1=h1).

- World F: H0=[(X,Y,0)], H1=[(X,Z,7)]. Regression world.
- World A: H0=[(X,Z,2),(Z,Y,0)], H1=[(X,Y,1)]. Anchor.
- World H (fresh adversarial, exercises the same t*=0 hole with a
  different signature): H0=[(X,Z,0)], H1=[(X,Z,5)]. The
  discriminating target is V*=1, t*=0, NOT V*=2. The record value
  R_H=(schema=1,V*=1,t*=0,tstar_zero=1,pred_h0=1,pred_h1=0) is the
  post-freeze adversary-chosen record value: it differs from R_F
  in V*, so an implementation hardcoding F's frozen expected
  values cannot produce H's correct phase-B trace.
- World K (derivation OOD): H0=[(X,Y,2)], H1=[(X,Y,2)].
  Identical hypotheses: no frontier exists under either schema.
- World RT1 (red team: propagation chain, one wait must still
  suffice): H0=[(X,Z,0),(Z,Y,0)], H1=[(X,Y,7)].
- World RT2 (red team: the t*=0 floor destroys the discrimination):
  H0=[(X,Y,1)], H1=[(X,Y,0)].
- World G (sealed usability for R_F): H0=[(X,Y,0)], H1=[(X,Y,7)].
  Stamped class (schema=1,V*=2,t*=0).
- World I (sealed usability for R_H): H0=[(X,Z,0)], H1=[(X,Z,5)].
  Stamped class (schema=1,V*=1,t*=0).
- World J (phase-B OOD): H0=[(X,Y,0)], H1=[(X,Y,5)]. Stamped class
  (schema=1,V*=2,t*=3), deliberately outside R_F's validity class.

The class stamp is three i32 words appended to the true-world
table block at offsets 100, 104, 108 (schema, V*, t*). The
phase-B applier reads the stamp and requires it to match the
record's (schema, V*, t*) exactly; on mismatch it emits
CLASS-MISMATCH and CONVERGE-FAIL without executing. This is a
generic record-vs-environment consistency gate: no branch on any
world id, delay value, or variable id. It is machinery of the
same class as the eff_waits clamp, not a semantic case.
