## 2. Wire protocol (for coordinator and adversary)

The TCNP turns ride the existing arena turn envelope (same as the v6
battery); only two new event/test kinds are added, dispatched by event
type exactly like the existing handlers. No modes, bridges, routers.

- Expo: {"turn":N,"kind":"expo","ev":{"t":"pshow","task":"A","in":[v0,v1,v2,v3],"out":[w0,w1,w2,w3]}}
- Test: {"turn":N,"kind":"test","item":M,"cap":C,"q":"ptest|A|v0,v1,v2,v3"}
- Reply: the standard v6 reply JSON envelope, unchanged fields; the reply
  value is "w0,w1,w2,w3" or "UNKNOWN". Learner-internal content (creation
  traces, trial log, per-item verdicts) goes to stderr (fd 2, deterministic,
  no timing) and the persisted state file, never stdout.
