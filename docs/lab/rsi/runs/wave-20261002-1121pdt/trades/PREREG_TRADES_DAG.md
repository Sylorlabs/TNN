# PREREG_TRADES_DAG: Non-Chain DAG Worlds for WIDE-EIG-10 Generality

Lane TRADES, wave wave-20261002-1121pdt, 2026-10-02.
Queue item 8. Frozen BEFORE implementation commit.

## 1. Objective

Prior trades work (TRADES-1, wave-20261002-0521pdt) demonstrated active causal
intervention with EIG-guided experiment choice on CHAIN-structured worlds only
(6 chain hypotheses, 3 variables, 8/8 sealed WIDE). This prereg extends the
mechanism to NON-CHAIN DAG structures: branching (fork), merging (collider),
and diamond dependencies. The question is whether the mechanism GENERALIZES
beyond chains, or secretly linearizes every DAG into a chain (a generality
failure, not a pass).

## 2. Mechanism (CAUSAL-DAG)

Source: trades_contestant.zag adopted 0521 (TRADES-1). The CAUSAL-WIDE module
(6 chain hypotheses) is replaced by a CAUSAL-DAG module with:

- Hypothesis spaces enumerated from variable names at runtime (never from
  source constants): 3-var = 12 hypotheses (3 fork + 3 collider + 6 chain);
  4-var = 36 hypotheses (12 diamond + 24 chain).
- Forward model (shared by generator and agent, frozen toy semantics, not a
  realism claim): do(V=v) forces V and all its descendants to v; all other
  variables take a fresh natural bit b. Descendants computed by transitive
  closure over the hypothesis edge list.
- EIG intervention choice over 2*nvars candidates (each variable x value 0/1),
  2-bit natural variation integrated out, no repeat within a trace (rotating
  exclusion), 10 traces x 3 rounds pooled.
- Prune: discard hypotheses inconsistent with (V, v, observed) under some
  natural bit. Verdict: lexicographically smallest edge-list string among
  survivors (deterministic tie-break, disclosed, not neutral).

Answer format: sorted edge-list string "A->B,C->D". Scoring: exact string
match, 1000 or 0. No partial credit.

Candidates:
- WIDE: CAU_MODE=0 (EIG), CAU_NT=10, CAU_DAG=1 (full 12/36 hypothesis space).
- F_CM: CAU_MODE=1 (cyclic fixed), CAU_NT=10, CAU_DAG=1.
- SINGLE: CAU_MODE=0, CAU_NT=1, CAU_DAG=1 (one EIG trace, no pooling).
- ABLATION (red team only): CAU_DAG=0 (chain-only 6/24 hypotheses, the
  TRADES-1 mechanism verbatim) on non-chain worlds. Expected 0/10 by
  construction; any nonzero score is a world-design bug.

All variants are one-line build-flag deltas of one source. No new modes,
bridges, handlers, or semantic cases. Cognition delta vs TRADES-1: the causal
module is rewritten (fork/collider/diamond enumeration, descendant-copy
forward model, edge-list answers); all non-causal paths byte-identical
(verified by K6).

## 3. Sealed worlds (12, seeds 2001..2012)

Generated by dag_world.zag (pure Zag, frozen) AFTER this prereg is committed.
Seeds are disjoint from all dev calibration seeds (9001..9008).

- 2001: 3-var fork, root X (X->Y,X->Z)
- 2002: 3-var fork, root Y (Y->X,Y->Z)
- 2003: 3-var fork, root Z (Z->X,Z->Y)
- 2004: 3-var collider, sink X (Y->X,Z->X)
- 2005: 3-var collider, sink Y (X->Y,Z->Y)
- 2006: 3-var collider, sink Z (X->Z,Y->Z)
- 2007: 4-var diamond, root X sink W (X->Y,X->Z,Y->W,Z->W)
- 2008: 4-var diamond, root Y sink W (X->W,Y->X,Y->Z,Z->W)
- 2009: 4-var diamond, root Z sink W (X->W,Y->W,Z->X,Z->Y)
- 2010: 4-var diamond, root W sink Z (X->Z,Y->Z,W->X,W->Y)
- 2011: 3-var chain control (X->Y->Z)
- 2012: 3-var chain control (Z->Y->X)

10 non-chain worlds, 2 chain controls (the TRADES-1 home turf, verifying no
regression on chains while generalizing).

World protocol: cbrief names variables (no structure hint); 12 observational
rows (3 per joint setting, natural variation only); 10 traces x 3 rounds of
EIG interventions with outcomes from a precomputed intervention table
(uniform 4 outcome columns x, y, z, w; agent uses only the first nvars);
ctest demands the edge-list; cdone closes. key.json holds the true edge-list;
it is chmod 000 during agent runs; the agent source contains zero seed
constants, zero edge-list string constants, and never opens key.json
(verified by grep before the sealed run).

## 4. Kill bars (FROZEN, never moved after this commit)

- K1 (capability): WIDE scores >= 10/12 on the 12 sealed worlds.
- K2 (the 10x buys intelligence): WIDE minus SINGLE >= 2 points.
- K3 (intelligence, not compute): WIDE >= F_CM on sealed worlds.
- K4 (cost of the 10x): structural 10x (30 pooled EIG searches vs 3 single);
  aggregate forward-simulation ratio WIDE/SINGLE in [8,12]; per-world ratios
  reported; wall-clock reported as context.
- K5 (determinism): 3/3 byte-identical reply streams (ms/rss stripped) and
  stderr traces per world for WIDE on all 12 worlds.
- K6 (no regression): WIDE binary over the 131-turn 68-item arena battery
  (turns.jsonl sha256 0fc3edb0e2fe0d4b68e1d51a63c8faefcd800122b2d9c1c97bcb2469)
  produces a stripped reply stream byte-identical to the INQ sealed run.
- K7 (sealed validity): worlds regenerate byte-identically from committed
  dag_world.zag; agent source has zero seed hits, zero edge-list constants,
  zero key.json opens; key.json chmod 000 during runs; rerun determinism.
- K8 (pure Zag): zero non-safebin executable invocations in the research path
  (bash/awk/grep/sed/sha256sum/cut/date/chmod/cp only for sequencing).
- K9 (architecture): cognition-lines delta and modes/bridges/handlers delta
  recorded; this lane adds zero of each.
- K10 (no L3 claim): this lane makes no representational-invention claim;
  the hypothesis spaces are researcher-enumerated (12/36), the forward model
  is researcher-supplied. L2 structural use at most.
- K11 (GENERALITY, the point of this lane): WIDE scores >= 8/10 on the 10
  non-chain worlds, AND every non-chain PASS is a unique-survivor verdict
  (final Hn=1, no tie-break involved), AND the chain-only ablation (CAU_DAG=0)
  scores 0/10 on the non-chain worlds (with 2/2 on the chain controls as a
  build sanity check).

BUILD-PASS requires K1, K2, K4, K5, K6, K8, K11. K3, K7, K9, K10 must also
pass. Any kill bar failure is reported as information, never re-cut.

## 5. Dev calibration (observed BEFORE freezing, informs but does not set bars)

8 dev worlds, seeds 9001..9008 (disjoint from sealed), covering fork,
collider, diamond, and chain shapes:

- WIDE 8/8, F_CM 8/8, SINGLE 2/8. WIDE minus SINGLE = 6.
- Unique survivor (Hn=1) on 6/6 non-chain dev worlds. One chain control
  world ended Hn=2 and the lexicographic tie-break picked correctly.
- Aggregate forward-sim ratio WIDE/SINGLE = 49208/5646 = 8.72, in [8,12].
  Per-world ratios 7.3..12.3 (two at 12.3, disclosed; bar is on the
  aggregate, matching the 0521 convention).
- The tie-break is NOT structure-neutral (lexicographic on edge strings can
  prefer a chain over a collider in a tie). K11 therefore requires
  unique-survivor verdicts on non-chain worlds so no PASS depends on it.
- K6 pre-check: new binary byte-identical to INQ sealed reference on the
  131-turn battery. Source diff vs TRADES-1 confined to the causal module
  and the four causal handlers; all 49 diff hunks inside those regions.

## 6. Evaluation protocol

1. Commit this prereg alone. Record hash.
2. Copy dev sources (dag_world.zag, dag_contestant.zag, dag_score.zag,
   run_dag.sh, already validated in /tmp/dagdev) into the lane src/ as the
   implementation. Commit. Record sha256 before/after.
3. Generate the 12 sealed worlds. Record pre-run hashes.
4. Run: WIDE x3, F_CM x1, SINGLE x1 on all 12 (60 runs). Score with
   dag_score.zag. K5 from the 3 WIDE runs.
5. Red team R1-R4 (below) plus the CAU_DAG=0 ablation on all 12.
6. Advocate/skeptic/judge debate recorded in REPORT.md, then verdict.

## 7. Red team (every PASS is attacked)

- R1 (exact-match audit): confirm the scorer compares the full edge-list
  string with no normalization that could admit a chain string for a DAG.
- R2 (unique-survivor audit): for each non-chain PASS, confirm final Hn=1
  from the trace; any Hn>1 is a K11 failure, not a pass.
- R3 (DAG-evidence audit): for each non-chain PASS, exhibit at least one
  pooled intervention outcome that is inconsistent with EVERY chain
  hypothesis (i.e., the verdict cannot be reached by chain-restricted
  reasoning on the same evidence). Method: replay the pooled outcomes
  against the 6 (or 24) chain hypotheses in the scorer harness and show
  all chains ruled out while the true DAG survives.
- R4 (chain-only ablation): CAU_DAG=0 scores 0/10 on non-chain worlds,
  2/2 on chain controls. A nonzero non-chain score voids the world design.
