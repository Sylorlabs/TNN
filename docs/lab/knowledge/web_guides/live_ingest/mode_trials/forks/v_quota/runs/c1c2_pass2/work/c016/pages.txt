S|## What Are Roman Numerals?
S|Roman numerals *are the number system that ancient Rome used.
S|Instead of the ten digits we use today (0–9), the whole system is built from just seven letters.* Historians don't know exactly why the Romans chose those seven letters, but the system grew over time from tally marks and earlier number symbols.
S|Seven building block numerals were enough to write any number they needed, without making the system large and hard to learn.
S|Each letter stands for a different value.
S|Put them together in the right order, and we can write almost any number we want.
S|So instead of writing 1, the Romans wrote I.
S|Instead of 5, they wrote V.
S|Instead of 10, they wrote X.
S|There's no symbol for 0, and no symbol for numbers like 2, 3, or 4 either.
S|Roman numerals work by combining a small set of symbols to build any number you need.

S|Once you know the order to look for, it works the same way every time.
S|When we read Roman numerals, we add or subtract the value of each symbol depending on where it sits next to the others.
S|Let's break it down: 1.
S|Each Roman numeral letter has a **value** (I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000).
S|When a symbol **repeats in a row**, you add its value that many times.
S|III is 1 + 1 + 1 = 3.
S|In standard Roman numerals, symbols are **not usually repeated more than three times in a row.** 3.
S|When a **smaller-value symbol comes after a larger-value symbol**, you add.
S|VI is 5 + 1 = 6, XVI is 10 + 5 + 1 = 16.
S|For **certain pairs**, when a **smaller-value symbol comes before a larger-value symbol**, you subtract.
S|IV is 5 − 1 = 4 and IX is 10 − 1 = 9, so you **treat each pair as one chunk**.
S|**Read the numeral from left to right**, adding or subtracting each symbol (or pair) as you go.
S|Now, we can put these rules to work.
S|**VII:** Start with V, which is 5.
S|Then you've got two I's after it, so you add 1 and 1.
S|That's 5 + 1 + 1 = 7.
S|**XIV:** Look at the X first — that's 10.
S|Since the I sits before the V, you subtract: 5 − 1 = 4.
S|Put it together: 10 + 4 = 14.
S|**XLII:** Start with XL.
S|The X sits before the L, so you subtract: 50 − 10 = 40.
S|Next is II, which adds 1 + 1 = 2.
S|Altogether: 40 + 2 = 42.
S|Here's a tip our tutors always share: if you ever see the same symbol repeated four or more times in a row, like IIII or XXXX, something's off.
S|Romans always found a shorter way to write it, so watch for that pattern.

S|Here's the process, step by step: 1.
S|**Break the number into parts.** Split it into thousands, hundreds, tens, and ones (for example, 1984 → 1000, 900, 80, 4).
S|**Convert each part into Roman numerals.** For each place value, use the symbols and subtractive forms you already know (like M, CM, D, C, XC, L, X, IX, V, I).
S|**Write the parts from biggest to smallest.** Put the Roman numerals for thousands first, then hundreds, then tens, then ones, all in one row.
S|Let's try it.
S|**18:** Break it apart: 10 + 8.
S|The 10 is X.
S|The 8 breaks down further into 5 + 1 + 1 + 1, which is V, I, I, I.
S|Put it together: X + VIII = **XVIII**.
S|**49:** Break it apart: 40 + 9.
S|For 40, a smaller symbol (X) comes before a bigger one (L), so you subtract: L − X, written as XL.
S|For 9, the same thing happens with I and X: X − I, written as IX.
S|Put it together: XL + IX = **XLIX**.
S|**247:** Break it apart: 200 + 40 + 7.
S|The 200 is two C's, or CC.
S|You already know 40 is XL.
S|The 7 breaks down into 5 + 1 + 1, or VII.
S|Put it together: CC + XL + VII = **CCXLVII**.
S|Notice that writing Roman numerals uses the exact same rules as reading them.
S|You're just working in the opposite direction, starting with a number and turning it into symbols instead of the other way around.

S|You scan from left to right, and the position of each symbol changes the total value.
S|There are really only three rules you need to know.
S|**The Additive Rule:** When you see a symbol of equal or lesser value placed *after* a symbol of greater value, you add them together.
S|This is the most common rule.
S|For example: VI is 5 + 1 = 6.
S|And LXX is 50 + 10 + 10 = 70.
S|**The Subtractive Rule:** This is the one that trips most people up, but it’s easy once you see the pattern.
S|When a smaller value symbol (only I, X, or C) is placed *before* a larger value symbol, you subtract the smaller from the larger.
S|For example: IV is 5 – 1 = 4.
S|XC is 100 – 10 = 90.
S|**The Repetition Rule:** You can repeat the symbols I, X, C, and M up to three times in a row to multiply their value.
S|**Important: The symbols V, L, and D are never repeated.** For example: III is 1 + 1 + 1 = 3.
S|CCC is 100 + 100 + 100 = 300.
S|You would never write VV for 10; you just use X.
S|Let’s break down that library date, MCMIV, using these rules.
S|We read left to right: M (1000), then CM (100 before 1000, so 1000 – 100 = 900), then IV (1 before 5, so 5 – 1 = 4).
S|Add them up: 1000 + 900 + 4 = 1904.
S|It’s like solving a tiny, satisfying puzzle.

S|## Frequently Asked Questions ### Why is there no zero in Roman numerals?
S|The concept of zero as a placeholder number wasn’t part of the Roman counting system.
S|They simply didn’t need it for their calculations, so a symbol for it was never created.
S|### Can any Roman numeral be subtracted from another?
S|No, the rules are specific.
S|You can only subtract I from V and X; X from L and C; and C from D and M.
S|You can’t, for example, write VL for 45; it must be XLV.
S|### What’s the largest number you can write in Roman numerals?
S|Using the standard symbols, the largest number commonly written is 3,999 (MMMCMXCIX).
S|By using the vinculum (a bar on top), you can create much larger numbers, but they are not typically seen today.
