**ALT4**
**Mechanism:**  
Four cheap binary signals from page metadata:  
S1 = (distinct byline authors \ge2)  
S2 = (distinct social-share platforms \ge2)  
S3 = (distinct meta-publisher strings \ge2)  
S4 = (distinct meta-generator/CMS values \ge2)  
Score = \Sigma Si (max 4). Accept if score \ge2.  
Deterministic threshold; no text/time/citation comparison used.  
**Metadata needed:** byline tags, <meta name=publisher>, <meta name=generator>, social plugin attributes.  
**Weakness:** metadata easily faked or stripped on low-quality pages.
