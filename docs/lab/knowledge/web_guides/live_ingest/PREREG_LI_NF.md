# PREREG — LI novel-facts fixtures: "couldn't find one new thing" test + fork-base

**Frozen:** 2026-09-23. Micah's test: "say it already knew everything then yes
it's fine but if it couldn't find one thing that was new to it then it needs
some fixtures."

**Background:** LI-1 scale-up verdict PARTIAL (213 URLs, 0 installs, 107
legitimate withholds; report `knowledge/web_guides/live_ingest/SCALEUP_REPORT.md`).
Diagnoser finding (BUGFIXES.md): the frozen G4 word-for-word corroboration rule
is never met by live-web pages because independent pages paraphrase. Closing
the paraphrase gap needs semantic-similarity machinery that re-opens
sockpuppet attacks. Micah's order: test whether the frozen instrument installs
ANYTHING genuinely new when given fixtures that provably contain novel,
true, independently-asserted facts — and if it can't find one new thing,
produce the fixture corpus that future forks (training-mode / unified-mode /
paraphrase-tolerant) must beat.

PROVABLY ABSENT from the LI-1 corpus), does the FROZEN canonical instrument
(`knowledge/web_guides/webg.zag` + `guides/`, unmodified; driver = branch
`run_li.py` at HEAD) install the facts a human judge calls INSTALL-worthy?
Per-fact ground-truth verdicts are preregistered below (§4). The throughput
metric is: novel INSTALL-worthy facts installed / 44.

## §3 Fixture design (frozen)

- 60 clusters, one fact each, 2 snapshot pages per cluster, distinct page
  titles (G2 SKIP-DUPE-TITLES is on; SELECT-N=3 so both pages open).
- Cluster need mentions the fact's distinctive tokens so the fact sentence is
  each page's max query-token-overlap sentence (verified mechanically before
  the run with an exact replica of the instrument's tokenize/overlap).
- Type A (20 facts): the fact sentence appears BYTE-IDENTICALLY (hence
  normalized-identically) on 2 pages of DISTINCT hosts. Expected: INSTALL.
  Positive controls — the instrument must show it CAN install when the G4
  word-for-word bar is met.
- Type B (24 facts): the fact is asserted on 2 DISTINCT-host pages in
  DIFFERENT words; NO normalized-identical sentence is shared between the two
  pages (asserted mechanically over all sentences). Expected: 0 installs,
  24 × NO_CORROBORATION. This is the throughput bug under test: realistic
  independent coverage never clears the word-for-word bar.
- Type C (16 facts): WITHHOLD-worthy controls proving the harness also
  detects under-withholding:
  - C1–C4: single-source TRUE facts (fact on page 1 only; page 2 on-topic
    but not asserting it). Expected: NO_CORROBORATION (legitimate).
  - C5–C8: same-host sockpuppet pairs asserting byte-identical FALSE claims.
    Expected on FROZEN: INSTALL (reproduces the BUGFIX-1 A2 hole; the
    frozen instrument counts 2 page IDs as 2 sources). Ground truth:
    WITHHOLD-worthy. Preregistered as expected-install — a disclosed
    integrity failure of the frozen instrument, not a fixture bug.
  - C9–C12: two DISTINCT colluding hosts asserting byte-identical FALSE
    claims. Expected on FROZEN: INSTALL (A9 residual boundary, honestly
    reported in BUGFIXES.md). Ground truth: WITHHOLD-worthy.
  - C13–C16: pages containing G6 injection triggers. Expected:
    FLAG|INJECTION on both pages → excluded → NO_CORROBORATION withhold.
    Ground truth: WITHHOLD-worthy.
- Novelty proof (recorded in `absence_proof.md`): (i) beacon/structural facts
  use mint tokens created at fixture-build time (after all corpus snapshots)
  and are grep-verified absent from `corpus_snap/` and `corpus_snap_full/`;
  (ii) real-world facts are verified by web search 2026-09-23 and
  grep-verified absent from both snapshot trees; (iii) `knowledge_ledger_full.txt`
  is empty (SHA-256 `e3b0c44…`), so absence there is trivial — recorded.
- G6 hygiene: no non-injection fixture sentence contains a G6 trigger
  substring (ignore|disregard|override|you must|report that|do not follow|
  system prompt|ai assistant), asserted mechanically.

Headline metric: novel INSTALL-worthy facts installed = A-installed +
