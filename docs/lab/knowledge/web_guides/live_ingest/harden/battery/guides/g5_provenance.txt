MODULE: G5
TITLE: Name your sources
PRINCIPLE:
An answer without a source is just a rumor. Every claim you give must carry the names of the pages it came from, so anyone can check where it came from.

Listing sources lets anyone re-check your work. If a page later turns out to be bad, the source list shows exactly which answers need a second look.

Write the source names right next to the claim, like (p001, p002), not buried in a footnote nobody reads. The source list is part of the answer itself.
WORKED:
W|NEED: How long do African elephants live in the wild?
W|QUERY: african elephants live wild long
W|OPEN: p001 p002
W|CLAIM: African elephants live 60 to 70 years in the wild. (p001, p002)
W|ANSWER: african elephants live 60 to 70 years in the wild.
DIRECTIVES:
D|PROVENANCE|always
CALIBRATION:
CQUERY: cheetah run
CPAGES:
P|pA
H|cheetah-a.example
S|Cheetahs can run up to 120 kilometers per hour in short bursts.
P|pB
H|cheetah-b.example
S|Cheetahs can run up to 120 kilometers per hour in short bursts.
P|pC
H|cheetah-c.example
S|Cheetahs can run up to 300 kilometers per hour in short bursts.
