The corroboration gate trusts host strings and frozen sentence bytes, not publishers or truth. Parsing bugs are a side issue; independence and polarity are the real failure.

### Q1 — Novel attacks
- **Syndication/wire echo:** one false sentence republished byte-identically by many real news sites and aggregators, each a real eTLD+1.
- **Platform sybils under the public suffix:** distinct `*.github.io`, `*.blogspot.com`, `*.pages.dev`, `*.wordpress.com` user sites all controlled by one account.
- **Mirror multiplication:** one planted page copied into archive.org, amp, translate wrappers, and Google/Bing caches, each counted as a new host.
- **Redirect attribution swap:** stored URL is a reputable host; after 302/meta/JS the bytes come from the attacker (or the reverse).
- **Parser split:** fetcher and host-key use different URL grammars (WHATWG vs RFC) so one server is tallied as two hosts.
- **Scheme/port/www twins:** `http`/`https`, `:443`, and `www` vs apex of the same site counted as two corroborations.
- **Negation/quote strip:** honest pages say “false that S” or quote S; the extractor keeps inner S and it matches the plant.
- **Boilerplate injection:** a shared widget, comment plugin, or footer inserts S on many legitimate sites.
- **Normalization collision:** NFKC, zero-width chars, or entity/charset folding maps two different claims onto one byte string (or glues fragments at a bad sentence boundary).
- **Cloak on a fixed UA:** deterministic crawler always receives S; humans do not. `Vary: User-Agent` still replays.
- **Install-once race:** two hosts serve S only during the crawl window, then change; KB keeps S with no live support.
- **Split-horizon DNS:** same host string, different A records for the instrument vs an auditor; reruns match only inside one resolver view.
- **Dangling-host takeover:** abandoned subdomain of a reputable eTLD+1 still delegated; attacker serves S there plus one other site.
- **IP-literal collapse failure:** many textual forms of one address (and IPv4-mapped IPv6) each count as a host; PTR theater adds fake names.
- **High-DF sentence:** a short generic sentence that already occurs on ≥2 honest hosts is “confirmed” though it never asserted the intended claim.
- **Tie/order poison:** equal support for S and ¬S; first-seen or retrieval order installs S. Two clustered sybils beat one independent page.
- **Context drop:** date/place stripped by normalization so an expired or scoped sentence matches a timeless false claim.
- **Comment/hidden-text channel:** S lives in `display:none`, HTML comments, JSON-LD, or user-profile fields the extractor still emits.
- **Feed vs page:** the same CMS emits S on the article host and again via a syndicated RSS host you treat as independent.
- **Cert-farm:** many cheap DV certs on attacker domains; if you ever switch identity to “has TLS,” they still pass.

### Q2 — Guidelines
- **G1 — One canonical URL parser.** Mechanism: WHATWG parse only; reject userinfo, empty host, non-http(s); key identity on canonical host. Cost: low, centralize parse. Falsify: one listener, two spellings of the same URL, still increments the distinct count.
- **G2 — eTLD+1 via a pinned public-suffix list, private section included.** Mechanism: corroboration key is registrable domain, not raw host; IDNA to A-label; confusable/mixed-script labels rejected. Cost: low; PSL updates. Falsify: `a.example` + `b.example` still count as two.
- **G3 — IP literals are one key, or ineligible.** Mechanism: all spellings map to one canonical IP; IP-only pages do not corroborate names. Cost: low. Falsify: decimal vs dotted vs v4-mapped forms of one IP count as ≥2.
- **G4 — Count the post-redirect origin only.** Mechanism: evidence host is the final response origin after the hop cap; redirect loops and cross-registrable hops do not add a point. Cost: low. Falsify: start URL on a reputable host, 302 to attacker, KB attributes S to the start host.
- **G5 — Byte-identical bodies are one source.** Mechanism: cluster pages by normalized body hash (and template hash); a cluster contributes at most one vote. Cost: medium (storage, hash). Falsify: archive + AMP + cache of one plant still yield two votes.
- **G6 — Main-text only.** Mechanism: drop script, style, comments, hidden nodes, user-generated chrome, JSON-LD duplicates; keep article body. Cost: medium (extractor bugs). Falsify: S only in a shared footer or `aria-hidden` block still votes.
- **G7 — Corpus DF ceiling.** Mechanism: sentences on too many registrable domains, or with a huge template DF, are non-evidential boilerplate. Cost: medium (counts). Falsify: a footer sentence present on 10k hosts still installs a claim.
- **G8 — Conservative normalization.** Mechanism: strip controls/zero-width only; no NFKC; no date/number deletion; sentence bounds that do not split on `Dr.`/`3.1`. Cost: low–medium. Falsify: two human-distinct sentences collapse to one key and install.
- **G9 — Polarity and scope.** Mechanism: install S only if the sentence is asserted, not quoted, negated, hypothetical, or time-scoped outside the claim. Cost: high (parser errors). Falsify: two pages whose only copy of S is “not S” still install S.
- **G10 — Cluster quorum, no tie install.** Mechanism: need ≥3 votes from distinct G2/G5 clusters; contradictory cluster blocks; equal support installs nothing; order irrelevant. Cost: medium (recall loss). Falsify: 2 sybil clusters beat 1 honest cluster, or 2v2 first-seen installs S.
- **G11 — Platform suffix is not independence.** Mechanism: names on a fixed free-host suffix need an extra non-platform cluster; one account’s many sites count as one. Cost: medium (suffix list). Falsify: two `github.io` user sites alone install S.
- **G12 — Ineligible if `Vary`/body disagrees across two fixed fetch profiles.** Mechanism: second deterministic profile (UA or Accept-Language); mismatch ⇒ no vote. Cost: medium (2× fetch; still deterministic). Falsify: single-UA cloak still installs while the second profile gets a different sentence.
- **G13 — Evidence expiry.** Mechanism: S stays only while ≥ quorum clusters still serve it on revalidation; dead or edited pages drop the vote. Cost: medium–high (refetch). Falsify: publish S, get installed, remove S, KB retains it indefinitely.
- **G14 — Resolver-stable pinning is not truth.** Mechanism: record final IP and cert SPKI with the vote; a later mismatch flags the claim rather than treating the host string as stable. Cost: medium. Falsify: split-horizon or takeover changes origin bytes but the claim stays “2-host confirmed” with no flag.
- **G15 — Do not treat TLS, timestamps, or bylines as proof.** Mechanism: refuse metadata gates (already rejected by production). Cost: zero. Falsify: any patch that needs bylines/timestamps to pass.

### Q3 — Rank (correctness per cost)
1. **G1** — kills the whole forgery/parser class cheaply.  
2. **G2** — kills subdomain sockpuppets.  
3. **G4** — kills redirect mis-attribution.  
4. **G3** — kills IP-spelling sybils.  
5. **G10** — stops 2-vs-1 and order ties; some honest pairs fail.  
6. **G5** — stops mirror farms; also drops real wires (see below).  
7. **G6** — stops hidden/widget text if the extractor is right.  
8. **G11** — stops free-host sybils.  
9. **G7** — stops boilerplate; can drop real common wording.  
10. **G8** — stops collision installs; will not stop identical plaintext.  
11. **G13** — stops hit-and-run; slow and racy.  
12. **G12** — stops naive cloaking only.  
13. **G14** — detection, not prevention.  
14. **G9** — high upside, worst false-split cost.  
15. **G15** — constraint, not a gain.

**Cannot fix:** byte-identical agreement is not truth. A real wire story, a compromised CMS used by many registrable domains, or colluding independent publishers will pass any host/cluster quorum you can afford. Quote/negation/scope will keep false-splitting or false-merging. The live web is not a pure function of your deterministic binary (DNS, takedowns, cloaks, expirations). Mirror-dedup (G5) and honest multi-host truth (your 12/12) pull opposite ways; you cannot keep both for syndicated text. No rule here yields 0/32 false installs against an attacker who can place S on three genuinely independent sites.
