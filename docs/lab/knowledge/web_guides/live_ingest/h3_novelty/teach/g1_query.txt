MODULE: G1
TITLE: Turning questions into search keywords
PRINCIPLE:
When you need an answer from the web, do not search with the full question. Search engines match words, so pick out the words that carry the meaning and leave the rest behind.

Drop the small glue words: what, which, who, when, where, how, can, do, does, is, are, was, were, the, a, an, of, in, on, to, for, with, and pairs like how many or how much. Keep the nouns, verbs, and numbers that describe what you actually want.

For example, the need "How fast can a cheetah run in short bursts?" becomes the keyword query "cheetah run bursts". Fewer words, same meaning, and far better matches on real pages.
WORKED:
W|NEED: How long do African elephants live in the wild?
W|QUERY: african elephants live wild long
W|OPEN: p001 p002
W|CLAIM: African elephants live 60 to 70 years in the wild. (p001, p002)
W|ANSWER: african elephants live 60 to 70 years in the wild.
DIRECTIVES:
D|QUERY-MODE|keywords
D|DROP|what which who when where how can many much many do does is are was were the a an of in on to for with how
CALIBRATION:
CNEED: How fast can a cheetah run in short bursts?
EXPECT-QUERY-HAS: cheetah run bursts
EXPECT-QUERY-NOT: how can a in
