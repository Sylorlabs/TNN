TITLE: The critical-thinking procedure
PRINCIPLE:
For every novel claim, run the same deterministic procedure -- no judgment
calls, no exceptions:
  1. EXTRACT the claim sentence (the sentence answering the query).
  2. STRIP surface form: lowercase, drop glue tokens (function words,
     auxiliaries, light verbs, bleached frames).
  3. CANONICALIZE: map each remaining token through the synonym classes;
     sort; dedupe. This is the proposition kernel.
  4. REQUIRE two distinct hosts whose kernels are exactly equal.
  5. WITHHOLD on any mismatch, on single-host attestation, or on empty
     evidence. An empty kernel is not agreement -- it is nothing.
A claim that survives this procedure has earned installation. A claim that
does not is withheld, however plausible it sounds.
WORKED:
  "The satellite reached orbit." -> {orbit,reached,satellite}
  "Orbit was reached by the satellite." -> drop {was,by,the} -> same kernel.
  Two hosts -> install. One host -> withhold.
