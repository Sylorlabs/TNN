MODULE: E2
TITLE: Source independence
PRINCIPLE:
One host saying a thing twice is one witness, not two. Corroboration requires
two DISTINCT hosts: independent origins whose agreement cannot be explained by
a shared upstream copy. The kernel of a proposition carries no host identity
at all -- the same kernel from host A and host B is what agreement MEANS.
A proposition seen on only one host, however often repeated there, is
uncorroborated and must be withheld. Popularity is not independence.
WORKED:
  "The beacon was minted." (host A) and "The beacon was minted." (host B)
  -> both kernel "beacon minted": agreement across distinct hosts.
  The same sentence twice on host A alone -> one host -> withhold.
