MODULE: E4
TITLE: Corroboration standards
PRINCIPLE:
After surface form is stripped, what remains must agree EXACTLY. Numbers and
names are load-bearing: 500 meters and 330 meters are different propositions
no matter how similar the sentences look. Nominalizations canonicalize
(one/single, deterministically/deterministic, writes/generation, before/ahead,
no/never), plurals canonicalize (pages/page, facts/fact, verdicts/verdict,
satellites/satellite), and determiners/quantifiers (each, every, a, the, all)
are bleached. The fail-closed rule: when in doubt whether a token is
bleachable, KEEP it. A kept token can only cause a withhold (safe); a wrongly
dropped token can cause a false install (unsafe). Modality is kept: "may
cause" and "causes" differ.
WORKED:
  "The tower is 500 meters." vs "The tower is 330 meters."
  -> {500,meters,tower} vs {330,meters,tower}: differ -> withhold.
  "One page lists facts." vs "A single page lists facts."
  -> one<-single, facts<-fact, a dropped -> identical -> corroborated.
