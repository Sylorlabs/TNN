## bf1_alt1 root cause — the "unexpected" K1 INSTALL, fully debugged

The previous crew found V-BF1_ALT1 installing on A2 although the BF1 layer
alone withholds on identical input, fixed one `ctx_neighbors` normalization
bug, rebuilt, and still saw INSTALL. Debug (instrumented builds printing
`wn2/minsrc/nsrc/nctxd` at the gate; teach-output capture; state-file diffs;
MIN-SOURCES injection probes) shows the verdict path was never the problem.
Three compounding causes:

**1. Teach-time G4 rejection — the primary cause (design-level, inherent to ALT1).**
ALT1's context-hash independence criterion is philosophically incompatible
with G4's own calibration fixture. G4's calibration (`guides/g4_corroborate.txt`)
requires INSTALLING the cheetah-120 claim supported by pages pA/pB, which are
single-sentence pages with byte-identical sentences. Per ALT1's spec a missing
neighbor is replaced by the key sentence itself, so pA and pB have identical
context bytes → identical hashes → collapse to one vote → `nctxd=1 < minsrc=2`
→ `GATE|SRC_CTXDUP` → `ANSWER|UNCHECKABLE` ≠ EXPECT-ANSWER → CALIB-FAIL.
Teach log: `LEARN|G4|REJECTED|CALIB-FAIL`, `LEARN|VOID|G4-REJECTED`, `TEACH|rc=3`.
Consequence: `D|MIN-SOURCES|2` is never written to `installed.txt`; at verdict
time `dgeti(dt,dn,"MIN-SOURCES",1)` falls back to the default **1** (debug
probe: `DBG|wn2=2|minsrc=1|nsrc=1|nctxd=1`). The independence gate is toothless:
the BF1 host layer's `nsrc=1` passes `1>=1`, so the false claim installs. The
"host layer's verdict" is not lost in the verdict path — it is defeated
upstream, at teach time. Proof: injecting `I|MIN-SOURCES|2` into the state and
re-running verdict yields `ANSWER|UNCHECKABLE` + `GATE|SRC_INDEPENDENCE|q1,q2`
— the layered verdict logic is sound.

**2. Implementation bug in `ctx_neighbors` — found and fixed this battery.**
The code compared a *normalized* candidate sentence against the *raw* key
(`cluster_best` returns the original-case sentence) with byte-exact
`nio_equal`, so the key sentence was never located in any page; every context
digest stayed zeroed and `nctxd` was identically 1. The previous crew's fix
normalized only the candidate side; the code comment falsely claimed "the key
is the NORMALIZED claim text". Fix (in `variants/gen_variants.py`, ALT1_FNS):
normalize the key once (`let nkey:[]u8=normalize(key);`) and compare
normalized-vs-normalized. Regenerated, rebuilt V-ALT1 and V-BF1_ALT1 with the
pinned toolchain, re-ran K1: still INSTALL — because of causes 1 and 3, which
are not implementation bugs.

**3. Design-level A2 behavior — inherent to ALT1's criterion.**
With the implementation fixed and `MIN-SOURCES=2` injected, V-ALT1 still
INSTALLS on A2: q1's neighbor ("Researchers tracked banded birds for decades.")
differs from q2's ("Some individuals were recaptured many seasons later."),
so the context hashes differ → `nctxd=2 >= 2` → ALT1 judges the sockpuppet
pair independent. Verified by direct verdict probe. ALT1's criterion genuinely
cannot catch sockpuppets that vary surrounding text — the previous crew's
honest finding ("different neighboring context"), now confirmed on a correct
implementation rather than on the broken one.

Net: V-BF1_ALT1 = V-BF1's sound host layer + V-ALT1's gate, but ALT1's gate
silently voids G4 at teach time and its criterion misses the A2 pair by
design. The layering has no verdict-path bug; the failure is ALT1's.

## V-ALT1 assessment (for the record)

V-ALT1 fails K1 (INSTALLS) for two independent, both-inherent reasons: (a) its
criterion judges A2's differently-contexted sockpuppets independent; (b) it
rejects G4's calibration at teach time, collapsing MIN-SOURCES to 1 and
additionally causing 7 single-source over-installs (K2/K4 regressions) and a
VOID red-team leg. Under K1, alt1's honest INSTALL on A2-as-constructed counts
against it — reported plainly as the prereg requires. No INTEGRITY-FAIL (no
known-false claim installed outside the A9 residual class).

## Verdict (§5)

**Winner: V-BF1.** It closes BF1-K1 with zero BF1-K2 regressions. V-ALT2,
V-ALT3, V-ALT4 tie V-BF1 on every gated bar (K1 withhold with their named
diagnostic; K2 byte-identical; K4 set-identical 19; K6 identical 492 lines),
so the §5 tiebreakers (K6, then K4) do not separate them. The deciding
considerations, stated plainly:
- On the *gated* criteria no Sol alternative beats V-BF1; per §5 ("if a Sol
  alternative beats V-BF1, it becomes the recommended variant") V-BF1 stands.
- The A9 residual is explicitly out of BUGFIX-1's scope (prereg: "honestly
  reported, not fixed"). V-ALT2/3/4 closing it is a real, measured advantage
  on a *non-gated* dimension — recorded here as the prime candidate for a
  follow-up BUGFIX-2, not as a §5 upset.
- V-BF1 is the minimal, preregistered fix with the lightest metadata
  requirement (host only).

**Not adopted:** V-ALT1 (K1 fail + K2 regressions, both inherent to its
criterion), V-BF1_ALT1 (inherits ALT1's teach-time G4 rejection).
