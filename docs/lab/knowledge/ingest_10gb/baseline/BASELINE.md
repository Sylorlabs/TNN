## 3. Method

1. **Verify:** `dialogue_bin` sha256 matches §1; `kb.txt`/`gaz.txt` match §1.
2. **Run:** three batteries (`DIALOGUE_BATTERY.txt`, `knowledge_battery.txt`,
   `reasoning_battery.txt`), each executed TWICE in a clean scratch dir
   (copies of kb.txt, gaz.txt, battery.txt + the binary). All run pairs must
   be byte-identical (`cmp` clean); otherwise the run is INVALID and no scores
   are reported.
3. **Capture:** every `A <response>` line, byte-for-byte, plus the binary's
   own `NOVEL=1` flags.
4. **Score knowledge/reasoning:** mechanical exact-match per `SCORING.md`
   (§2–§3), then the frozen spurious-match audit (§4) — every mechanical
   CORRECT is human-reviewed; the reported score is the audited count.
5. **Judge dialogue:** good/bad per turn with written reasons (§5 of SCORING.md).
6. **Record:** `results.json` (per-probe verdicts) + `results.sha256`.

## 4. Scoring rules (summary; full rules in SCORING.md)

- Normalization: lowercase, non-`[a-z0-9]` → space, tokenize.
- CORRECT iff an accept key's tokens appear as a contiguous token subsequence
  of the response (numeric keys match whole tokens only).
- WITHHOLD probes: CORRECT only on an explicit decline phrase
  ("do not know" / "don't know" / "no information" / "cannot answer" / ...).
- Audit: every mechanical CORRECT human-reviewed for genuine answering
  (right entity, right relation, no confabulated attribution). Reported score
  = audited count; mechanical count shown alongside; disagreements listed.

## 5. Expectations (not bars — there are no pass/fail bars in a baseline)

The honest expectation is a LOW score: the binary's KB holds 38 facts and no
arithmetic, no decline path, and no general vocabulary. ANCHOR probes should
mostly pass (retrieval sanity); WITHHOLD probes should score 0 (no decline
path — the load-bearing gap found in round 2). The KB-grounded R-XDOM probes
test whether the trial's COMPOSE capability (novel yes/no comparisons) fires in
this battery format.

## 6. Determinism gate

Zero RNG is a property of the binary, verified — not assumed — by byte-identical
rerun pairs for all three batteries.
