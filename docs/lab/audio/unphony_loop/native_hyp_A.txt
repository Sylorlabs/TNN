HYPOTHESIS H2 — "THE ATTACK IS MISSING" (rank #1, expected ear-impact highest)
====================================================================
1. Mechanism: In every real struck/plucked/bowed instrument, the first 5-50 ms
   are a different physical regime from the sustain: inharmonic strike
   partials (stiffness-dominated, f_n = n*f0*sqrt(1+B*n^2) with LARGE B),
   a broadband noise burst from the hammer/plectrum/bow bite, and a pitch
   overshoot as the string settles into its standing-wave regime. Classic
   psychoacoustic result: strip or swap the attack and listeners can no
   longer identify the instrument at all. Timbre identity lives in the
   transient, not the steady state.
2. Why current renderers miss it: additive-sine renderers start all partials
   at t=0 with their steady-state harmonic ratios and a smooth ADSR-style
   ramp; filtered-noise renderers shape only the gross envelope. Neither
   produces a regime change at 5-50 ms: no inharmonic strike partials with
   fast independent decay, no noise burst, no pitch overshoot. The ear
   hears a tone that "fades in" instead of being struck — the signature of
   an organ/tonewheel, which is exactly the "phony" quality.
3. Decisive measurement (pure Zag, on WAVs):
   - Segment each note by onset (energy-flux onset detector, 10 ms frames).
   - Window A = 0-30 ms post-onset, Window B = 120-400 ms post-onset.
   - Compute spectral centroid C = sum(f*|X|)/sum(|X|) in each window
     (46 ms Hann frames, 75% overlap, 0-12 kHz).
   - Fit inharmonicity B in each window by least-squares of measured
     partial peaks to f_n = n*f0*sqrt(1+B*n^2), n=1..8.
   - PREDICT (real anchor): C_A - C_B > 800 Hz; B_A / B_B > 3.
   - PREDICT (current renders): |C_A - C_B| < 200 Hz; B_A ~= B_B ~= 0.
   - CONFIRM: both gaps hold on anchor-vs-render. KILL: if the current
     render already shows C_A - C_B > 800 Hz (i.e. it has a transient),
     or if the real anchor shows |C_A - C_B| < 200 Hz (anchor itself is
     legato/synth-like), this hypothesis is dead.
4. Fix sketch (Zag-buildable):
   - strike_module(note): three parallel branches, all integer/fixed-point:
     (a) strike partial bank: 8 partials at n*f0*sqrt(1+B_strike*n^2),
         B_strike from instrument table (e.g. piano low ~2e-4 scaled up
         x5-10 for the strike regime), each with independent fast decay
         tau 15-60 ms, implemented as 2-pole modal resonators with R set
         from tau; (b) noise burst: h01 hash stream, 8-25 ms long,
         through 2 fixed biquads (bandpass 2-6 kHz), gain proportional
         to velocity; (c) pitch overshoot: f0(t) = f0_target *
         (1 + 0.02*exp(-t/20ms)) i.e. +~35 cents decaying with tau 20 ms,
         applied as a phase-accumulator rate multiplier.
     - Crossfade strike -> sustain (H1 modal body) at 30-60 ms with
       equal-power crossfade. Deterministic: every parameter is a table
       constant or a function of (note_id, velocity).
   - RANDOMNESS AUDIT: branch (b) uses the h01 deterministic hash stream,
     not RNG. Byte-identical reruns hold. FLAG: none — no step needs
     true randomness; the burst is shaped deterministic pseudo-noise.
5. Strongest reason it might be wrong: if the motif clips are legato
   wind/string lines with soft tonguing, the attack window is physically
   short and the phoniness must come from elsewhere (see H1/H6). Also, if
   the current renderers already implement attack ramps with brightness
   (check the actual renderer code before building anything), the measured
   gap may be small and this dies on the measurement, not the theory.

HYPOTHESIS H1 — "DEAD PARTIALS": NO COUPLED BODY (rank #2)
====================================================================
1. Mechanism: A real instrument is ONE excitation driving a COUPLED modal
   structure (string + bridge + body). All partials are driven by the same
   physical event through shared coupling, so their amplitude envelopes
   co-modulate: correlated but not identical (differential damping, mode
   coupling, wolf notes). The ear reads this correlated shimmer as
   "one physical object vibrating."
2. Why current renderers miss it: additive renderers assign each partial
   either (a) a fixed amplitude ratio times ONE global envelope (pairwise
   envelope correlation exactly 1.000 -> "plastic", over-correlated), or
   (b) fully independent envelopes (correlation ~0 -> "disembodied",
   under-correlated). Neither reproduces the 0.6-0.9 correlated-but-alive
   regime of a real body.
3. Decisive measurement:
   - For a sustained note, estimate f0 per 46 ms frame (autocorrelation),
     heterodyne/peak-pick partials 1..8, build amplitude tracks A_k(t).
   - Compute Pearson r for every pair (k,l), report mean off-diagonal r_bar.
   - PREDICT (real anchor): r_bar in [0.55, 0.95].
   - PREDICT (current renders): r_bar = 1.000 exactly (fixed-ratio case)
     or r_bar < 0.15 (independent-envelope case).
   - CONFIRM: anchor r_bar < 0.95 AND render r_bar >= 0.999 or <= 0.15.
   - KILL: if the render already lands in [0.55, 0.95], or the anchor
     itself is ~= 1.0, dead.
4. Fix sketch (Zag-buildable):
   - exciter_fn(velocity, brightness) -> integer pulse buffer e[n],
     length 64-256 samples (pluck: 3-sample snap; hammer: raised cosine
     2-4 ms; bow: stick-slip saw-ish ramp — all closed-form, no RNG).
   - Modal bank: 8-16 parallel 2-pole resonators,
     y[n] = b0*e[n] + 2*R*cos(theta)*y[n-1] - R*R*y[n-2],
     with (f_k, R_k, gain_k) from an instrument table; gains from a
     fixed mode-shape vector (constants). Shared excitation guarantees
     correlated envelopes; per-mode R_k gives differential decay, so
     r_bar lands in the live zone by construction, not by tuning.
   - Body EQ: 2 fixed biquads for the instrument's formant-ish bumps.
   - RANDOMNESS AUDIT: none. All tables/constants. FLAG: none.
5. Strongest reason it might be wrong: envelope micro-decorrelation may be
   below audibility — listeners might not hear the difference between
   r_bar=1.0 and r_bar=0.8 at all, in which case the fix changes the meter
   but not the verdict. Also, if the renderer uses fixed ratios, r_bar=1.0
   is a trivially true prediction and the "fix" is untestable against the
   current renders (still worth building if the anchor differs, but the
   A/B against Micah's ears is the only real test).

HYPOTHESIS H3 — "NO ROOM" (rank #3)
====================================================================
1. Mechanism: Every real motif recording is an instrument IN a space.
   The ear expects two things: early reflections (5-40 ms, a fixed sparse
   pattern that says "walls at these distances") that are IDENTICAL for
   every note (same room, same mic), and a late tail whose energy scales
   with note energy. A dry render in a vacuum reads as "close-miked
   synthesizer" no matter how good the tone is.
2. Why current renderers miss it: note-placement renderers sum dry voices;
   if reverb exists at all it is usually a single static impulse or a
   fixed wet mix applied identically per note, which gets the energy
   scaling and the per-note position wrong — or there is no room at all.
   V11's voice forks had the same gap (no tract, no space).
3. Decisive measurement:
   - Take an isolated staccato note; from 50 ms after offset, compute the
     Schroeder integral of the squared signal in 3 bands (0.2-1,
     1-4, 4-10 kHz); fit T60 per band.
   - Cepstrum of a 200 ms post-onset window: look for rahmonic peaks
     at 5-40 ms quefrency (early reflections).
   - PREDICT (real anchor): T60 >= 0.25 s in at least 2 bands;
     cepstral peaks present 5-40 ms.
   - PREDICT (dry render): tail hits the noise floor in < 80 ms;
     T60 < 0.1 s; no cepstral peaks.
   - CONFIRM: anchor shows room, render does not. KILL: if the current
     render already shows T60 >= 0.25 s and cepstral peaks (it has a real
     room), dead.
4. Fix sketch (Zag-buildable):
   - Early reflections: image-source, 8-12 taps per note, tap
     delays/gains precomputed from room dims + source/mic positions
     (closed-form, constants); per-note source position varies slightly
     with pitch (low notes "sit" lower) — deterministic function of MIDI
     pitch, NOT random.
   - Late tail: feedback delay network, 6 delay lines (prime-ish lengths
     in samples, constants), feedback matrix = fixed Hadamard (unitary,
     deterministic) — FLAG: literature FDNs use RANDOM matrices; the
     Hadamard substitution is the load-bearing determinism choice and
     must be validated to not ring at the matrix's eigen-frequencies.
   - Wet gain per note from a fixed distance model; tail energy then
     scales with note energy automatically.
   - RANDOMNESS AUDIT: none. FLAG: the Hadamard-vs-random matrix choice
     (above) is the one step that "wants" randomness; it is replaced by
     a fixed orthogonal matrix, which is deterministic and reruns
     byte-identically.
5. Strongest reason it might be wrong: reverb is the classic way to POLISH
   bad synthesis without fixing it — it can wash out transients (fighting
   H2) and make everything sound distant rather than real. Micah judged
   all 4 clips horrible; if ANY of those clips already had reverb, this
   hypothesis drops below H4/H6 immediately. Check the actual clip chain
   before building.

HYPOTHESIS H4 — "EVERY REPEAT IS THE SAME NOTE" (rank #4)
====================================================================
1. Mechanism: A human player never plays a repeated motif bit-identically:
   level +/-2-3%, onset +/-1 ms, brightness tilt, intonation wander of a
   few cents — all bounded, all stationary (the 50th repeat is no further
   from the mean than the 2nd). The ear uses this micro-variation as a
   "living player" cue; its total absence reads as sequencer/MIDI.
   Micah's verdicts ("2 = same as 1", "4 = same as 3") show the sameness
   was directly audible.
2. Why current renderers miss it: PAR is F(plan,t) — repeats are
   bit-identical (CV = 0). AR added state but as DRIFT (unbounded,
   error-accumulating — recurrence fell to 0.74), which is the WRONG kind
   of variation: real players don't random-walk away from the motif.
   Deterministic does not have to mean identical; it means a pure
   function of state, and "note index" is legitimate state.
3. Decisive measurement:
   - Align repeated motif instances by onset; per note compute RMS and
     spectral centroid; compute coefficient of variation across repeats.
   - Fit variance vs repeat index: slope ~0 (bounded jitter) vs
     growing (random walk).
   - PREDICT (real anchor): CV 2-6% per note, flat slope.
   - PREDICT (PAR render): CV = 0 exactly. (AR render: growing variance,
     nonzero slope — wrong kind.)
   - CONFIRM: anchor shows bounded nonzero CV; render shows 0 or growing.
   - KILL: if the anchor's repeats are themselves near-identical
     (CV < 1%, e.g. a quantized anchor), dead.
4. Fix sketch (Zag-buildable):
   - micro_variation_engine(piece_id, note_index, param): for each note,
     d = h01(piece_id || note_index || param_id) mapped to [-1,1];
     apply level *= 1+0.03d, onset += 0.7ms*d, brightness_tilt *= 1+0.04d,
     f0_cents += 4d. All bands documented, all deterministic, reruns
     byte-identical.
   - CRITICAL: bounded by construction (no accumulation across notes —
     each note's offset is a pure function of its own index, never of
     the previous note's state). This is what distinguishes it from AR's
     drift.
   - RANDOMNESS AUDIT: h01 hash stream only — deterministic pseudo-noise,
     explicitly allowed. FLAG: none, provided nobody "improves" it with
     a real RNG later.
5. Strongest reason it might be wrong: AR drifted and was judged EQUALLY
   horrible — so "some variation" alone clearly doesn't fix phoniness;
   H4 only addresses a secondary cue. If the core horrible-ness is
   timbral (H1/H2), H4 is lipstick. Also possible: Micah's "sameness"
   complaint was about motif IDENTITY (the composition), not note
   rendering — in which case no amount of micro-variation matters.

HYPOTHESIS H6 — "THE SUSTAIN IS FROZEN" (rank #5)
====================================================================
1. Mechanism: Real sustained tones (bowed strings, winds) are never
   static: vibrato (4-7 Hz FM, 10-30 cents, depth growing in over
   200-400 ms) and beating between near-coincident partials produce
   continuous slow motion. A static additive tone has zero slow
   modulation, which the ear reads as "held organ key."
2. Why current renderers miss it: additive sines with fixed frequency and
   amplitude per note; no LFO anywhere in the path. (V11 voice forks had
   the same disease: F0 nailed, everything around it frozen.)
3. Decisive measurement:
   - F0 track (autocorrelation, 30 ms frames) over any note longer than
     600 ms: measure peak-to-peak FM depth and rate in 4-8 Hz band, and
     depth-vs-time envelope.
   - PREDICT (real anchor): >= 12 cents p-p, rate 4-7 Hz, depth rising
     over the first 200-400 ms.
   - PREDICT (current renders): < 4 cents p-p, flat.
   - CONFIRM: anchor modulates, render is frozen. KILL: if the motifs
     contain no sustained notes (>600 ms), this hypothesis cannot apply
     — kill by repertoire, not by measurement.
4. Fix sketch (Zag-buildable):
   - vibrato_gen(note): phase-accumulator LFO, rate =
     5.2 Hz + 0.3 Hz * slow_drift(note_time) (slow_drift a fixed
     low-frequency function, deterministic); depth envelope 0 cents for
     first 150 ms, ramp to 25 cents by 400 ms, hold.
   - Apply as FM via fractional-delay pitch modulation on the modal-bank
     output (H1), NOT by retuning oscillators per-sample; the body's
     fixed resonances convert FM into coupled AM automatically (real
     vibrato has AM from body filtering — this falls out for free).
   - Beating: detune paired resonators in the modal bank by 2-5 cents
     (constants) — slow beating emerges with no extra module.
   - RANDOMNESS AUDIT: none. All rates/envelopes are fixed functions of
     note time. FLAG: none.
5. Strongest reason it might be wrong: repertoire-dependent — if the
   motifs are all short notes, vibrato never engages and this explains
   nothing about the 4 judged clips. Also, bad vibrato (wrong rate,
   too deep, starting too early) sounds MORE phony than none; the depth
   envelope shape is doing real work here and must be validated by ear.

HYPOTHESIS H5 — "NOTES DON'T TALK TO EACH OTHER" (rank #6)
====================================================================
1. Mechanism: In a real instrument/room, every note leaves energy behind
   that the next notes ride on: sympathetic string resonance (piano),
   room modes still ringing, the body's own reverberation. A motif is a
   continuous coupled event, not a sequence of isolated samples.
   Stateful-sequential placement renders each note from silence.
2. Why current renderers miss it: AR carries state but as abstract
   sequencer state (timing/amplitude drift), not as ACOUSTIC state —
   no shared resonator, no energy bus. PAR carries nothing. Neither has
   a physical channel through which note N can excite the resonances
   that note N+1 will sound through.
3. Decisive measurement:
   - During a note at pitch P, measure narrowband energy (3-semitone
     windows) at the pitches of the two previously sounded notes;
     compare against the same windows in a silence/room-tone segment.
   - PREDICT (real anchor): >= +8 dB above floor (sympathetic/room
     residue).
   - PREDICT (current renders): ~= 0 dB (nothing there).
   - CONFIRM: anchor shows residue, render does not. KILL: if the
     anchor shows no residue (< 3 dB), or the motifs are staccato with
     full damps between notes (no physical channel exists), dead.
4. Fix sketch (Zag-buildable):
   - sympathetic_bank: 12-24 parallel 2-pole resonators tuned to the
     scale degrees (constants), tau 1-3 s, fed from the main mix bus at
     low fixed gain (e.g. -20 dB); never re-triggered per note, just
     continuously excited — this IS the acoustic state channel.
   - room_energy_accumulator: single-pole lowpass on the bus energy,
     fed back into the FDN input at low gain (room "loading up" during
     loud passages — deterministic, no RNG).
   - RANDOMNESS AUDIT: none. FLAG: none.
5. Strongest reason it might be wrong: smallest predicted effect size of
   the six — a few dB of residue under the direct sound. For staccato
   motifs it may be literally inaudible, and mistuned sympathetic gains
   buy muddiness, not realism. This is a polish hypothesis, not a
   rescue hypothesis; build it last.
