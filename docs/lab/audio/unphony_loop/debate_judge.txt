## §1. HYPOTHESIS RANKINGS

### 1a. Likelihood of being the DOMINANT phoniness cause (provisional)

**#1. Missing physical source model — harmonic-sustain deficit.**
Synthesis, not one of the six as written: V11 showed pitch without a
source model sounds phony (F0 385 Hz correct, 0% formant frames vs 30%
real, HNR 0.5 dB vs 4.5 dB real). The motif clips extend it: HNR −2..0 dB
means no harmonic series is even present. A real pitched source =
excitation × resonator, and that product necessarily yields (i) harmonic
partials in sustain, (ii) a distinct attack regime, (iii) body resonances
(formants). The current renders have none of the three. This is the only
candidate that simultaneously explains V11, the "same horrible" verdict
across recurrence 1.00 and 0.74 (broken timbre is identical in both), and
the "same-but-slightly-different" fingerprint (identical broken timbre
carrying different note content). Killer: calibrated meters on single
isolated rendered notes — if one note already fails the timbre bars, no
plan-level mechanism can be dominant. If the calibrated meters instead
show the sustain IS harmonic (proxy was wrong), this #1 collapses and #2
takes the lead.

**#2. H2 — the attack is missing.** Strongest psychoacoustic prior in the
set (timbre identity lives in the first 50 ms; strip the attack and
instrument identification collapses). Mechanism is specific and physical:
inharmonic strike partials, excitation burst, pitch overshoot — none
present in smooth-ADSR renders. Demoted below #1 only because the measured
inharmonicity is whole-clip, not attack-windowed; H2's decisive
measurement (centroid/B contrast attack-vs-sustain) must still be run,
and if it shows the attack window is NOT the anomalous region, H2 drops
to a secondary fix. Conditional ear-impact is the highest of the six
*once a harmonic sustain exists*.

**#3. H1 — dead partials / no coupled body.** The "one physical object"
cue: real partials co-modulate through shared coupling (r_bar in
[0.55, 0.95]); renders are either over-correlated (1.000) or
disembodied. V11-grounded via formants (the voice's body). The fix
(shared excitation into a modal bank) is the natural sustain engine for
#1's renderer. Risk, honestly stated: envelope micro-decorrelation may be
near the audibility floor — this could move the meter without moving
Micah's ears. The blind test is the only arbiter.

**#4. Plan-side event-schema impoverishment (hyp B §1A Mechanism 4).**
The strongest surviving plan hypothesis: both AR and PAR plans come from
the same generator family, so "same horrible" is exactly what shared
impoverished event parameters (hardcoded attack=0, zero release,
flat vel) predict — recurrence drift is irrelevant to it, so it is NOT
killed by the AR/PAR evidence. Testable only by the 2×2's B cell. Ranked
below the render candidates because a plan defect predicts a *flavor
change* in horror between different plans, and because no plan rescues
an inharmonic renderer (the 2×2's predicted scoreboard already concedes B
fails every timbre bar).

**#5. H6 — frozen sustain (no vibrato/beating).** Real sustained tone is
never static; static sustain reads as "held organ key." Strictly
repertoire-conditional: if the motifs contain no notes >600 ms, kill by
repertoire, not by measurement. Also the easiest to get wrong (bad
vibrato sounds MORE phony than none). Build only after #1–#3 land.

**#6. H3 — no room.** Large effect *if* the renders are truly dry, but:
(a) reverb is the classic polish that hides bad synthesis without fixing
it, (b) it fights H2 (tails wash transients), (c) check the actual clip
chain first — if any judged clip already had reverb, demote immediately.
Room is a property of the *scene*, and the loop's stumped verdict was
about the *source*. Fix the source first; add the room to a working
source.

**#7. H4 — bounded micro-variation.** Directly addresses Micah's audible
"sameness," but the AR evidence caps it: AR *had* variation (wrong kind)
and was judged equally horrible, so variation is at most a secondary cue.
Its real value is as a cheap, safe, deterministic improvement with a
clean kill test (anchor CV < 1% → dead). Keep at the bottom of the build
queue, not in it.

**#8. H5 — sympathetic coupling.** Smallest predicted effect size (a few
dB of residue under the direct sound), inaudible for staccato motifs,
muddiness risk if gains are wrong. Polish hypothesis. Build last or never.

### KILLED — dead on arrival (kill loudly, as instructed)

- **Any hypothesis reducible to "fix recurrence/timing drift."** Frozen by
  the decisive evidence: recurrence 1.000000 vs 0.741083, identical
  horror. This includes grid-quantization fixes, drift-correction fixes,
  and "humanize the timing" as a primary rescue.
- **Plan-side timing-only theories** (metronomic-grid horror vs drift
  horror): predicted a flavor change between clips 1/2 and 3/4; none was
  heard.
- **Additive-sine resynthesis as a fix** (correct F0 + static harmonic
  stack): this is V11's PARADD pathology in pure form; the T4 trap exists
  to execute it. Any fork that is secretly this dies at the trap, before
  ears.
- **Reverb-as-rescue promoted to primary cause.** Room does not create
  source physics. H3 stays a secondary module inside a working renderer.
- **Anything requiring true randomness** in the synthesis path: banned by
  standing law. Hash streams (h01/SHA-256 counter mode) are deterministic
  signals, not RNG — allowed, but every use gets a named audit line and
  byte-identical rerun proof.

### 1b. Testability (cleanest killer first)

1. H2 — two-window centroid/inharmonicity contrast on existing clips +
   anchor. One measurement, binary outcome, no new build.
2. H1 — partial envelope correlation r_bar on existing clips + anchor.
   Binary outcome (anchor in [0.55,0.95] AND render at 1.000/≤0.15).
3. H3 — T60 per band + cepstral early reflections on existing clips +
   anchor. Binary.
4. Plan/render seam — the repaired 2×2 (§2): committed decision rule,
   four cells, falsifiable in both directions.
5. H4 — repeat-CV on anchor; dies cheaply if anchor CV < 1%.
6. H6 — repertoire-conditional; needs sustained notes to even apply.
7. H5 — smallest effect, hardest to isolate from H3's room measurement.

### 1c. Buildability under zero-RNG / deterministic constraints

All six are buildable; none needs true randomness. Ordered by
implementation risk:

1. H4 — pure function of (piece_id, note_index, param_id) via h01. Trivial.
2. H6 — fixed LFO + depth envelope; FM via fractional delay. Low risk.
3. H2 — three deterministic branches + crossfade. Medium-low risk; the
   strike-partial B constants need an instrument table (measure or set
   from literature, then freeze).
4. H1 — modal bank + fixed mode-shape vector. Medium risk (fixed-point
   resonator stability at low R; validate pole radii < 1 in the chosen
   precision).
5. H5 — sympathetic bank fed from the mix bus. Medium risk (gain staging;
   muddiness).
6. H3 — image-source early reflections are easy; the **Hadamard FDN is
   the load-bearing risk**: literature FDNs use random orthogonal
   matrices, and the fixed-Hadamard substitution must be validated
   against eigen-frequency ringing before it ships. Deterministic, but
   not proven innocent. This is the one module I'd red-team separately.

## §2. PLAN-vs-RENDER: THE 2×2 NEEDS REPAIR — COMMITTED REPAIRS

**Verdict: the 2×2 stands in structure, but it does not stand as written.
Four repairs, then run. Plus one sharper test that runs BEFORE it.**

### Repair 1 — the single-note pre-test (the sharper decisive test).
Before composing P_HUMAN or building R_PHYS: take ONE isolated rendered
note from R_CUR and score it against the frozen discriminator's timbre
bars (F1–F6), plus a blind single-note ABX vs a real anchor note.
- If the single note fails (predicted: it will — HNR ~0 dB alone
  condemns it), the render-side case is proven at the note level with
  zero plan confound, and the 2×2's job shrinks to quantifying the
  *plan's marginal contribution* rather than adjudicating the primary
  cause. This is cheaper, faster, and cleaner than the full factorial.
- If the single note PASSES the timbre bars, the render case as stated
  is dead and the loop pivots to plan/content immediately — the 2×2
  becomes the main event rather than the follow-up.
This pre-test is the falsification-first move the whole loop should
have led with. Meters before renderers.

### Repair 2 — reframe the decision rule around C vs D, not B vs C.
Given the measurements, the "B passes → plan dominates" branch is
near-empty: no plan makes an inharmonic renderer pass timbre bars, and
the predicted scoreboard already concedes B fails F1–F6/F8. The live
question is the C/D contrast:
- C (P_TNN + R_PHYS) passes everything except F7/F7b and the blind judge
  calls it real → **render dominates**; timing microstructure is
  second-order.
- Only D (P_HUMAN + R_PHYS) passes → **both necessary**; the loop moves
  to plan-render co-design next (and TNN-composed expressive plans become
  the follow-up loop).
- D fails every bar → exhaustion: phoniness is neither the event plan
  nor the source model — suspect motif CONTENT (melodies no human would
  write) or a broken discriminator. Report per UNPHONY_BAR_V1 §7(c).
- Keep the B branch for honesty (if B passes, I concede the plan case),
  but label it decorative until a harmonic renderer exists.

### Repair 3 — R_PHYS must guarantee harmonic sustain, not just attack
physics. As specified (§1C), R_PHYS is "excitation burst + formant filter
bank + room" — but nothing in that spec forces the *sustain* to be
harmonic. A formant bank driven by silence after a 20 ms burst is still
an inharmonic renderer, and then C's failure would be misread as "plan
matters." The module spec in §4 Build 2 fixes this: a periodic sustain
source (modal bank per H1) is mandatory, with the attack burst as a
parallel branch. The experiment tests a *complete* physical source model
or it tests nothing.

### Repair 4 — freeze the event schema AND the onset-detection fallback
before the run. Adopt hyp B §3.3: log detected-onset counts per file; if
<60% of planned onsets are detected, score F7 INCONCLUSIVE, not fail.
A renderer whose onsets are undetectable mush must not launder a timbre
failure into a plan failure.

**Commitment (judge's):** the render side is the provisional favorite
(§1a #1), but the 2×2 — repaired — is the instrument that can kill it.
The single-note pre-test is the cheapest shot the render case will ever
get; if it misses, I abandon render-dominance without complaint.

## §3. DISCRIMINATOR: FINAL FEATURE LIST + FREEZE PROCEDURE

**Verdict: keep all 8 features; harden, don't cut. The hardening is the
bundle rule, not any single feature.**

No single feature is load-bearing by design (hyp B §2A): Prong 1 requires
ALL bars passed, so gaming one feature buys nothing. That is the real
anti-gaming defense, and it holds. Feature-by-feature disposition:

- **F1 (median voiced HNR, band [5,20] dB):** KEEP. Now the highest-signal
  bar: current renders sit at −2..0 dB, real pitched music at +10..20 dB.
  Harden: the "mix noise to land in band" game is caught by F2/F5
  conjunction — write that conjunction into the bar's freeze notes.
- **F2 (formant-frame fraction):** KEEP. The V11-grounded bar (0–3%
  renders vs 30% real voice; instrumental analog frozen per anchor
  class). Strongest physical-model signature in the set.
- **F3 (centroid mean + dispersion):** KEEP, HARDEN: F3b (dispersion) is
  gameable by a brightness LFO. Add the cross-check to the frozen recipe:
  an F3b pass is valid only with an F6 pass; F3b-pass/F6-fail scores
  F3b INCONCLUSIVE (free wobble, not living timbre).
- **F4 (attack ZCR ratio):** KEEP. The T7 trap (2 ms clicks + hard-cut
  tails) is its named killer — clicks drive the ratio the *wrong* way.
  Keep T7 mandatory.
- **F5 (formant glide):** KEEP. The anti-static-filter bar; a static
  2-formant fake passes F2 and dies here.
- **F6 (brightness–dynamics coupling):** KEEP. Hardest to fake without
  real physics (a dynamics-driven lowpass moves centroid without moving
  formants → dies on F2/F5; T10 trap covers it).
- **F7/F7b (IOI CV + timing–dynamics correlation):** KEEP — deliberately
  plan-side, so the instrument can catch plan phoniness and the 2×2's B
  cell gets a fair timbre-independent hearing. With the §2-Repair-4
  inconclusive rule.
- **F8/F8b (decay slope + tail variance):** KEEP. F8b (tail variance
  >15% of mean) is what kills fixed-tail fakes and the T11 Frankenstein.

**Traps: keep all 11 (T1–T11).** T8 (current horrible renders must fail a
majority of bars) is the negative control that keeps the instrument
honest; T4 (additive-sine resynthesis) is the single most important
phony-trap. T11 license note stands: anchor audio as an INTERNAL attack
probe only, deleted after the trap run, bytes never enter any fork —
and the trap log records the deletion.

**Freeze procedure (per UNPHONY_BAR_V1 §2 — addendum before first fork
judged):**
1. Select motif-class anchors: anchor A + a second real recording B
   (different performer/piece, same class). Record file IDs + SHAs in
   the addendum. No fork is judged against an anchor chosen after the
   fork was heard.
2. Run the instrument on A, B, and A-halves (first 50% / second 50%).
   Set each bar [lo,hi] to cover observed real variance with 20% margin,
   never narrower than the two-recording spread (T1's anti-overfit rule).
3. Run all 11 traps; all must behave as specified. Any misbehavior →
   fix the recipe, re-run ALL traps, re-freeze.
4. Determinism gate: run the instrument twice on the same file;
   measurement vectors must be byte-identical.
5. Commit instrument source + measurements + trap log (incl. T11
   deletion record) + bar values with a Micah-visible version tag.
   Frozen. Amendments need his sign-off (V2); the frozen copy stays in
   git history.
6. **Do not freeze on the crude proxy.** The clip_measurements.txt HNR
   is labeled crude; freeze bars only on the calibrated instrument's
   own numbers.

## §4. BUILD SHORTLIST (max 3, falsification-first order)

### BUILD 1 — Calibrated meter battery (meters before renderers)

**Module spec (pure Zag, deterministic, integer/fixed-point):**
- `meter_hnr(path) -> i32 milli_dB`: 4096-sample frames, hop 1024,
  normalized autocorrelation lags 88..882 (50–500 Hz); frames with
  max r < 0.30 skipped as unvoiced; per-frame
  HNR = 1000*log10(r_max/(1−r_max)) via integer log table; median
  over voiced frames.
- `meter_attack_contrast(path) -> (i32 centroid_delta_mHz, i32 b_ratio_milli)`:
  energy-flux onset detector (10 ms frames); window A = 0–30 ms
  post-onset, window B = 120–400 ms; spectral centroid per window
  (46 ms Hann, 75% overlap, 0–12 kHz, fixed-point FFT); inharmonicity
  B fit per window by least-squares of partial peaks 1..8 to
  f_n = n*f0*sqrt(1+B*n^2); report C_A − C_B and B_A / B_B.
- `meter_partial_corr(path) -> i32 r_bar_milli`: f0 per 46 ms frame
  (autocorr), heterodyne partials 1..8, amplitude tracks A_k(t),
  mean off-diagonal Pearson r × 1000.
- `meter_room(path) -> (i32 t60_lo, i32 t60_mid, i32 t60_hi, i32 early_reflect_flag)`:
  Schroeder integral on post-offset tails in 3 bands; cepstral
  rahmonic peak search at 5–40 ms quefrency.
- `meter_repeat_cv(path, plan_onsets) -> (i32 cv_milli, i32 slope_milli)`:
  per-note RMS + centroid across motif repeats; CV and variance-vs-index
  slope.
- Plus the 8 discriminator features F1–F8 per §3 recipes.
- `determinism_selftest()`: two runs, byte-identical vectors, else the
  instrument does not ship.

**Frozen prereg:**
- Claim: the calibrated meters reproduce the crude-proxy direction on
  the 4 clips (render HNR ≤ +2 dB; real anchor HNR ≥ +5 dB) and show
  real-vs-render gaps on the H1/H2/H3 decisive measurements at or above
  the predicted margins (H2: C_A−C_B > 800 Hz real vs < 200 Hz render;
  H1: anchor r_bar in [0.55,0.95] vs render ≥0.999 or ≤0.15; H3: anchor
  T60 ≥ 0.25 s in ≥2 bands vs render < 0.1 s).
- Kill bar: any decisive measurement whose gap fails to appear kills
  that hypothesis WITHOUT a renderer being built. If calibrated render
  HNR lands within 3 dB of the anchor, the "inharmonic throughout"
  synthesis (§1a #1) is dead and H2-attack becomes the lead.
- What gets measured: full vector on all 4 clips + anchor A + anchor B.
- "Genuinely better" numerically: the battery discriminates current
  renders from the real anchor on ≥ 6 of 8 features, all 11 traps
  behave, determinism gate passes. (This build's "better" is
  discriminative power, not audio quality.)

### BUILD 2 — R_PHYS v1: physical source renderer (repaired per §2)

**Module spec (pure Zag, zero RNG, byte-identical reruns):**
- `excitation_gen(note_id:i32, vel:i32) -> {burst:[]i16, pulse:[]i16}`:
  (a) attack burst: SHA-256 counter-mode stream seeded by note_id,
  8–25 ms, through 2 FIXED biquads (bandpass 2–6 kHz coefficients
  frozen as integer constants), gain = vel_table[vel]; (b) sustain
  pulse train: phase-accumulator saw-ish pulse at f0_target (integer
  period table), 2–4 ms raised-cosine hammer shaping for struck
  voices. Both deterministic; audit line in source: "no RNG —
  hash stream only."
- `strike_module(note) -> []i16` (H2, 0–60 ms): 8 partials at
  n*f0*sqrt(1+B_strike*n^2), B_strike = 5–10× the sustain B from the
  instrument table (frozen constants); each partial an independent
  2-pole resonator with R from tau 15–60 ms; pitch overshoot
  f0(t) = f0*(1 + 0.02*exp(−t/20ms)) as a phase-rate multiplier
  (fixed-point exp table); equal-power crossfade to sustain at
  30–60 ms.
- `modal_body(excitation) -> []i16` (H1): 8–16 parallel 2-pole
  resonators, y[n] = b0*e[n] + 2*R*cos(theta)*y[n−1] − R²*y[n−2],
  (f_k, R_k, gain_k) from frozen instrument table; gains from a fixed
  mode-shape vector; shared excitation in → correlated envelopes by
  construction. Pole radii validated < 1 in the build's fixed-point
  precision (CI check).
- `vibrato_gen(note_t_ms) -> i32 cents_offset` (H6, optional module,
  independently killable): 5.2 Hz phase-accumulator LFO; depth 0 cents
  <150 ms, ramp to 25 cents by 400 ms, hold; applied as FM via
  fractional delay on modal_body output (body resonances convert FM
  to coupled AM for free). Kill rule: if blind listeners rate
  vibrato-on MORE phony, the module is deleted, not tuned.
- `room_send(mix) -> []i16` (H3): early reflections — image-source,
  8–12 taps, delays/gains closed-form from frozen room constants;
  per-note source height = deterministic function of MIDI pitch;
  late tail — 6-line FDN, prime-ish delay lengths (frozen), feedback
  = FIXED Hadamard matrix (the flagged substitution); RT60 0.4 s;
  wet gain from frozen distance model. Eigen-ring validation tones
  run at build time; any matrix resonance above −40 dBFS blocks ship.
- Pipeline: excitation → strike (0–60 ms) → modal_body → vibrato →
  mix bus → room. Sympathetic bank (H5) and micro-variation (H4)
  explicitly EXCLUDED from v1 (separate kill tests, no scope creep).

**Frozen prereg:**
- Claim: R_PHYS renders of the P_TNN motif plan pass all timbre bars
  F1–F6 and F8 within frozen real variance (F7/F7b may fail — predicted).

- What gets measured: frozen discriminator vector per render; blind

## §5. CONFIDENCE + THE SINGLE MOST LIKELY WAY I'M WRONG

**Confidence:** ~70% that the dominant cause is renderer-side missing
source physics (no harmonic sustain + no attack regime + no body
resonances); ~55% on the internal ordering (#1 harmonic-sustain deficit
over #2 attack). ~80% that the falsification-first order (Build 1 before
Build 2) is correct regardless of which component dominates — the meters
are cheap and every hypothesis in §1 carries a meter-killable prediction.

**The single most likely way I'm wrong:** the crude HNR proxy is
misleading about the sustain. If the calibrated meters show the current
renders ARE harmonically structured in sustain (r_max high, proxy was
fooled by beating/detune or windowing), then the whole "inharmonic
throughout" synthesis collapses: #1 falls to #4, H2-attack becomes the
clear dominant cause, and Build 2's modal-body sustain engine is solving
a problem the renders don't have — the fix would be attack-regime
physics on top of the existing sustain. This is exactly why Build 1 runs
first and why its kill bar names this branch explicitly. Second-most
likely: the plan's event schema is so impoverished (zero releases, flat
velocities, hard note boundaries) that no renderer rescues P_TNN — the
2×2's D-only branch — in which case the loop's real work is a planner
that imagines acoustic scenes, not note lists.

**Provisional → Final:** when the calibrated meter results land, I
re-score §1a against measured (not proxy) numbers; when grok-4.7/fable-5.1
outputs land, I check for mechanisms my ranking missed (especially any
plan-side mechanism sharper than event-schema impoverishment, and any
attack on the discriminator's trap coverage). Anything that moves a
kill bar moves the FINAL verdict, loudly.
