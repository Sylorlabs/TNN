   synthesis without fixing it, and here the arithmetic is brutal:
   convolving an inharmonic source (HNR -2 dB) with a room gives an

   Technical risk, flagged by the doc itself and not resolved: the
   FDN's Hadamard feedback matrix. Literature uses random unitary
   matrices because fixed structured matrices produce audible
   coloration — a real symmetric Hadamard matrix has real
   eigenvalues and, with commensurate-ish delay lines, rings at the
   matrix's eigen-frequencies: metallic phoniness ADDED by the fix.
   "Must be validated to not ring" is not a plan; it is a hope.
2. Contradiction with evidence: the doc says demote H3 "if ANY of

3. Constraint check: clean on RNG (Hadamard substitution is

4. Verdict: WOUNDED. Exact repair: (a) prove the Hadamard FDN does

2.4 The 8-feature discriminator — WOUNDED (one recipe bug, gaming gaps)
--------------------------------------------------------------------
RECIPE BUG — F2 false-positives on harmonic stacks. F2 counts LPC-
12 pole pairs with bandwidth < 400 Hz, center 200–3500 Hz, as
"formant-like," with NO harmonic-coincidence rejection. An order-12
LPC on a static harmonic stack places narrow poles ON the
harmonics (partials are spectral peaks; bin width at 2048 samples
is ~21.5 Hz, so harmonic peaks are far narrower than 400 Hz).
Result: the very additive-sine renders F2 is meant to fail (trap
T4) can PASS F2 by accumulating "formant-like" poles at harmonic
frequencies. F5 (glide of the lowest such pole) then measures
nothing physical. Note the tension: V11 measured 0% formant frames
on ARTIC with SOME method — either that method had harmonic
rejection the B-recipe omits (then the recipe underspecifies the
proven method — fix by porting it), or the recipe as written is
vulnerable (fix by adding harmonic-coincidence rejection: poles
within ~±30 Hz of n·f0 don't count — or estimate the spectral
ENVELOPE via cepstral liftering instead of raw LPC peaks). This is
checkable on trap T4 TODAY: if T4 passes F2, the instrument is
broken and every F2/F5-based conclusion in the 2x2 is void.
SPEC GAP — F1 undefined on zero voiced frames. The recipe says
frames with max r < 0.30 are skipped; on the current renders
(and trap T6) possibly NO frames are voiced. The median over an
empty set is undefined — NaN handling could accidentally pass,
fail, or crash. The T6 note says "F1 undefined → scored as fail,"
but the F1 recipe doesn't state the rule generally. Repair: "zero
voiced frames → F1 = FAIL (explicit)" in the recipe, tested by T6.
GAMING ANALYSIS, per feature:
- F1 (HNR 5–20 dB): gameable as admitted (noise mixed into sines)
  AND by a subtler route — adding a weak periodic component at ANY
  f0 raises r_max into the band, and pitch accuracy is explicitly
  NOT measured (§2E). A mistuned-but-periodic fork passes F1.
  Caught by F2/F5 only if those work (see recipe bug above).
- F2: gameable by a static 2-formant filter (admitted); the
  harmonic-pole bug above makes it gameable by doing NOTHING.
- F3b (centroid dispersion > 150‰): gameable by ANY slow
  modulation — a brightness LFO with no musical function passes
  the number. F6 is the designated catcher, but see below.
- F4 (ZCR ratio > 1500‰): the fixed windows ([n0,n0+1323],
  [n0+22050,n0+30870]) assume notes ≥ ~700 ms; on short-note
  motifs the sustain window lands in the next note. The "no new
  onset inside" guard exists — but if it triggers on most notes,
  F4 is computed over a tiny surviving N with no minimum-N rule.
  Add: require ≥ 8 valid onset pairs, else INCONCLUSIVE (not fail).
  Gaming: T7 covers clicks; a fork that gates noise by its own
  onset detector passes F4 by CONSTRUCTION — which is fine,
  because that IS an excitation model. Convergent gaming is not
  a bug here.
- F5: inherits F2's bug. Additionally, "random formant jitter
  would pass" is hand-waved to Prong 2 (ears). Ears are the
  backstop for everything, which means the bars are not the
  discriminator — the judge is. Say so explicitly.
- F6 (brightness–dynamics r > 0.4): gameable by a deterministic

  F2/F5 catch the lowpass fake (filter sweep moves centroid

  The defense chain has a single point of failure.
- F7/F7b: F7b (timing–dynamics r > 0.25) is gameable by a
  non-musical deterministic formula (longer = louder, always).

  cell C=(P_TNN,R_PHYS) is PREDICTED to fail them, and the

- F8/F8b: offset detection ("RMS drops > 12 dB within 100 ms,
  stays low ≥ 200 ms") fails on legato phrases with 40–80 ms
  overlap (P_HUMAN's design!) — offsets may never register, N
  collapses, per-mille over tiny N is noise. Add minimum-N and
  INCONCLUSIVE (not fail). F8b's variance check (> 15%) is
  gameable by hash-varying tail lengths per note — deterministic
  and probably harmless (real tails do vary), so not a kill, just
