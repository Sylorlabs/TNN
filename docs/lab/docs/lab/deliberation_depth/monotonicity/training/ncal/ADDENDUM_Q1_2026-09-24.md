## 1. Label-imputation assumption (for B9X release redesigns)

`necc_input.tsv` encodes abstained cells as `correct=0` (placeholder; the v1
matrix only ran confidence on released cells). Verified pre-run: across all 1000
items × 7 depths, the `correct` label among released cells is CONSTANT per item
(1000/1000 label-constant, 0 label-changing, 0 never-released). B9X inputs impute
each abstained cell's true label from its item's released cells. This is a
deterministic, verified property of the frozen matrix, not invented data; it is
disclosed here and in every B9X result. If the counterfactual "what would an
abstained cell's judgment have been" differs from the constant, that is a caveat
on B9X, recorded in VERDICT_Q1.md.

## 4. Decision rules (restated from V3 §1; applied to measured s1 A/B/C results)

- **Q1a:** the v1 impossibility proof survives ONLY if (i) no in-class mechanism
  in the §6-compliant search clears the step, (ii) no ORACLE clears it, and
  (iii) exactly the predicted premises are load-bearing under constraint
  variation. Otherwise the "proven" claim is STRUCK and the residual is
  classified by the refuting evidence (KNOWLEDGE if ORACLE clears and in-class
  does not; SELECTION if a B9X clears; MARGIN-LEDGER or CEILING-STRUCTURE per
  the clearing in-class mechanism; JOINT if the clearing direction breaks other
  bars, naming them).
- **Q1b/c:** KNOWLEDGE iff ORACLE clears and B9X/in-class do not;
  SELECTION-ARCHITECTURE iff a B9X design clears with B1/B2/B4–B8 held and B13
  not worsened (B9 and the O-rise B3s excluded by design); ARCHITECTURE-deeper
  iff none clear — then prove/refute the survivor-mean lemma in Zag (lemma
  statement to be committed before the proof attempt).
- The "proven"/"structural" v1 claims are not accepted on authority; any claim
  contradicted by measurement is struck in VERDICT_Q1.md with the refuting
  numbers.
