## 2. Organs fighting — the fable round

One deep batched round: `docs/lab/onebrain/fable-organs-fighting/`.

**Headline:** figure-it-out deliberation beats rigid policy in 3 of 4 conflict
classes — but only with mechanical circuit-breakers (bounded rounds,
escalation, weight gaps). Unbounded deliberation loops; silent winner-picking
corrupts the ledger. The deciding failure modes are all ledger failures:
silent winner-picking, silent contamination, silent override.

**The 9 principles** (mechanism vs governance marked):
1. PROVENANCE AUTHENTICATION (mechanism) — every op carries a
   signed/ledger-chained origin ID; forged origin rejected pre-execution.
   Load-bearing: without it every other principle is underminable.
2. WEIGHTED CONFLICT RESOLUTION (hybrid) — W_H > W_C > W_S > W_P; higher
   weight wins iff the gap exceeds governance threshold Δ; else ledger a
   collision and escalate.
3. MANDATORY DEPENDENCY LEDGERING (mechanism) — promote/surface records a
   dependency DAG; status changes flag dependents for re-evaluation. Taint is
   recomputable, not permanent.
4. COLLISION LEDGERING + BOUNDED DELIBERATION (mechanism) — N-round bound
   (e.g. 10): worst case escalates (= rigid policy), best case resolves.
5. PROVISIONAL VISIBILITY + MANDATORY TAGGING (mechanism) — provisional is
   visible but flagged; invisibility is silent killing.
6. CORROBORATION REQUIRES EPISTEMIC INDEPENDENCE (governance) — sources
   sharing a false root are one source; unknown independence treated as
   single-source.
7. ESCALATION TRANSPARENCY (mechanism) — escalation entries carry both sides'
   provenance, deliberation history, human-readable summary. Kill bar: one
   missing-field escalation → FAIL.
8. QUARANTINE REHABILITATION (hybrid) — un-quarantine only on corroborated
   independent evidence; threshold governance-tunable.
9. LEDGER IMMUTABILITY, APPEND-ONLY REVISIONS (mechanism) — revisions append
   referencing entries; replay to any T is exact.

**What NOT to do:** majority-vote without independence; absolute pins (dogma
machine); invisible-until-promoted provisional; LLM/probabilistic tiebreaker
(violates determinism — escalate instead); deleting old ledger entries;
fixed organ precedence for all conflicts.

**Open questions:** replay-cost budget for dependency re-evaluation (DoS
vector); circular-dependency detection; escalation policy when governance is
offline (fable recommends provisional-commit-flagged-pending-review,
untested); weight arithmetic with per-source confidence; retroactive
independence re-computation; key compromise handling; organ-level distrust
learning.

**6 discrimination batteries (3A–3F)** specified in the round, preregisterable:
weighted pin-vs-revoke (W_H=100, Δ=20: single-source and 5-source revokes
rejected, 10-source succeeds); dependency ledgering + lazy re-eval; collision
+ bounded deliberation (exactly N=10 rounds then escalation); figure-it-out vs
rigid policy on contradicted promotion (rigid passes initially, fails the
T+20 extension); provenance authentication end-to-end (3 frozen attacks must
be rejected pre-execution); epistemic independence vs vote-counting
(5 sources downstream of one false root must NOT promote).

**Status:** the 9 principles are APPROVED as laws by Micah; adoption pending
long-horizon testing. Still his call: weight/threshold values,
offline-governance escalation policy, key-revocation policy.

## 5. i32 OFFSET RULE — the compiler bug, closed

`docs/lab/toolchain/i32/` — full report + 49 reproducers + full-tree audit.

**Root cause (predictive, not dice):** native codegen compiles `as []i32`
indexing with ×8 byte scaling, and consecutive blocks sit
round_up_pow2(B)+8 bytes apart — so `b[t]` ≡ `a[S(B)/8 + t]` in source
indices. 30/30 measured offsets match across B=16…2048, counts 2–5, mixed
sizes, interleaves, pre-allocs. Toolchain SHA-256 pinned in the report.

**Full-tree audit:** all 10,587 `.zag` files swept. 7 suspect functions in 4
files (2 byte-identical copies). `thincert.zag` (plus armc-rerun copy) NEEDS
RE-VERIFICATION for the 2026-09-20 gate evidence + armc-rerun re-derivation —
both feed the unsigned Arm C gate amendment. Byte-identical rerun of the old
binary is NOT sufficient: rebuild from the arena sources
(`redteam/certifier-rebuild/thincert_rb.zag`) and rerun. Arm C stays parked.
The CERT RV3 0-flips claim is provably benign (13/14 old/new agree
byte-identical; crash inputs never occurred historically). `as []i64/u64`
re-verified clean — the old "u64 corruption" was a victim of a neighboring
mistyped array, not a u64 defect.

**Standing rule:** never use `as []i32/u32/u16` for indexed tables — `[]u8`
arenas with explicit little-endian accessors.
