## Normalizer note (EN)
The delivered EN binary does not emit the prereg's stderr `TR` contract: it
writes prose traces + `A`/`T` lines all to stdout. `trial/normalize_en.py`
(documented, mechanical only — byte-verbatim split, no rewording) converts EN
stdout → `run.out` (`T`/`A` lines) + `run.err` (`TR turn=N ut=N` opener +
`TR`-prefixed prose). `ut=` is taken from the frozen battery's DIALOGUE type
token. Deliberately dropped: `X <expected>` echoes (on flip probes the battery
E-line is the NEW answer containing the flipped token — including it would pass
the token check spuriously), `RESULT`/`DIGEST` summaries, headers. grade.py
was NOT modified.
