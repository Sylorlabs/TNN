1. Verdict on "honest prediction": wrong layer, and — worse — wrong object. The core error is the shape of the calibration object, not the planner's honesty about it. Flat-probe calibration is a pointwise map requested→actual per atom; the renderer under a moving contour is a stateful system — realized F0 at frame t depends on phase-accumulator history, atom/resonator state, envelope state. It's a functional, not a function. "Honest prediction" changed the planner's confidence in a mis-shaped model without reshaping it. The smoking gun: t11 was never in the diagnosed mechanism class (t8/t12/t14) and regressed 80→588 — a mechanism-targeted fix that craters an out-of-class fixture isn't fixing a mechanism, it's redistributing error. The structural tell: the fix was derived entirely from existing flat-probe data — zero new measurements of the disputed phenomenon; it never rendered a single moving contour to test whether predictions were realizable. The entanglement it ignored: "measured probe bias" is measured through YIN over a rendered WAV, and YIN's period estimate is itself contour-dependent — so part of the "measured bias" may be the tracker, not the renderer. On the action-space question: possibly, and it's checkable — if the planner speaks Hz-contours while the renderer realizes quantized contours, honesty about the wrong units can't save it. Process critique: battery mean 425→380.5 passed a gate while two fixtures cratered — add a regression gate to acceptance (with byte-identical determinism, any regression is real; mean-based gates will keep passing bias-shuffling fixes).

2. Three broad mechanisms:
- M1 — Contour-conditioned calibration (make the calibration object an operator). Parameterize contours θ = (F0 center, glide span/rate, vibrato rate/depth, onset rate); probe the full grid over θ and fit per-atom bias as a smooth function. Bets: the bias functional is smooth and low-dimensional in θ — a finite grid spans it, intra-class variation small. Falsify: hold out grid nodes and midpoints; if median interpolation error on held-out θ ≥ ~1/3 of the local bias magnitude, the functional isn't grid-spannable — kill M1.
- M2 — Inverse control in renderer-native space (calibration as pre-compensation). Invert the direction: learn "what must be requested so the output is Y" per atom, fitted on moving-contour probes; stronger variant: re-encode planner output in the renderer's native quantized units. Bets: the renderer's contour transfer is injective and well-conditioned over the operating set — no dead zones/flat regions. Falsify: LSB sweep — request contour pairs differing by the smallest expressible increment (1 F0 LSB, 1 frame shift); if outputs don't move or move non-monotonically, no inverse exists there — kill M2.
- M3 — Closed-loop replan (retire open-loop calibration as sole mechanism). plan → render → measure (same pipeline as scoring) → residual in measured space → fixed correction iteration. Bets: the plan→measured-output map is locally contractive at the fixtures' operating points — sign-stable, gain < 1. Falsify: perturbation probe — from base plans apply ±δ edits to contour parameters and measure output deltas; if signs flip or gains exceed 1, the loop isn't contractive — kill M3. Note: M3's objective measures in YIN-measured space, so it absorbs tracker bias rather than fighting it — correct if err_pm's pitch component is measured the same way. Ordering: M3 first (weakest assumptions; determinism converts the renderer from liability to asset).

3. The distinguishing experiment: telemetry decomposition. One protocol that assigns the contour-dependent bias to a layer by construction, not by behavior: (1) Instrument the renderer (deterministic code you own) to log internal realized frequency at full precision; (2) canonical contour battery: flat, glides ± at 3 rates, vibrato at 2 depths × 2 rates, matched to the fixtures' speech contours; (3) for each: request f_req(t) → render → (a) read internal f_int(t), (b) run standard YIN → f_yin(t); (4) decompose: e_renderer(t) = f_int(t) − f_req(t) (true transfer error); e_instrument(t) = f_yin(t) − f_int(t) (tracker error on moving contours); (5) validity control: synthesize the same contours with an offline float/trig gold renderer (zero production constraints). Decision rule (integrate |e| per contour, pre-register the gate): if ∫|e_renderer| < ~20% of total → the "measured probe bias" is predominantly the instrument; fix the probe before any calibration work — M1/M2 fitted to current probe data would faithfully calibrate the tracker's artifacts. If ∫|e_renderer| dominates → genuine calibration transfer failure; M1/M3 apply directly, M2's sweep maps the dead zones. Both material → measurement first, unconditionally: a calibration fitted on biased measurements is useless. Why this over a behavioral A/B: behavioral tests conflate the two error sources. Order of operations: telemetry decomposition (hours, no architecture change) → regression gate added to acceptance → mechanism earned by a measurement.
