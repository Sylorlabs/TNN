# Amendment 2026-09-27 — D2-3: D2 P4 — order templates instead of ordered part-pairs

**Status: APPROVED by Micah, 2026-09-27** (signed individually, recorded in
`SIGNOFF_2026-09-27_D2.md`, item D2-3). Enacted 2026-09-27.
The frozen prereg text is left byte-intact; this dated amendment governs.

## What it changes

D1's interference check compares pair (i,j) against its reverse (j,i) —
e.g., reverse-then-dupfirst vs dupfirst-then-reverse. D2's three sub-skills
combine in *orders* (forage-first vs ward-first templates), so the check
compares order templates (FW vs WF accuracy) using the same 0.25/0.75
asymmetry numbers. The numbers don't move; only the unit being compared
changes, because D2's compositions are sequences, not pairs.

`PREREG.md` (frozen 2026-09-27, commit `6ca9e042110ca`), §3:

> - **P4 — interference analysis:** per ordered-pair accuracy table.
>   Systematic order asymmetry (pair (i,j) ≤0.25 while (j,i) ≥0.75, parts
>   mastered in isolation) → (d).

>   the unit moves from ordered part-pairs to order templates.

## Why

D2's compositions are temporal sequences of three sub-skills, not ordered
pairs of string rules. The interference the P4 check is designed to catch —
the agent can compose in one order but not the reverse — has a direct
analog: forage-first (FW) vs ward-first (WF) order templates. Comparing
template accuracies with the same 0.25/0.75 asymmetry numbers preserves the
bar's meaning and severity while matching D2's structure. The elig-set and
actual-(c)-only reclassification fixes from the D1 red team (3b) are wired
in.

## Evidence

- `docs/lab/composition/d2spec/D2_INSTRUMENT_SPEC.md` §8 P4 (order-template

- FWF is excluded from P4: its sandwich structure is not an order pair,
  and the spec tests asymmetry on FW vs WF only.
- D1's P4 is unaffected: ordered part-pairs stand for text rules.

## Effect

- D2 P4 compares FW vs WF template accuracies on the elig set with the
  frozen 0.25/0.75 numbers; (d) CONFIRMED only when the asymmetry holds
  with parts mastered in isolation.
- No other bar, threshold, taxonomy code, or D1 behavior changes.
