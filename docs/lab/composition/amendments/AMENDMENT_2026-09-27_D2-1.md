# Amendment 2026-09-27 — D2-1: D2 P2 scoring — checkable criteria instead of literal exact-match

**Status: APPROVED by Micah, 2026-09-27** (signed individually, recorded in
`SIGNOFF_2026-09-27_D2.md`, item D2-1). Enacted 2026-09-27.
The frozen prereg text is left byte-intact; this dated amendment governs.

## What it changes

For text rules, "exact match" works — there is one right answer string. For
action sequences, many equally-good paths solve the same scenario (different
routes to the same mote, different foraging orders). Demanding one exact
action string would fail agents that genuinely solved the scenario. The D2
instrument scores each P2 episode pass/fail against checkable criteria
instead: a ward placed before the storm, zero unmitigated storm ticks,
enough motes eaten, alive at the end. The do-nothing probe (P3) keeps
literal exact-match (the all-WAIT action string).

This is the frozen §1.3 definition of correctness applied where literal
exact-match is infeasible — not a new notion of correctness.

## Why

Literal exact-match against one reference action string is infeasible for
action sequences: many optimal paths exist (different routes to the same
mote, different forage orders), so a single reference trace cannot define
correctness. Without this amendment D2 has no fair scoring rule and stays
unbuildable. The criteria are checkable against real sim state (storm
ticks, ward placement, mote counts, energy, survival) — they are the
sub-skills' semantics composed per the scenario's structure, exactly what
§1.3 demands.
