## 5. Leg FE3a — buildability of the sense-revision loop

- Build `fe3a/fe3a.zag` (pure Zag, zero RNG): 10 frozen exemplars, 16
  bytes each (window A = bytes[0..8], window B = bytes[8..16], disjoint);
  sense judgment = 1 iff mean(A) ≥ T; re-inspection judgment = 1 iff
  mean(B) ≥ T; reversal iff the two disagree; revision loop: take the
  first reversal in index order, T −= 1 if re-inspection said 1 else
  T += 1; re-run; stop at zero reversals or 64 iterations; emit the full
  per-iteration trace.
- Frozen exemplars (A, B, label), constant bytes per window:
  (97,103,1), (98,104,1), (99,105,1), (97,104,1), (98,105,1), (99,103,1),
  (101,97,0), (102,98,0), (101,98,0), (102,97,0). T0 = 100.
- Frozen Python prototype prediction (the Zag output must match it
  exactly):
  - it0: T=100, reversals=1(first), errs=10 → T=99
  - it1: T=99, reversals=1, errs=8 → T=98
  - it2: T=98, reversals=1, errs=6 → T=97
  - it3: T=97, reversals=0, errs=4 → STOP. FINAL T=97, errs=4, iters=4.
- Kill FE3a if the 3 runs are not byte-identical (sha256). PASS →
  FE3b is buildable-in-principle (reported; FE3b itself is OUT of scope
  for this crew).
- Note (preregistered): 4 residual errors remain at convergence because
  re-inspection agrees with the wrong A-window judgment on those
  exemplars — an honest property of the toy, not a defect: the bar is
  buildability + byte-identity, both decided by the runs.
