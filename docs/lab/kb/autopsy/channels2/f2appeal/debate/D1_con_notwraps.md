# D1 — CON (NOT-WRAPS): permanent unrecoverability is NOT established

**Camp thesis:** PACKAGE 3 measured three judgment-side members dead on one
threat model, then declared the whole FAMILY permanently unrecoverable. The
retirement's own scope note admits the evidence covers "one frozen adversary
construction (δ ≲ σ band), two frozen senses, six tasks" — the appeal battery
exists precisely because "measured exhaustion" rested on one transform
family, one noise amplitude, one noise distribution, and one draw.

## Argument 1 — The F2 vacuity routing was a mechanism, not a finding

F2 fired at the maximum (P(C|Y=0) = 1.0000, 40/40), but the frozen A2
mechanical rule routed the every-vacuous case to C3 "rather than to
immediate retirement" (verdict §2.2). All 6 (A,task) cells were vacuous —
100% calibration + 100% test consistency. The frozen letter's choice of C3
over auto-retire is a routing convenience, not a measured claim that no
judgment-side member can recover. Permanent language was then attached to a
routing outcome, not to an exhaustion proof: C3's 0.0049 bits measured one
stochastic member at one amplitude, and DPI covers only the deterministic
re-readings where J(T(x))==L(J(x)) held on the FROZEN T family. Nothing in
PACKAGE 3 measured — or claimed to measure — exhaustiveness over the family.

## Argument 2 — The C3 single-amplitude measurement underdetermines noise stability

C3 measured bits = 0.0049 pooled (0.0046 A / 0.0043 B), P(agree) = 0.918,
P(agree|Y=1) = 0.939 vs P(agree|Y=0) = 0.894 — at exactly ONE amplitude
(±300 pcm / ±8 img), ONE draw, ONE uniform-i.i.d. distribution. The recovery
hypothesis PACKAGE 3 never tested: fooled judgments plausibly sit nearer a
decision boundary, so agreement-vs-amplitude curves should separate fooled
from correct judgments — higher amplitude flips fooled while correct holds.
At ±300 both held (0.939 vs 0.894 — nearly the same). That is a null at one
point on the curve, not a null of the curve. No amplitude sweep, no
multi-draw, no structured distribution was measured. Declaring the stochastic
branch dead from a single point is underdetermination, not exhaustion.

## Argument 3 — The DPI argument is transform-specific; the δ≲σ scope note caps the claim

All four camps accepted the DPI consequence — on the frozen transforms
(h-flip / time-reversal / frame-reversal), where J(T(x))==L(J(x)) held for
all 92 test + 93 calibration fixtures on sense A. DPI death was proven for
the FROZEN T family. A different transform with a well-defined label map
(vflip, signflip, fshift) may break the J(T(x))==L(J(x)) identity entirely —
and that was never measured. The verdict's own scope note concedes the
retirement "retires the judgment-side family *for this threat model* — not
a claim about all possible adversaries." If the claim is already scoped to
one adversary construction, "permanent" does no work — and beyond that scope
it claims more than measured. Either way, permanent retirement is
unjustified by the measurements.

## Why G1 alone does not satisfy us

G1 scopes F2 auto-execution to the frozen threat model and forbids automatic
execution against untested threat models. That fixes governance. It does
not fix the evidence. Before any "permanent" language is used we demand:

1. **The exhaustion claim must rest on an explored space, not a point.**
   Permanent retire = R1/R2/R4 return NULL across amplitudes, horizons, and
   distributions — not just C3's one point. G1 scopes the claim; it does not
   supply the missing measurements.
2. **DPI generality must be tested, not assumed.** Permanent retirement of
   deterministic re-readings requires R3 to show the identity holds (or the
   judge breaks, F3-style) under alternative transforms — not just the frozen
   family that happened to be measured.
3. **No silent re-widening.** Any future use of "permanent" beyond the
   frozen construction needs a new preregistered battery (G1 says this), AND
   any reopening under C* must apply member-by-member — one test's NULL
   cannot inherit another member's verdict.

CON's bottom line: the appeal battery, if fully NULL, earns WRAPS. Until
then, the family is parked, not dead.
