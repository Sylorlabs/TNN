Build (from this directory):
  ~/workspace/tnn-lab/toolchain/bin/znc_linux_x86_64_abed8aa1 chan.zag -o chan --no-analyze
Run (3x, byte-identical SHA256 required):
  ./chan <workdir> batch_A.txt batch_B.txt stimclass.txt split.txt \
      variant_A.txt variant_B.txt calrows_A.txt A > out_A.txt
  ./chan <workdir> batch_A.txt batch_B.txt stimclass.txt split.txt \
      variant_A.txt variant_B.txt calrows_B.txt B > out_B.txt
workdir holds the batch files + inputs/*.txt (see ../inputs/, built by
../prep_inputs.py). Binaries and .zagd caches are never committed.
