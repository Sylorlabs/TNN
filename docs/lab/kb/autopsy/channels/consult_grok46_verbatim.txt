1. Human verification: Collect independent human judgments on identical stimulus instances by having observers report whether the change is genuine vs. illusory; causally independent because human perception routes through evolutionarily distinct cortical pathways (e.g., primate ventral stream) not present in ML sensor training, so no shared fooling mechanism. Expected info: ~1.5 bits (humans reliably separate real vs. adversarial perturbations in these classes with >90% accuracy in controlled tests). Fails if human is fooled by adversarial example (rare for listed perturbations) or verification omits exact stimulus match.

2. Cross-modality sensor check: If A (e.g., vision) is suspect, query B's audio judgment on the same adversarial variant and threshold disagreement; causally independent via separate physical transducers (photoreceptors vs. basilar membrane/cochlea) with uncorrelated noise distributions and no joint training objective. Expected info: ~0.8 bits (near-zero mutual information between modalities under matched perturbations). Fails if adversarial attack spans both senses (e.g., motiondir affects both) or A/B pipelines share learned features.

3. Ground-truth stimulus reconstruction: Reconstruct raw stimulus from stimulus ID metadata and compare against adversarial variant via deterministic signal processing (e.g., FFT/IFFT for pitch/timbre or pixel-level differencing for color/shape); causally independent as it bypasses any learned judgment entirely and operates on raw waveform/image before ML encoding. Expected info: ~1.2 bits (reconstruction fidelity directly exposes spectral/temporal artifacts). Fails if reconstruction pipeline itself is corrupted by the adversarial perturbation or ID metadata is lost.

4. Multi-class label consistency audit: Group by perturbation-class label and inspect cross-variant confidence deltas (high-conf wrong judgments should cluster in noise vs. primary); causally independent because class labels are metadata external to the fooled sensor's forward pass. Expected info: ~0.3 bits (weak signal due to known anti-informativeness). Fails if label assignment correlates with fooling (e.g., motiondir perturbations are systematically mislabeled) or corpus is incomplete for a given class.

5. Independent analytic causal probe: Apply non-ML feature detectors (e.g., Hough transform for shape, autocorrelation for timbre) to decode perturbation class and flag inconsistencies with reported judgment; causally independent as these are hand-engineered signal rules, not learned models. Expected info: ~0.7 bits (detects local anomalies in frequency/temporal structure). Fails if adversarial attack mimics natural statistics that pass non-ML detectors or if corpus lacks raw signal data for the ID.
