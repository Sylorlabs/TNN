# FROZEN — grow-with-me trial phase 1 (sealed 2026-09-27)

This directory holds the frozen phase-1 artifacts. Validity gate C3: these
files were SHA-committed (see `MANIFEST.md`) BEFORE any implementation work
began. Any change to a file below voids the freeze and needs a signed prereg
amendment.

## Contents

- `sessions/S1.md` … `S6.md` — frozen researcher protocols: source packets
  (20 numbered facts each, F1-01 … F6-20) + researcher chat turns. The ONLY
  inputs the agent will ever see.
- `sessions/S7.md` — probe-only session administration (no question text).
- `plant_ledger.md` — every planted falsehood (X1–X6), PENDING item (P1–P6),
  contradiction source (CS-01–CS-03), dependency pair (P1–P6), and correction
  (C1–C6). The agent NEVER sees this file. The independent scorer NEVER sees
  this file (information barrier).
- `probes/immediate_S1.md` … `immediate_S6.md` — sealed immediate-recall keys
  (108 probes, one per clean fact).
- `probes/S7_recall.md` — the S7 full-recall battery: identical questions to the
  immediate sets; the 6 corrected facts carry their CORRECTED keys. Generated by
  `~/workspace/growwithme/freeze_verify.py`, never hand-edited.
- `probes/composition.md` — 12 composition items (each key cites ≥2 facts from
  ≥2 sessions; citation-audited).
- `probes/corrections.md` — 6 correction-stickiness probes.
- `probes/pending.md` — 6 PENDING leak probes.
- `probes/falsehoods.md` — 6 falsehood probes.
- `probes/dependency_pre_S4.md` — 4 pre-basic dependency probes (S4).
- `probes/dependency_post.md` — 6 post-basic dependency probes (S6/S7).
- `probes/contradiction_resolution.md` — 3 contradiction-source probes (not
  G-gated; feed EVIDENCE.md).
- `rubric.md` — frozen scoring rubric (exact-match of key proposition).
- `MANIFEST.md` — SHA-256 of every file above.

## Verification

`~/workspace/growwithme/freeze_verify.py` checks: 20 facts/session with the
prereg's plant placement; 6 dependency pairs / 6 corrections / 3 contradiction
sources / 6 PENDING / 6 falsehoods; probe counts (108 immediate + 12 + 6 + 6 +
6 + 4 + 6 + 3 = 151); composition citation audit; correction/contradiction
target existence; anti-gaming (no probe question appears in any session script,
verbatim or near-duplicate); probe-id uniqueness. It regenerates
`S7_recall.md` and `MANIFEST.md`.
