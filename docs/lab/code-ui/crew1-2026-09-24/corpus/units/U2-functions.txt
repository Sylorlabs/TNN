# U2 — FUNCTIONS (manual excerpt; sources: handbook/2/everyday-types.html, handbook/2/functions.html)

## Declarations
- function greet(name: string) { console.log("Hello, " + name); }
- Parameter annotations go AFTER the parameter name: (name: string)
- Return annotation after the parameter list: function f(): number { return 26; }
- Return type usually inferred; annotate for documentation/stability.
- Async: async function f(): Promise<number> { return 26; }  // annotate Promise<T>

## Arity is checked
- Calling with the wrong NUMBER of arguments is an error even without annotations.

## Optional parameters
- function f(n: number, suffix?: string) — optional params LAST, marked with ?

## Function types
- (a: string) => void  — "function taking string, returning nothing"
- Parameter NAME required: (string) => void means param NAMED string of type any!
- type GreetFunction = (a: string) => void;

## Arrow functions + contextual typing
- names.forEach((s) => console.log(s.toUpperCase())); // s inferred as string
- When context gives the type, annotations are unnecessary.

## Generics preview (full unit U5)
- function firstElement<Type>(arr: Type[]): Type | undefined { return arr[0]; }
- Type parameters relate input types to output types.

## Common errors
- TS2345: Argument of type 'X' is not assignable to parameter of type 'Y'.
- TS2554: Expected N arguments, but got M.
- TS7006: Parameter 's' implicitly has an 'any' type (needs annotation under strict).
