`0086932eaa72aa7c839ae05854d1ddff0e686b4050c1fde4f0047c46895d06a4`).

All four FIX variants ported; FIX-A is the adopted diet.

Key porting decisions (full detail in `PORTING_NOTE_FIXA.md`):
- FIX-A anchor count as exact integer math: `need = 19*t - 20*c`
  (== float `ceil((0.95*t-c)/0.05)` on all 84 real class-legs, 0 diffs).
- Skip iff `20*c >= 19*t` (== float `c/t >= 0.95`, 0 diffs).
- `[]u8` arenas + LE accessors throughout (no `as []i32`, ZNC-2026-09-21-007).
- Output streams in 1 MiB flushes (no slice > 2^25; FIX-A s100 output is
  33,273,050 bytes).
- Two bugs caught during development by the byte-identity proof and edge
  inputs: lowercase ID prefixes (fixed before proof), `nio_alloc(0)`
  empty-pool check misfire + undersized anchor-item arena on the trap
  batteries (fixed; proof re-run clean on the final binary).
