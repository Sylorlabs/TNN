## 4. Decision rule (B9X2)

A B9X2 design is an amendment CANDIDATE ⟺ ALL of:
  (a) ceiling/O Gviol = 0 (the O-rises cleared);
  (b) B13 strict violations ≤ 6 (not worsened vs m11 baseline);
  (c) no currently-passing bar broken: B1 = 0, B2 = 0 (V1=V2=0), B4 ≥ 0.50,
      B5 ≥ 0.20, B6 ≥ 0.95 per family, B7 ≤ 0.30.
  (B8 computed and reported, not gated — defective as frozen. B9 excluded by design:
  every B9X changes release by definition. B3-redteam reported as context, not gated:
  the Q1b/c rule targets the O-rises; redteam B3 is Q1a's question and is already failing.)

- If ≥1 design meets (a)∧(b)∧(c): the report names it as a qualified amendment
  candidate with full bar evidence (Micah's call whether to amend).
- If none meets (a)∧(b)∧(c): the "don't amend B9" recommendation is HARDENED — it
  then rests on FOUR searched release designs (FIXED, DECORR, STRAT, GRAD) spanning
  {fix the cohort, decorrelate the selection, hold composition constant, phase the
  cut gradually}, and the report states the exact obstruction each design hit
  (the B3/B13 joint-constraint note from v1 §4 predicts this outcome: on ceiling/O,
  clearing the rise by release means releasing low-confidence items, which deepens
  underconfidence — the two bars pull in opposite directions).
