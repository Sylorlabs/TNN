## 1. Feature semantics (frozen feat.zag)

f1 = clamped margin @t; f2 = t·1000/64; f3 = leader-changed flag (0/1000);
f4 = margin delta vs t−1 (clamped ±1000); f5 = consumed/ne·1000;
f6 = nalive/nh·1000; f7 = sole-survivor flag (0/1000);
f8 = max margin drop along path. All integer thousandths.
**f2 is DELETED from the function class** (the fork's causal bet:
elapsed-depth inflation rides on f2-like signals). f2 is never read by
either the trainer or the policy.

## 2. Marginal yield my (ideas file §(a), RSW definition — exact)

Integer thousandths, clamped [0,1000]. Along one item's ordered depth
rungs (d strictly ascending; d_prev = previous rung's depth):
- first rung: my = f5.
- later rungs: my = min(1000, max(0, f5 − f5_prev)·1000 / max(Δf2, 1)),
  with Δf2 = (d − d_prev)·1000/64.

All operands non-negative after the max(0,·); plain integer division
(truncation irrelevant — numerator ≥ 0). Δf2 > 0 always since d > d_prev.

## 3. Ledger keying (exact)

- m = min(4, f1/200) — 5 margin bins. f1 ∈ [0,1000] ⇒ f1/200 ∈ {0..5} ⇒
  m ∈ {0,1,2,3,4}.
- y = min(3, my/250) — 4 yield bins. my ∈ [0,1000] ⇒ my/250 ∈ {0..4} ⇒
  y ∈ {0,1,2,3}. The bottom bin y=0 is exactly "budget burned, no new
  evidence".
- d_idx = log2(d) ∈ {0..6} for d ∈ {1,2,4,8,16,32,64}. Depth is a STRATUM,
  never an additive input.
- Key q = (m, y); 20 keys × 7 depths = **140 cells**.
  cell(q,d) = (m·4 + y)·7 + d_idx ∈ {0..139}.

## 4. Counting rule (exact)

Per (q, d) stratum, two counters: n = released outcomes, k = released
correct outcomes. Training iterates `features.tsv` in file order
(grouped per battery, per item, depths ascending):
- Per-item chain state (updated for EVERY row, regardless of rel4/heldout —
  yield is a trajectory property): prev_id, f5_prev, d_prev.
- For a row: if id == prev_id, my by the later-rung formula; else my = f5.
- Update rule — **released items only, after the label, heldout=0 only**:
  if heldout=0 AND rel4=1: n[cell] += 1; if correct4="1": k[cell] += 1.
- No learned weights. The ledger (k,n per cell) IS the parameter.
  Emit value: C0 = ρ(k,n) = (k+1)·1000/(n+2) ∈ [1,998]
  (shared interior-ratio invariant; cold start ρ(0,0)=500).

Baked into `src/mey_params.zag` as 280 constant fns (`mey_k<cell>()`,
`mey_n<cell>()`), generated by `train_mey.zag` — never hand-edited.

## 5. Inference path rule (load-bearing — exact)

The eval driver is a BATCH driver: one binary, frozen ordered cell list
(see §6), all 37 legs in one run; per-item cross-depth state lives in
memory (no on-disk state). Per (battery, depth) leg, items in file order;
per (battery, item) state:
(prev rung: f5_prev, d_prev, y_prev, f3_prev, f8_prev; plus Clast = most
recent emitted C on a released rung, undefined until first release).

For each item at leg depth d:
- Run frozen deliberation (cfg identical to policy_f20: shallow/deep rounds
  = d). t = min(d, st.rounds). Compute f1,f3,f4,f5,f6,f7,f8 (f2 skipped).
- my, y, m, cell, C0 = ρ(k[cell],n[cell]) as in §2–§4
  (my uses previous rung of the same (battery,item); first rung my = f5).
- If released (lt == l1; M4 skeleton untouched):
  - C = C0, then caps:
  - if has_prev:
    - trauma: (f3 == 1000 && f3_prev == 0) OR (f8 > f8_prev)
      → C = min(C, Clast − 1), where Clast is the most recent emitted C
      (if the item was never released before, Clast is undefined and the
      trauma branch cannot fire — first release emits C0).
    - else if y < y_prev → C = min(C, Clast) [wasted budget cannot raise
      confidence]. (If never released before: C = C0.)
    - else → C = C0 (clean path, yield nondecreasing: emit ρ even if
      higher than Clast).
  - else (first rung): C = C0.
  - Clast := C.
- Else (abstain): rconf = 0, cert "leader-changed" (frozen convention).
- Update rung state: f5_prev=f5, d_prev=d, y_prev=y, f3_prev=f3, f8_prev=f8
  (always, released or not).

Rationale for Clast-vs-previous-rung: the caps compare against emitted
confidence; an abstained rung emits no confidence, so the comparison is
against the most recent emitted one. The yield bin y_prev is always the
immediately previous rung's (trajectory property).

## 7. Causal-test sidecar (falsification (a) evidence)

Per leg the driver also writes `<battery>_m36_d<depth>_<A|B>.feat.tsv`:
id \t depth \t t \t correct \t rel \t f1 \t f5 \t my \t y \t m \t C0 \t C.
The (a) analysis (analysis/causal_f36.py): per family (ceiling split
P/D/O), restrict to items with nondecreasing f5 at every recorded step;
per (family, depth) cell with n_rel ≥ 30 among those items, compute
mean C and accuracy; least-squares slope of mean-C vs d_idx and of
accuracy vs d_idx. KILL (a) fires iff slope_C > 0 and slope_C > slope_acc.
