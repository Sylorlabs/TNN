# Slice 10 — The adaptivity metric (Track 1: state-dependent deterministic variation)

## 1. Slice
Track 1, slice 10: the quantitative definition of *adaptive* variation — the measure that
separates Arm C (lawful state-dependent expression) from hardcoded sameness (Arm A) and
from seeded RNG (Arm B).

## 2. Falsifiable claim
Arm C's expression variation is **adaptive** iff, over controlled same-input /
different-lawful-state pairs: (G1) the expression choice moves in the preregistered
*predicted direction* at rate ≥ 0.60; (G2) no protected output (verdicts, memory
decisions, integrity refusals, ledger contents) ever changes; (G3) normalized mutual
information between state projection and expression choice is ≥ max(0.30, 5× the
permutation-null 99th percentile); (G4) G1–G3 all hold on held-out *novel* states whose
variable values lie outside the developmental curriculum's visited region. Precondition
(G0): replaying (input, full logged state) is byte-identical 100% of trials. **If any
gate fails, the claim "the variation is adaptive" is dead** — the arm is either
hardcoded, dice, or a lookup table.

## 3. Design
Definitions (all preregistered before the trial). `V_expr`: the Track-1 state variables
allowed to influence expression (e.g. deliberation budget remaining, active-hypothesis
count, conversational priming register). `D`: a fixed deterministic discretizer mapping
an output's expression surface to a choice code `c = (template_id, elaboration_bin,
order_code)`. `R_v`: per-variable executable rule, a pure function of (input, s, s′)
stating the predicted direction of change on an ordinal choice axis (e.g. "higher
budget → higher elaboration bin"). A "lawful edit" is a single-variable state change
performed through TNN's own real transition ops (re-run of a deliberation episode with
one evidence item altered, or the counterfactual-edit op TNN itself can perform) —
never hand-crafted byte surgery.

```
fn adaptivity_trial(probes, states, rules) -> Verdict {
  for (p, s) in all_pairs(probes, states)
    require(bytes(run(p, s)) == bytes(replay(p, log(s))))  // G0: else stop
  hits = 0; total = 0; prot = 0; samples = []
  for p in probes, s in states, v in V_expr {
    s2  = lawful_edit(s, v)
    dir = rules[v].predict(p, s, s2)          // mechanically derived, pre-committed
    c1  = D(run(p, s)); c2 = D(run(p, s2))
    if protected_diff(run(p,s), run(p,s2)) { prot += 1 }
    hits  += moved_toward(c1, c2, dir) ? 1 : 0   // tie / no-change = miss
    total += 1
    samples.push((proj(s), c1)); samples.push((proj(s2), c2))
  }
  rate   = hits / total
  nmi    = miller_madow_nmi(samples)          // bias-corrected, normalized
  null99 = permutation_null(samples, 1000)    // shuffle state labels
  novel  = repeat_all_above_on(novel_states)  // G4: held-out region
  return Verdict{rate, prot, nmi, null99, novel}
}
```

The lookup-table control is G4 plus executable rules: a table memorizes visited
(input, state) cells and has no compressed rule to extrapolate, so it fails on novel
states; the scored predictions are generated by executing the preregistered rules as
code, not by the system's post-hoc story. Rules must be inspectable (white-box law);
novel probes include *two-variable* edits to test compositionality (per-variable rules
composed must predict the joint move — a table cannot compose).

## 4. Kill bar
| Gate | Bar | Kill condition |
|---|---|---|
| G0 replay fidelity | 100% byte-identical | any mismatch — metric is measuring nondeterminism, stop |
| G1 directional hit | point est. ≥ 0.60 **and** lower 99.5% CI > 0.50, n ≥ 400 controlled pairs | below bar — variation is not state-lawful |
| G2 protection | 0 protected-output changes, all pairs | any change — violates Micah's MUST-NOT list |
| G3 NMI | observed ≥ max(0.30, 5 × null99), N ≥ max(400, 40·K) samples | below bar — expression independent of state (dice-shaped) |
| G4 novel states | G1–G3 bars pass on novel set alone (≥ 1/3 of pairs) | fails — lookup-table-shaped memorization |

Sample-size justification: n = 400 pairs gives ≥ 90% power for true hit-rate 0.60 vs
0.50 null at one-sided α = 0.005 (null SE 0.025, alt SE 0.0245). The 0.60 bar sits
2.8σ above the direction-blind 0.50 baseline, so a directionless variation source
(RNG, noise) cannot clear it by luck; it is deliberately short of near-perfection,
which would smell of hardcoding. N ≥ 40·K keeps the Miller–Madow bias correction and
the permutation null tight. G0 leans on committed MA1 evidence (58/58 replay,
tnn-native-lab branch); G1's predicted-direction machinery leans on RC1's proven
self-simulation ("every prediction held").

## 5. Honesty notes
- `D` is human-chosen and can inflate or hide adaptivity. Mitigate: preregister it,
  report sensitivity (coarsen/refine by ±1 bin — bars must survive).
- NMI estimators are biased; always report raw I, H(S), H(C), and corrected NMI, and
  let the permutation null (not the 0.30 floor) be the binding constraint when they disagree.
- Ordinal axes (elaboration depth, alternative count) carry the headline number;
  categorical template switches are weaker evidence — say which is which.
- This metric certifies *lawfulness*, not intelligence: a thermostat is adaptive by it.
  Deliberateness (rules owned by TNN's own judgment machinery) is a separate claim,
  out of scope for this slice.
- Novel states must remain lawful (reachable via real transition ops); invariant-
  violating synthetic states test nothing.
- Base-state reuse induces pair correlation — use cluster-robust CIs (cluster = base
  state) or accept the bar as conservative.
- Small-but-consistent changes can clear G1; `D` must define the minimal *meaningful*
  choice difference (≥ 1 elaboration bin or different template family).
