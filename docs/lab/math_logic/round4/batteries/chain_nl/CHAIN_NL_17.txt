# CHAIN_NL_17

Domain: causal_temporal
Type: derivation

S1. Four events P, Q, R, S are scheduled on four days: Monday, Tuesday, Wednesday, Thursday, one event per day.
S2. Event P happens before event Q.
S3. Event R happens the day after event Q.
S4. Event S does not happen on Monday.
S5. Event Q does not happen on Thursday.
S6. Event S happens after event R.
S7. Determine the day of each event.

TARGET: P is on Monday, Q is on Tuesday, R is on Wednesday, and S is on Thursday.
