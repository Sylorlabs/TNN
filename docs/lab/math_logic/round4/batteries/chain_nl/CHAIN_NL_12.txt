# CHAIN_NL_12

Domain: logic_puzzles
Type: derivation

S1. If the alarm rings, the guard wakes.
S2. If the guard wakes, the dogs bark.
S3. If the dogs bark, the gates lock.
S4. If the gates lock, the lights flash.
S5. If the lights flash, the warden is called.
S6. If the warden is called, the vault is sealed.
S7. If the vault is sealed, the all-clear is sounded.
S8. If the all-clear is sounded, the night log is closed.
S9. The alarm rings.
S10. Prove that the night log is closed.

TARGET: The night log is closed.
