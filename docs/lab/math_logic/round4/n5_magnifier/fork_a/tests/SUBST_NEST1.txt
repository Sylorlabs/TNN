# SUBST_NEST1 (nested substitution: x inside a larger expression)

Domain: number_theory
Type: derivation

S1. x=a+b.
S2. General substitution schema: for any terms $A and $B and any expression $E, if $A=$B then $E with every $A replaced by $B equals $E with the substitution made.
S3. Prove that (x+1)^2=((a+b)+1)^2.

TARGET: (x+1)^2=((a+b)+1)^2.
