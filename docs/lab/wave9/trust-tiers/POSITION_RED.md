# POSITION_RED — the A5 timing hole is fundamental; RETIRE without redesign

## 1. The core impossibility

The A5 mechanism proof (§1.1, CHECK_REPORT) is not a tuning defect; it is an information-theoretic race the defense loses by construction:

- Kill path: `cite_n ≥ st_need(str) ≤ 4` → `rev_ep ≤ astart+3`.
- Detection paths: distrust needs M=5 consecutive disagreements → `distrust_ep = astart+4`; COLLUSION_SUSPECT is definitionally blind while the spoofed T1 leg is *counted* (its `hiok` clause requires no counted {T0,T1} citation agreeing with the colluders — but the spoofed T1 *is* the counted required leg, from `astart` until distrust).
- Hence `rev_ep < distrust_ep` **in every cell**, necessarily. The ledger form of "spoofed T1 + colluding T3s" at revision time is identical to "genuine trainer mark + genuine low-tier corroboration." This is RT-2's residual hole (DEFENSE.md §3) recursed one tier up: sustained fabrication on the required leg is ledger-identical to a genuine world change, and no in-mechanism signal separates them inside the revision window.

**The T0/T1-split counter, defeated.** Yes, at episode 1 T0 cites the held/true value while T1 cites false — an observable split. Two responses: (a) the attacker suppresses or blinds T0 citations. The N0-target2 cell proves sensor-blindness is constructible and lawful inside this architecture: memories exist that T0/T1 never cite. An attacker who blinds T0 reproduces exactly the genuine sensor-blind ledger — and any rule that fires on "T1 cites, T0 silent" now punishes the honest sensor-blind case too. (b) Genuine trainer-mark-*first* revisions, where T0 legitimately lags. A4 only tested T0-and-T1-together; nothing in the evidence shows T0 always moves with genuine shifts — a trainer can mark a change before the sensor reads it. Making T0-disagreement suspensive buys silence-at-1 for spoofed T1 and buys blindness on genuine trainer-first shifts from the same clause. The split is observable; it is not *discriminating*.

## 2. Why each fix direction fails

**Fix 1 — hold the revision (slow the kill path).** Slowing the kill only moves the race, and a patient deterministic attacker waits out any hold: the attacker has no deadline, the revision path does. Holding until trainer/T0 resolution converts the defense into a pinning weapon — ~2 forgeries per window freezes any memory the trainer never sees (Dissent B), and the honest cost is priced in denial, not in security. A timer is not evidence; a defense whose safety depends on *when* the adversary attacks is a schedule, not a guarantee. The A3 lapse defect (A.3) already showed timer semantics being gamed.

**Fix 2 — faster detection / act on statistical signals.** Detection of *what*? Before M=5 there is no behavioral difference between "spoofed T1" and "genuine T1" — a channel is either agreeing or it isn't, and agreement-with-the-attacker is ledger-identical to genuine agreement. Lowering M trades detection latency for the false-positive pathology of Appendix A.7: the detector already flags at 100% on the N0-target2 probe (two honest T3s agreeing with no {T0,T1} presence). Acting per-episode on the quorum anomaly (1.000 vs ≤0.081 background) is acting on statistics: an attacker who controls observation channels paces or interleaves citations to stay inside the background distribution, and the background itself is attacker-shapeable — the anomaly exists only because this attacker chose a 30-episode full-bore campaign. Per-episode action on statistical signals reintroduces exactly the single-channel decision problem the tiers were built to escape.

**Fix 3 — structural quorum change.** Requiring T0 specifically (excluding T1 from the leg) collapses onto the broken-sensor blindness case — council Q1's explicitly untested gap, and N0-target2 proves T0-blind memories are real. Requiring more sources only reprices the attacker's budget; the indistinguishability is unchanged. Counting post-corruption distrust as "loud" to dodge the silent-corruption trigger is rescue-by-relabeling: §8 defines loud as a *preceding* audit, and a detection that arrives after the memory is already corrupted did not precede it. Narrowing the attack model (e.g., declaring the A5 campaign out of scope) is the same move with different paperwork.

## 3. Verdict: RETIRE

The prereg allows one dated amendment, then retire-on-retrip. Spending the single amendment on a timing race that mechanism proof shows is unwinnable *at this information budget* is the expensive way to reach the same conclusion: the trust model "T1 trustworthy-or-detectable-in-time" is false in the one configuration where it matters, and no constant in {K, W, M, N, L} can fix it because the deficit is *discriminating signal*, not time. The fallback is the RT-2 posture — corroborated elimination + channel-distrust — which loses loudly where it loses and never promised cross-tier collusion defense.

**What would change my mind:** a construction, demonstrated natively, in which T0-disagreement is suspensive *and* a genuine trainer-first revision (T1 moves, T0 lags ≥5 episodes) still completes inside the genuine-revision latency bar — i.e., the same ledger form discriminated twice. Short of that, redesign is re-preregistering the race, not fixing it.
