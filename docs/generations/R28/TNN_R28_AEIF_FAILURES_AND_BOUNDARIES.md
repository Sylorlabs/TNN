# R28 Failures and Boundaries

- **Native R28 execution is blocked.** No executable pinned `znc` is materialized in the active cloud terminal. The candidate Zag source is source-contract validated only.
- Graph authority is retired as the default, but graphs are not declared universally useless; optional derived relation indexes remain.
- Identity is strong but not perfect: hard five-seed identity 97.92%, hard switching 90.00%.
- More training is not monotonically beneficial: continuous-life performance peaks at dose 256 and regresses at 512/1,024.
- The privileged memory heuristic is researcher-authored hardcoding. Its use as default must not be described as a learned memory breakthrough. TNN override is real in the reference battery (~39.49%).
- Learned memory-only alternatives v3/v4/v5 did not beat the privileged heuristic; these failures are preserved.
- Substrate meta-search is promising but evaluated on only six hidden profiles.
- Nominal 100% component scores frequently failed harder tests; nominal sibling 100% fell to 93.54% interactive and 78.96% high-noise.
- Contextual affordance is strong but noisy performance remains below clean.
- One-shot names are ~99.5% on the bounded hard name test; this is not general natural speech.
- Hard connected speech is the dominant blocker: integrated hard speech 22.08%; current CTC path failed even after acoustic pretraining.
- No teenager/adult English, natural open-world video/audio, human superiority, AHI, open-ended RSI, consciousness, or production TNN claim is established.
