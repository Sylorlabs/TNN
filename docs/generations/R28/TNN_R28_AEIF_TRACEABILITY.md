# R28 Causal Traceability Contract

Every consequential mutable decision is designed to emit a parent-linked event containing development step, subsystem, subject/candidate ID, evidence strength, uncertainty, generic reason code, and parent event ID.

Trace stages include sensory ingress, core/PAM representation, episodic retrieval, identity hypothesis arbitration, memory disposition/retrieval, active observation, action-effect prediction, language/name binding, social provenance, architecture revision, and rollback.

Generic failure classes include undertraining, teacher/curriculum mismatch, memory loss, retrieval failure, routing failure, representation loss, confidence miscalibration, over-persistence, over-switching, interference/overconsolidation, resource pressure, and regression.

The intended reconstruction is:

`evidence → representation → episodic retrieval → hypotheses → memory/world/language/social decision → error → causal diagnosis → training/memory/architecture revision`

TNN may learn from traces; it cannot silently rewrite the immutable root verifier or hidden labels.
