# R32 V11 Reusable-Probe Hardening — Training-Only Causal Result

Status: **REFERENCE_ONLY / CURRICULUM_OVERCORRECTION / ARCHITECTURE_UNCHANGED**

V11 changed only developmental evidence availability/resource pressure relative to V10. On the identical seed-9714 forced reusable-apparatus challenge, V10 had ~0.04 no-unique UNKNOWN, ~0.46 resolvable success, and ~0.09 mean apparatus trials. V11 moved no-unique UNKNOWN to ~0.77, but resolvable success collapsed to ~0.10; mean apparatus trials remained only ~0.07.

The intended resource support was genuinely present in development: 1,343 randomized resource starts, including 296 starts where source 7 was the only optional evidence source. This rules out simple undersampling of the resource envelope.

## Causal classification

**Bad curriculum / active-observation credit under epistemic support shift.** The generic resource curriculum taught the controller that ambiguous-looking, resource-poor states often favor the neutral UNKNOWN fallback, but it did not sufficiently distinguish states where the same ambiguous passive evidence becomes resolvable through a stable consequence apparatus. It therefore overgeneralized resource poverty into abstention.

This is not evidence against the persistent hypothesis population, temporal/provenance state, neutral-UNKNOWN economics, or residual action-value architecture. Those remain fixed for the next experiment.

## Next causal test

Use delayed grounded outcomes—not ambiguity/condition labels—to balance resource-start development between histories whose independent delayed consequences converge to a unique state and histories that remain non-convergent. Preserve randomized source masks/costs and reusable source-7 provenance. This tests whether the failure is curriculum class imbalance / credit coverage rather than representational insufficiency.
