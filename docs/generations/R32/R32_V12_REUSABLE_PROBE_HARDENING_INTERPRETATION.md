## Causal classification

V9-V12 INSPECT targets are one-step terminal backups: an observation is valued only by the best KEEP/COMMIT/UNKNOWN decision immediately after that single observation. This structurally undervalues evidence actions whose benefit appears after multiple costly same-lineage trials. V8's oracle terminal target showed the opposite pathology (runaway repeated observation), so both boundaries point to the same missing mechanism: recursive option value with real cost and learned stopping.
