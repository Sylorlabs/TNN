No inspected candidate is credited with innate English/domain answers. That is
a scoped observation, not a proof that all possible callers are label-free.
Features carrying terms like uncertainty, causal value or entity identity need
an origin trace; relabeling evaluator quantities does not make them legitimate.

## Five-arm tournament

A: minimal generic safe substrate. B: current documented defaults. C: richer
generic system fluency (typed operation semantics, error contracts and examples
of safe composition). D: the same fluency taught through attributed human-
authorized experiences. E: learning its use from consequences where feasible.
All retain the same protected safety/rollback and resource envelope; no arm is
allowed to remove protections merely to be "minimal."

Hold architecture capacity, initial learned parent state, domain experiences,
resources and permitted operations fixed. Describe how birth-policy differences
are introduced to a research fork without erasing history. A true newborn
ablation, where scientifically necessary, is labeled a separate control and
cannot supply canonical continuation evidence. Count fluency teaching and human
interventions as experience/cost, not free architecture capacity.

Measure learning speed, final capability, transfer, rigidity, safe self-revision,
resource use, dependence and retained regressions. Test unfamiliar domains that
use the same generic operations differently. Falsify rich fluency with premature
module creation, wasted calls, worse adaptation or continued teacher dependence.
Retain broadly useful defaults when supported; the objective is not minimal
hardcoding at any cost.
