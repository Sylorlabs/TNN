no native helper, fixture, expected observation, parser, historical result or

`Research/R33_B000_RUN_PRIMARY_V1`. The launcher saves the original registration,

## Enforced controls and limitations

Child environment contains only PATH and C locale, with no inherited credentials.
The sandbox denies writes, network operations and additional child processes;
the one executable is explicitly admitted. Wall/CPU/output ceilings match the
original preregistration. Runtime file reads are **not kernel-isolated**: the
strict library-read allowlist aborted in the system dynamic loader before main,
including for the system `true` utility. The frozen native driver has no file-
read, network, exec, dynamic import or learner-state facility, checked by the
existing source allowlist. This is adequate only for these reviewed literal
non-learning helpers; it is **not an M2 shadow-isolation qualification**.

This host rejected DATA and RSS setrlimit requests. The 256 MiB RSS ceiling is
therefore an actual wait4 peak measurement with mandatory post-run rejection,
not a claimed hard memory barrier. The reviewed fixture has a bounded 229,432-byte
largest live i32 allocation. CPU is kernel-bounded, stdout/stderr are drained
with strict byte caps, and a wall deadline kills the process group. No audit
result with a measured ceiling violation may be accepted. The compiler is a
separate external bounded process, not a learner, and its costs are recorded.

V2/V3: restricted read profiles aborted in the macOS dynamic loader before main;
binding the Homebrew interpreter's real image alone did not solve the failure.
The `true` crash report localized the failure to dyld CacheFinder/ignition.

probe was an insufficient test of network operations. V5 tests an actual loopback
connect and recognizes only EPERM/EACCES as permission denial. Connection refusal
is not misclassified as sandbox enforcement. All earlier records remain retained.
No B000 fixture or historical scientific generator ran during any preflight.

The final preflight, launcher, lifecycle verifier and tests must be hash-frozen
before primary admission. Unknown preflight outcomes fail closed. Preregistration
checks stay frozen; the new lifecycle verifier validates the original snapshot
and current execution separately. It must reject invented results, exposure
disagreement, unverified hashes, unqualified sensor/authority claims and repeats.
