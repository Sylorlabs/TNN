# N18 parent-runtime boundary

The native parent runtime and evaluator are not currently qualified. This is a
required dependency, not an implementation detail that N18 may infer from the
R27 pickle, the N10 inert map or the N17 compile-only authoring binary.

Before either N18 route can be registered, the candidate must pin a native
parent runtime identity and an evaluator identity with:

- exact input/output ABI;
- supported parent state and mutable-copy semantics;
- old/new training and probe generation boundary;
- decision/action timing and tie-breaking;
- native telemetry and failure/refusal behavior;
- no Python, pickle, reducer, historical verifier or hidden foreign process;
- source/compiler/build/input hashes and resource bounds; and
- explicit classification as either full native R27 continuity or a named
  surrogate parent under an enacted methodology amendment.

The historical 33/33 receipt and semantic digest remain provenance witnesses
only. Until this boundary is populated by the selected route, the N18 status
must remain prerequisite-blocked and no binary may be authored.
