# N18 concept review — independent disposition

Disposition: **REQUEST_CHANGES**.

The independent review found that keeping R27 bytes unchanged proves custody
and non-mutation but does not prove that a new native execution path is
behaviorally canonical R27. The proposed sidecar therefore could not be
admitted with the claim “composite beats canonical R27” while the parent
continuity gate remains blocked.

The review required either completion of N17 through
`FULL_NATIVE_R27_CONTINUITY_QUALIFIED` or a prospective methodology amendment
creating a separately named frozen-parent composite benchmark class. It also
required the matched no-op adapter, randomized/untrained sidecar control,
fresh disjoint populations, exact canonical hash pin and postrun identity,
fixed metrics/margins/multiplicity treatment, holdout-leakage controls, exact
freeze/admission semantics, no parent writes, and independent postrun review.

This packet incorporates those changes. The review did not authorize N18
implementation or execution, and this record does not constitute approval of
the packet.
