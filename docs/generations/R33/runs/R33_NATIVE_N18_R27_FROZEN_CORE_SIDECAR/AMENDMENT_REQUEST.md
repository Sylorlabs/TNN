# Prospective methodology amendment request — N18 benchmark class

This is a proposal, not an amendment. It has no effect on the governing
contract and does not authorize N18 execution.

The amendment route is mutually exclusive with the N17-qualified route. Before
N18 registration, exactly one route must be recorded in a versioned freeze:
`N17_FULL_NATIVE_R27_CONTINUITY` or
`FROZEN_PARENT_NATIVE_SURROGATE_COMPOSITE_AMENDMENT`. Null, both, or a route
selected after observing results is invalid.

## Proposed addition

Add a named benchmark class:

`FROZEN_PARENT_NATIVE_SURROGATE_COMPOSITE`

The class would permit a separately reviewed native composite experiment after
exact parent custody, source mapping, native evaluator boundaries, and frozen
parent non-mutation controls are established, even when full historical
behavioral continuity remains unresolved.

## Claim boundary

Evidence from this class could be labeled only:

`NATIVE_SURROGATE_COMPOSITE_BEATS_SURROGATE_PARENT`

It could not be labeled “beats canonical R27,” could not create an R27
descendant, and could not grant learner authority, mutate canonical R27 or
promote a checkpoint. A later full-continuity result would be required before
any canonical comparison claim.

## Minimum safeguards

The amendment would require, before exposure:

- exact canonical R27 raw SHA256 custody pin and byte-for-byte postrun identity;
- native parent identity and evaluator boundary, with unresolved behavior
  clearly labeled surrogate rather than canonical;
- independent review before preregistration;
- exact source/compiler/binary/input freeze and separate one-invocation stage
  admissions;
- matched parent-only, no-op-wrapper and randomized/untrained-sidecar controls;
- fresh, disjoint development/validation/confirmation populations;
- fixed primary superiority margins and multiplicity treatment;
- no holdout-label, probe or evaluator leakage into sidecar learning;
- no canonical writes, authority grant, promotion or descendant identity;
- independent postrun review and explicit surrogate-only disposition.

## Why this does not bypass continuity

The amendment would create a different evidence class, not redefine historical
R27 continuity. It would allow useful mechanism measurement while preserving the
truth that the parent path is a native surrogate until N17 qualifies it.

Prospective approval must come from the governing methodology owner before any
N18 registration or exposure. This file records the request only.

## Required approval record

An enacted amendment must provide, before registration:

- amendment version and effective UTC date;
- approving methodology owner/authority and immutable approval record;
- exact added and superseded contract clauses;
- confirmation that all unrelated forward dependencies remain mandatory;
- an attestation covering the live sensory, telemetry, authority and
  fresh-evidence dependencies, with each unresolved dependency retained as a
  blocker rather than silently waived;
- exact surrogate-parent raw/source identity and native evaluator definition;
- exact native feature/output ABI and claim vocabulary;
- the mutually exclusive selected route;
- confirmation that the amendment does not authorize canonical mutation,
  learner authority or promotion.

Without those fields, `AMENDMENT_REQUEST.md` remains only a proposal and N18
cannot be preregistered.
