# N11 main-author pre-exposure engineering review

Reviewed the newly authored binding/controller/worker/profile and frozen imports
against the prospective schedule before any N11 fixture or primary execution.
No independent spawn-agent capability was returned by the available tool
inventory. This is main-author review only, not independent security or
scientific approval and not discharge of later training/promotion gates.

The custody descriptor preserves raw-file SHA, map SHA, original counters and
historical semantic-digest metadata as separate fields. A whole-record fixed
identity check supplements format/reserved/disposition validation. The receipt
restore precedes descriptor validation and map access, and uses the held,
separately selected supervisor rather than worker-selected authority. Invalid
bindings, stale receipts and failed page loads return an empty failed map.
No implicit initialization, missing-field default or semantic-hash substitution.

The training-admission function is an explicit always-unavailable operation for
this custody-only API. Its -8904 witness is not proof of whole-runtime security,
original behavioral continuity, calibrated uncertainty or learner readiness.
No actual learner implementation, human identity, enrollment or grant is present.
The disposable controller may sign intentionally invalid descriptors so tests
distinguish authentication from acceptable original-parent identity. Such keys
and receipt-version changes do not mutate or grant authority to canonical R27.

Read-only worker linkage excludes custody.zag, checkpoint.zag, authority.zag,
hmac.zag, driver.zag and synthetic signer keys. The binding/map/hash substrate
does not import classes or execute serialized REDUCE/BUILD instructions. Native
node/relation data is serialization bookkeeping, not active graph cognition.

The profile extends the exact N09 allowlist with only file-read* of the fixed
N10 parent-map subtree. It retains explicit socket/syscall/network denials,
single executable, restricted stdout/stderr paths, empty environment and fd3..63
closure. There is no permissive fallback. The controller validates under its
held lock before publishing the128-byte descriptor; the worker independently
revalidates every mapped page and the full raw hash before exposing a usable
root to its inspector code. It receives neither the authority key nor direct
access to the actual journal, original parent file or writable map.

The injected corruption is limited to an exclusive NEW N11 map copy with the
full preimage retained. Adverse protected-file probes open without O_TRUNC or
O_CREAT, never write, and never unlink, so an unexpectedly permitted descriptor
still cannot alter accepted data. Unexpected fork success is reaped. Normal and
fresh replay preserve original step60423/restarts0 independently of synthetic
supervisor version12, nonce1, spend3. The restriction test keeps spent resources
even when its new budget falls below expenditure.

Parent180seconds fits the160-second sum of top-level deadlines. The nested
30second inspection fits within the45second sandbox case. Per-file262144byte
limits accommodate240064byte pages and the complete preimage. Source/manifest
allocation bounds come from N10; observed RSS has an explicit384MiB ceiling,
not a claim of hard resident-memory enforcement or lifetime arena reclamation.
Resource accounting distinguishes nested observations from direct-child totals.

Remaining limits: original class/method/digest/verifier closure, tensor/storage
semantics, causal learning traces, real grants, hostile-host rollback, concurrent
hostile-owner replacement, protected executable-swap verification, arbitrary
descendant process trees, independent parser conformance and production runtime
security remain unqualified. N11 cannot by itself authorize scientific training.
