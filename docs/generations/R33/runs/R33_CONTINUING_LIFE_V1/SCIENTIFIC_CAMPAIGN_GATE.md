# Scientific continuing-life campaign gate

Complete this record before any new scientific exposure. The engineering run
`CL-ENGINEERING-01` is not a scientific campaign and does not fill this gate.

## Frozen before exposure

- Hypothesis: the same accepted learner acquires useful new behavior while retaining an earlier competency under changed conditions.
- Learner identity and parent digest: exact native R27 behavioral-continuity identity after N17 closure.
- Controls: ordinary updating, frozen behavior, matched resource control, and mechanism removal for every candidate mechanism.
- Resources: wall time, CPU, memory, storage, observation bytes, action count, and trainer/help budget.
- Evidence partitions: fresh acquisition, returning competency, unfamiliar combinations, contradiction/change, reload continuation, and help withdrawal.
- Assistance rule: assistance is separately attributed and removed at the predefined point.
- Acceptance criteria: numerical thresholds for retained competence, new learning, transfer, post-reload performance, assistance-free performance, and causal attribution.
- Exclusions: hidden identities, semantic segmentation, future consequences, evaluator labels, and post hoc threshold changes.

## Required result

A pass must show useful new learning alongside retained earlier competence,
transfer beyond repeated examples, continued learning after a fresh-process
reload, measured performance after help withdrawal, inspectable links from
experience to consequential updates, and complete accounting for memory,
computation, observations, and help. A failure determines the next controlled
investigation; more checkpoints or longer execution do not count as improved
cognition.
