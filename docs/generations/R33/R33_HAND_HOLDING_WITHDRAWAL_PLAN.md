# R33 competence-gated assistance withdrawal

Status: prospective design; no learner has advanced through these stages in R33.
Assistance stage is per competency and distinct from M0–M7 mutation authority.

| Stage | Permitted training assistance | What independent testing removes |
|---|---|---|
| H0 | Full human-authorized demonstrations | The demonstration and any answer-bearing state |
| H1 | Contrasts and counterexamples | The paired cue that reveals the correct distinction |
| H2 | Prompts | Prompt content and prompt-timed hints |
| H3 | Trainer asks questions only | Question selection that reveals an answer or failure type |
| H4 | Help only when TNN requests it | Unrequested assistance; qualified episodes separately run without help |
| H5 | Trainer fully withdrawn | All teaching aid; protected safety supervisor remains active |

## Advancement contract

For each competency, preregister required fresh transfer slices, minimum sample
coverage, acceptable independent performance, uncertainty/calibration criterion,
retention delays measured in both elapsed events and time, and maximum regression
on prior competencies. Freeze numerical thresholds before probe exposure; use
the trainer's declared competency/risk requirements, not a universal age schedule.

Advance only after repeated fresh probes, delayed retention and unassisted
competence all pass. A fixed number of lessons, elapsed age, or a high assisted
score is insufficient. Do not train on qualification examples after seeing them
without consuming/reclassifying them and allocating new independent evidence.

Record the policy and every help event. A rescue during a probe makes it an
assisted episode and does not count toward the independent numerator. Safety
intervention stops the episode and is reported; it is never suppressed to keep
the label "withdrawn."

## Causal withdrawal tests

Use matched parent forks with continued help, graded withdrawal, abrupt
withdrawal and request-only help, sharing allowed experience budgets. Separate
the effect of less information from changes in task difficulty, teacher tone,
reward or available actions. Include a teacher-absent but otherwise identical
context so absence itself is not a benchmark mode label.

Measure assistance-dependent gain, collapse magnitude, recovery, help request
quality, unassisted generalization, retention, interventions and internal state
changes. Performance collapse is evidence of scaffolding dependence, not a
reason to silently restore help and count the episode as independent.

After regression, mark the competency unqualified and record the reason. The
human trainer may authorize renewed teaching; preserve the failed withdrawal
evidence and require new qualification. H5 never permits self-granting tools,
values or structural authority beyond the separately protected contract.
