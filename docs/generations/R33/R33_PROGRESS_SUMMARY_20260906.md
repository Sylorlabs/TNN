## 2. What the program is trying to build

TNN's intended architecture is a continuing, inspectable learner using raw
experience, persistent competing hypotheses, memory, consequences, and active
evidence gathering. It is not intended to be a transformer/LLM, fixed tokenizer,
next-token predictor or fixed knowledge-graph cognitive system. Raw sensory
evidence remains available alongside optional learner-created abstractions.
Supplied word, phoneme and voice-activity boundaries must not silently become
the learner's cognitive units.

The ownership split is explicit. A human trainer defines goals, experiences,
policies and real-world authority. Automated teacher aids can select lessons,
but their knowledge is attributed to them, not credited as learner competence.
The architecture supplies generic mechanisms and protected verification; the
learner may change only the state and mechanisms that its current authority
permits. Evaluator truth and hidden answers stay outside cognition.

R27 is still the accepted checkpoint, not a fully recovered native executable.
R32/E51AJ is the inherited completed experimental frontier, with a mixed or
unreplicated retention direction and no final no-tradeoff result. Those
historical results were not restarted or promoted by calling the next work R33.

## 4. Early audit and component corrections

B000 confirmed five actual defects in the selected prototype helpers. A visual
summary could lose channel order. An acoustic sampling window could miss a
distinguishing impulse. Trace saturation could silently drop an event. A
storage-selection helper could choose a protected slot. Limited reconstruction
capacity could silently omit the tail. Matching those expected witnesses was
a successful diagnostic of defects, not a passing sensory or safety boundary.

C01 then exercised new exact-transport and refusal components: 77 scalar
checks and 77,986 vector elements matched. It covered all PCM16 codewords,
the maximum RGB fixture, shape/rate/capacity rejection, protected-slot refusal,
and selected codebook/trace rules. That was in-memory component evidence.

C02 advanced to encoded file bytes, physical metadata, snapshots and fresh
process reload: 48 native cases, 144,384 vector values and 258 retained artifacts.
It did not establish natural perception or a complete brain checkpoint.

C03 exercised 21 persistence/replay groups and 80 native replay executions.
Its 173 total subprocesses included Python supervision. The later human
native-only instruction superseded that implementation path. C03 remains
historical mixed-language evidence, including its 763 manifest entries; it was
not erased, rerun or relabeled as a native-only supervisor.

## 6. Telemetry and sensory transport

N04 passed 556 native telemetry assertions in eight groups and 27 parent
checks. It covered bounded in-memory records, missingness, assistance
attribution, pointwise retention accounting and exact reconstruction. No live
learner understanding, global freshness or working dashboard followed.

N05A exposed an allocation assumption: native integer storage had been treated
as four bytes. N05B measured an eight-byte native stride, corrected allocation
and alias extents under a new identity, and passed 749 completed-child checks
plus 406 parent checks across 41 children. Fresh replay, abandoned reservations,
process death, SIGKILL, explicit failure and corrupted records were exercised.
The qualified envelope is only 16 events, 32 attempts and six 64-byte causal
slots. Missing causal fields remain missing rather than being filled with
plausible explanations.

N06 connected raw bytes to durable evidence, telemetry and observer access.
It compared 377,264 sample/pixel values and 636 physical metadata fields, with
727 child checks and 163 parent checks. It covered signed PCM16, RGB8, order,
timestamp/timebase conditions, corruption, absent evidence and capacity limits.
Its envelope is PCM16LE mono/stereo at 8,000–192,000 Hz with bounded payloads,
and RGB8 frames up to 64 by 64. This is encoded-file transport and observer
access, not unrestricted microphone/camera operation or learned audio/vision.

The sensory plan explicitly separates S0 transport, S1 task-relevant
information reaching the learner, and S2 useful learned perception. Exact bytes
at S0 cannot stand in for transfer, retention or robustness at S2. The complete
evidence-to-hypothesis-to-decision-to-consequence-to-update trace of a running
learner is still unqualified. The human-facing dashboard remains a specification.

## 9. The blocking dependency

The missing artifact is the original `tnn-pre-v1-r27-general-learning` source
release, or an authoritative complete source export. Its required evidence
includes the original inference/update methods, accepted-state digest
canonicalization, full verifier, source provenance and dependencies. The known
custom-module inventory contains eleven files spanning R15 through R27, headed
by `r27_experiments.py`; transitive closure still requires actual source.

Serialized fields and weights do not uniquely specify arbitrary missing method
definitions. Creating replacement methods could produce a new compatibility
candidate, but would not recover the original program or prove its accepted
behavior. Nor is it valid to invent a new digest algorithm and assert that it
reproduces the historical digest. A byte-for-byte map is not an executable
continuation of the accepted learner.

The prior recovery reports document archive, Git, backup and local attachment/
session searches, with explicit scope limits. The post-N11 report records 11
text attachments and 195 session files searched without the original class/
verifier declarations. Those earlier search results are inherited records,
not all rerun in this continuation, and none proves global absence.

This continuation performed an additional Drive metadata search with no keyword
query and a raw non-trashed name filter for the original release prefixes and
`r27_experiments.py`, `r26_experiments.py`, and `r15_master_training.py`.
It returned an empty results array without a reported error. This was not a
remote archive-content search, a download, or proof of exhaustive visibility;
the connector's legacy search restrictions still limit negative conclusions.
No new original-source locator was recovered.

The source gap blocks original-behavior continuity and dependent training. It
does not make all independent non-learning work impossible. Source-independent
inspection, carefully scoped engineering and later-stage design remain possible,
but must not be presented as closing the original behavior gate.

## 12. What advances the real program next

The critical next input is the authoritative original source release or exact
source export, not another copy of the already preserved pickle. Once available,
inspect historical source as inert text, identify the original semantics and
state/digest coverage, and implement a separately specified native continuation
that preserves learned values, aliases, RNG/optimizer/pending state and evidence.
Historical graph/BPE/VAD data must remain inert unless its permitted transfer
has been explicitly designed and qualified; do not silently delete it.

Parent continuity alone is still insufficient. The relevant sensory and causal
trace paths, exact scientific source/evaluator/fresh populations, resource
accounting, required independent reviews and authentic human authority must
also be established before dependent integrated work. N15 has now supplied a
bounded synthetic preservation diagnostic, but it does not replace the planned
fixed-family capacity/dose studies or establish a continuing learner. Any new
stability/plasticity follow-up must use a new reviewed identity and wholly fresh
populations rather than weakening N15's thresholds or recycling its evidence.

**Bottom line:** the repository contains substantial tested engineering for
integrity, recovery, telemetry, raw transport, control and accepted-parent
custody. It does not yet contain a qualified trained R33 successor. R27 remains
unchanged while the missing original behavior and the scientific program remain
explicitly unresolved.
