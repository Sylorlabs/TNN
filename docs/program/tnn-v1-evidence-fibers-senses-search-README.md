# TNN v1: Evidence, Fibers, Senses, and Search Research Stage

This package is a reproducible research stage in the same TNN v1 lineage. It is **not** TNN v1 Beta and does not claim confirmed AGI/AHI.

## What is established in this stage

- Native Zag v2 strict compilation and checked-mode parity for `src/tnn_next_stage.zag`.
- Evidence-Weighted Belief Revision (EWBR): repeated popularity does not become truth automatically.
- Provenance-Aware Curriculum (PAC): clean/noisy/order-reversal/source-reversal histories remain distinguishable.
- Resource-Elastic Fiber Scheduling (REFS): owner resource envelopes alter speed; fibers consume unequal resources.
- Fiber-to-Memory Consolidation (FMC): useful findings enter shared long-term memory before fibers terminate.
- Shared Tool State (STS): exact compiler/tool work is shared and stale results are rejected.
- Peripheral Adaptive Microcircuits (PAMs): local sensory microcircuits can improve invariance without becoming separate minds.
- Query Intent Grounding (QIG) and Search Evidence Adjudication (SEA): search serves a defined uncertainty and popularity is not evidence.
- State-Continuous Development (SCD): the accepted brain state continues without replaying the complete lifetime.

## What remains open

- Adult written and spoken English.
- Natural continuous video and raw-waveform adult speech.
- User-ready autonomous web research.
- Real repository apprenticeship and cross-domain skill transfer.
- Integration of these mechanisms into one adult persistent brain.
