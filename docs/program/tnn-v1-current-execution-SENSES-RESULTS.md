# Sensory development and PAM results

## PAM definition

**PAM — Peripheral Adaptive Microcircuit**: a local adaptive neural field near a sensory receptor. It may normalize, denoise, compress, track temporal structure, and emit shared motifs, but it has no private identity, goals, autobiography, or world model.

PAMs are not fibers. A fiber is a temporary train of thought inside the shared brain; a PAM is persistent sensory neural tissue used by that brain.
