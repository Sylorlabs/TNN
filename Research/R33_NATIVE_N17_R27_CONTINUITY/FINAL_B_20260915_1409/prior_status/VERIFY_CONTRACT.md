## Required check classes for N17 review

Every proposed N17 check must be labeled exactly one of:

1. `DIRECT_NATIVE_RECOMPUTATION`: derived from canonical parent bytes/map or exact frozen source/reference bytes without invoking historical code.
2. `NATIVE_EQUIVALENT_REQUIRES_REVIEW`: a new native definition intended to test the same historical invariant; equivalence must be justified before preregistration.
3. `HISTORICAL_WITNESS_ONLY`: retained for provenance and never counted toward N17 native qualification.
4. `DEFERRED_BLOCKER`: not yet representable without new native machinery; terminal full-continuity qualification is forbidden while any required item remains here.

The independent review must determine the exact required set and terminal gate. This design deliberately does not decide that after seeing any N17 execution output.
