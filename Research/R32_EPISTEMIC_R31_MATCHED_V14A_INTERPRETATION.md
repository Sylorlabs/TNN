# R32 V14-A — Dynamic Curriculum-Only Causal Test

Status: **REFERENCE_ONLY / REJECTED_CURRICULUM_ONLY**

V14-A preserved the V13 representation, neutral UNKNOWN economics, recursive fitted-Bellman INSPECT credit, provenance dependence, raw evidence retention, and R31 KEEP authority. The only scientific change was developmental exposure to reusable grounded-consequence histories whose outcomes could be stationary, stochastic, biased-stochastic, step-changing, reversing, or unstable-then-stable. Generator modes were never learner features; delayed grounded windows supplied action utility.

On the forced reusable-apparatus seed-9714 battery, the controller became strongly over-conservative: no-unique UNKNOWN **0.955**, but resolvable success only **0.0125**. Mean reusable trials collapsed to **0.0071** and cost-rational UNKNOWN was **0.97**. There was no runaway probing.

## Causal classification

**Representation/evidence-state insufficiency exposed by curriculum shift**, not undertraining. Merely adding dynamic histories teaches the controller that ambiguous/resource-poor states are often unsafe, but the existing aggregate/recent trajectory features do not cleanly distinguish persistent stochastic non-uniqueness from a true state change followed by stabilization. The result is abstention instead of evidence acquisition.

## Decision

Reject curriculum-only repair. Retain the V13 recursive option-value mechanism because it previously proved multi-trial evidence can be useful. Next matched causal arm V14-B uses the identical V14-A curriculum but adds continuous ordered-history change-point / return-to-prior features computed from retained raw evidence. No condition label, fixed threshold, or fixed probe count is added.
