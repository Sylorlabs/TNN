# R33 architecture contract

Status: specification with source-audited gaps; not an implemented R33 runtime.
Parent authority: [charter](R33_PROGRAM_CHARTER.md), canonical R27 step 60,423.

## Components and boundaries

| Owner | Inputs and facilities | Decisions / write scope |
|---|---|---|
| Human trainer | Experiences, feedback, curriculum, values and resource envelope | Grants/revokes allowed actions and milestone ceiling; never fabricates learner competence |
| Architecture team | Generic native arithmetic, sensory ingress, memory and safe execution facilities | Versioned implementation changes, qualification instrumentation and migrations |
| Protected supervisor | Verified policy, grants, checkpoint lineage and root verifier | Enforces ceilings, admission, canary, rollback and audit continuity |
| Continuing learner | Admitted observations, its episodic/hypothesis state and allowed consequences | Representation, retrieval, rehearsal, action value, inquiry and qualified non-core proposals |
| Automated teaching aid | Trainer-authorized experience or demonstrations | Supplies attributed help only; cannot edit hidden weights or receive learner credit |
| Evaluator | Withheld truth, condition identities, sealed outcomes | Scores externally; cannot influence learner features, scheduling or update selection through hidden labels |

State cells, local experts, associative banks, recurrent fields, executable
PAMs, and structural motifs are possible native mechanisms. None alone is
assumed to be intelligence. Trace dependency records are provenance, not a
mandatory graph representation of world knowledge.

The inherited explicit correction keeps active cognition and future Foundry
graph-free. Historical graph controls remain history, not an implementation
candidate or a justification for restarting that tournament.

## Information path

An admitted experience has an immutable payload reference, clock/order metadata,
source provenance, declared numeric encoding and transformations. The learner
may create abstractions alongside this reference. Observations used by a
decision remain recoverable for the qualified retention horizon. Resource-driven
loss or eviction is explicit, authorized, and counted; it is never represented
as exact retention.

The evidence-to-update chain includes observations, retrieved memories,
competing hypotheses, activated mechanism/version, predicted values, chosen
action, observed consequence, and attributed parameter/memory/structure delta.
Human-readable descriptions summarize that chain; they cannot replace it.

## Lifetime identity

Every branch records `brain_id`, immutable parent checkpoint digest, birth ID,
developmental event counter, migration version, and branch purpose. A migration
must preserve episodes, uncertainty/hypothesis alternatives, learned parameters,
memory policy, optimizer/replay state, RNG streams, pending actions, route state,
resource accounting and trace ancestry. It must compare pre/post predictions and
continue learning in a fresh native process.

E51AJ's 130-coefficient shared fork is a controlled experimental lineage, not
proof that the entire accepted R27 brain was migrated. R33 currently has no
promoted checkpoint and no verified end-to-end migration. Native capability
claims must identify which lineage was actually tested.

A smaller-capacity arm cannot silently discard parent knowledge. Use lossless
adapter/zero-contribution extension where possible; otherwise declare the arm a
component laboratory comparison, not the continuing developmental brain. Newborn
controls may only be explicitly separate scientific controls, never a restart
of the accepted learner or a way to conceal interference.

## Current implementation gaps

The source audit found heuristic scoring and thresholds in older prototypes,
an operation-ID recognition helper rather than a complete protected function
dispatcher, and no demonstrated R33 authority ladder. Existence of a function
or a metric name does not establish a learned capability. Source-level
invariants, native execution, boundary fuzzing, and end-to-end interventions
are distinct evidence levels.

New runtime candidates must name all reachable modules. Legacy functions are
not incorporated merely because their source is present in the repository.
Any imported hardcoded policy is classified as protected mechanics, adjustable
birth bias, trainer assistance, learned state, or evaluator-only code before
use. Unclassified paths block qualification.
