# Human-matched learning-efficiency protocol

R6 does **not** claim to beat humans. No matched human participants were tested.
The following protocol is required before such a claim is allowed.

## Task families

Use invented content so neither humans nor TNN can rely on prior factual memory:

1. novel visual objects under viewpoint and lighting change;
2. novel spoken and written labels;
3. novel actions and action-effect rules;
4. compositional event descriptions;
5. causal interventions and counterexamples;
6. source reliability and contradictory reports;
7. tool procedures demonstrated by video;
8. delayed cross-domain transfer.

## Matched exposure

Both groups receive the same information-bearing episodes in randomized order.
Run 1, 2, 4, 8, and 16-example conditions. TNN code and evaluation criteria must
be frozen before human data is inspected.

## Measurements

- accuracy and calibrated abstention;
- exposures to criterion;
- immediate and delayed retention;
- transfer to new wording, viewpoint, speaker, and context;
- exact source/provenance recall;
- interference with old skills;
- wall-clock learning latency;
- persistent memory growth;
- counted operations and measured machine energy;
- human response time and a separately reported estimate of metabolic energy.

## Promotion rule

A human-superiority claim requires a preregistered hidden test, adequate sample
size, confidence intervals, no post-hoc architecture changes, and superiority
on both competence and sample efficiency. Machine energy/memory advantages must
be reported separately rather than collapsed into one arbitrary scalar.

Until that study is run:

```text
HUMAN_SUPERIOR_LEARNING = NOT_EVALUATED
HUMAN_SUPERIOR_MEMORY = NOT_EVALUATED
```
