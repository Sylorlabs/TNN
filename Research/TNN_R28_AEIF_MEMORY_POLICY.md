# R28 Memory Policy

## Birth/default policy
`PRIVILEGED_HEURISTIC_DEFAULT` is researcher-authored core bootstrap policy. It is explicit hardcoding and is **not credited as learned cognition**.

## Authority
TNN owns storage decisions. Learned experience may override, mutate, or replace the default. The default is a starting policy, not an immutable rule.

## LRU
LRU is allowed only as an eviction-order primitive when TNN has already chosen representation/value policy. `LRU_REPRESENTATION_CONTROL` is a control, not the canonical authority.

## Why
In the 12-seed R28 reference battery, pure LRU obtained higher raw overall recall by sacrificing exact-detail retention. The heuristic-default + TNN-override policy had the highest defined project utility and preserved substantially more exact evidence.
