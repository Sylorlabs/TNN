# Source

- `experiments/` — experiment controllers and harnesses that are committed
  (e.g. the R32 `.zag` native experiment sources).
- `zag/` — reserved for recovered TNN implementation source. Currently empty
  except for this index; see the R27 source-recovery notes. Build and
  reproducibility conventions for recovered source will be documented here.
- `tools/` — manifest generators, verifiers, and migration scripts.
