# U3 — INTERFACES / OBJECT TYPES (manual excerpt; source: handbook/2/objects.html)

## Three ways to name an object type
- Anonymous: function greet(person: { name: string; age: number }) { ... }
- interface Person { name: string; age: number; }
- type Person = { name: string; age: number; };
- Properties separated by , or ; — annotations after the name.

## Property modifiers
- Optional: xPos?: number  — may be absent; reads as number | undefined under strict
- readonly prop: string — readable, not writable (type-check time only)
- Handle undefined: if (x === undefined) ... or ?? default or ?. access
- Destructuring with defaults: function paintShape({ shape, xPos = 0, yPos = 0 }: PaintOptions)

## extends (interface inheritance)
- interface Dog extends Animal { breed: string; }
- Derived interface has all base properties plus its own.

## Index signatures
- interface StringArray { [index: number]: string; }
- interface Dict { [key: string]: number; }  // dictionary pattern
- With a string index, ALL named properties must match the index type.

## Excess property checking
- Object literals assigned to a typed location may NOT add unknown properties:
  createSquare({ colour: "red" }) // ERROR TS2561: 'colour' does not exist; did you mean 'color'?
- The check catches typos at creation sites. Type assertions (as T) bypass it.

## Common errors
- TS18048 possibly-undefined on optional property reads.
- TS2561/TS2353 excess property in object literal.
- TS2411/TS2412 index-signature mismatch.
