# Program-Wide Decoration Audit

**Date:** 2026-09-27
**Ordered by:** Micah — "is there anything else that got this treatment — im sure a lot of stuff did"
**Source frozen at:** `origin/tnn-native-lab @ 6b23696fc` (all five sector auditors read from this commit; read-only, no source changes made)
**Synthesized by:** night-shift coordinator from the five completed sector reports

## Method

Five sector auditors independently probed every line claiming TNN-native machinery, using neuter/ablation probes (does the component change outcomes when removed?), read-site audits (is the value ever read on a decision path?), and authorship tracing (who wrote the choice rule — TNN or the crew?). Each component is classified:

| Verdict | Meaning |
|---|---|
| GENUINE | Causally proven on a decision path: neutering/ablating it changes outcomes |
| DECORATIVE | Present in code/docs but changes nothing when neutered, or read by nothing |
| CREW-SCAFFOLDED | Real mechanism with real effects, but the choice rule was authored by the crew, not TNN |
| ADJUDICATED | Already killed, closed, or honestly scoped as instrumentation — not a live claim |
| NOT-YET-BUILT | Claimed direction with no implementation at the audited commit |
| OPEN | Built but unwired: no caller on any live TNN decision path |

Scope limits: read-only audit, no new batteries (disk constraint), no source changes. The audio sector verified the strongest checkable claims (SHA identity) but did not re-run waveform batteries.
