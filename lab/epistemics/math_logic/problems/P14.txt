ID: P14
DOMAIN: combinatorics
TYPE: find_error
STATEMENT: Consider the following proof by induction of the claim that all horses are the same color. Find the error and explain why the conclusion does not follow.

Base case (n = 1): a set of one horse is trivially all the same color as itself.
Inductive step: assume that any set of n horses are all the same color. Consider a set of n+1 horses. Remove one horse; the remaining n horses are all the same color by the inductive hypothesis. Remove a different horse instead; those n horses are also all the same color by the hypothesis. Since the two groups of n overlap, all n+1 horses must be the same color.
Therefore, by induction, all horses are the same color.
