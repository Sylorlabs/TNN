**Frozen:** 2026-09-22 (before any H1 build output exists).
**Builder:** H1 fork crew (subagent).
**Branch:** `tnn-native-lab`, repo `sylorlabs/TNN`, dir `docs/lab/senses/pam-rebuild/forks/H1/`.

## 1. Hypothesis under test

**H1 — Witnessed Event Lattice** (Sol, gpt-5.6-sol via UnoRouter, 2026-09-22).
Verbatim text in `senses/pam-rebuild/HYPOTHESES.md` — not paraphrased here; this
prereg implements it. Summary pointers only: (a) deterministic temporal lattice
of witnessed events, modality-neutral shared types (`agent`, `action`, `object`,
`relation`, `change`), original waveform/frames retained as native evidence;
(b) percept = ordered set of event records with id / time_span / entity_slots /
predicate / quantized-interval attributes / fixed-size witness refs /
integer support / integer contradiction / ≤K alternatives, event-scale
granularity, no sample/pixel values above the transducer, no premature labels;
(c) MEMORY CONTRACT as the six numbered rules (warrant check → contradiction
search → bounded provisional WITHHOLD → conflict deliberation with re-check or
robust action → install only on temporal persistence or independent
corroboration → retrieval gated on stored invariant); (d) efficiency targets
35% compute / 10% percept memory; (e) beauty: one witnessed-event object does
perception, indexing, uncertainty, evidence, conflict, retrieval.

## 2. What is built

- `src/h1.zag` — pure-Zag percept pipeline (integer arithmetic only, zero RNG,
  no wall-clock, no uninitialized reads) implementing the H1 event format.
- The MEMORY CONTRACT as executable code inside the same binary: warrant
  check, contradiction search, provisional buffer, conflict deliberation
  (deterministic span re-check or robust action), install-on-corroboration,
  retrieval gating — wired to a deliberate-memory install gate.
- `sense` CLI: `h1 <task> <fixture> [--stream=ID] [--ablate]` → percept
  event records + judgment/confidence/ops + install/withhold disposition +
  hash-chained ledger (SHA-256, `R33_NATIVE_SHA256_V2.zag`) in stream mode.
- `src/gen_h1_adv.py` — deterministic adversarial augmentation generator.
- `evidence/` — raw run logs, metrics, ledger verification, B7 artifacts.

## 4. Percept format (frozen)

One text line per event record on stdout (after the `key=value` header lines):

```text
ev id=<16 hex> span=<s0>:<s1> ent=<e0>,<e1> pred=<PRED> attr=<lo>:<hi>
   wit=<mod>:<ws>:<wl>[;<mod>:<ws>:<wl>]* sup=<0..1000> con=<0..1000>
   alt=<PRED>:<sup>[,<PRED>:<sup>]*
```

- `id`: FNV-1a-64 over (task, span, predicate, quantized attrs) — stable hash
  of source span + content.
- `span`: [start,end) in modality units (pixel row-range for images as
  `y0*W+x` linear spans; sample range for audio; frame range for video).
- `ent`: typed anonymous entity slot ids (`r0`=region, `s0`=source…).
- `pred`: ONSET | SUSTAIN | TRANSITION | REL_SAME | REL_DIFF | MOTION |
  SHAPE_CIRCLE | SHAPE_TRIANGLE | SHAPE_SQUARE | F0_HIGHER | F0_LOWER |
  F0_SAME | TIMBRE_PURE | TIMBRE_BRIGHT | TIMBRE_DARK | TIMBRE_RICH |
  DIR_<octant> | DIR_STILL.
- `attr`: quantized interval [lo,hi] (NOT a point estimate), task-specific
  units documented in §5.
- `wit`: up to 4 fixed-size witness refs `modality:span_start:span_len`
  (`img`, `pcm`, `vid`).
- `sup`/`con`: integer support / contradiction scores, 0..1000.
- `alt`: ≤3 (K=3) mutually exclusive alternative event records
  (predicate + support). Alternatives count as event records for the
  10,000-percept scale bar.

No sample/pixel values appear above the transducer line. No premature labels:
class predicates are interval-derived, never asserted from a point estimate.

## 5. Pipeline (frozen mechanism design; integer detail in source)

Ops definition (frozen): 1 op per pixel/sample element visited during witness
extraction + 1 op per compare/accumulate step in decision loops + 1 op per
input byte absorbed by the ledger SHA-256. Same grain as Approach A's
element-visit counting.

**T1 colordisc.** Witnesses: mean RGB of 4 sub-spans (left-top, left-bottom,
right-top, right-bottom). SUSTAIN events per half (mean ± spread interval).
RELATION event from distance interval [d_lo,d_hi] of the two half-pairs:
REL_DIFF if d_lo > 40; REL_SAME if d_hi ≤ 40; else ambiguous with alternatives.
sup = 1000·|d_mid−40|/(|d_mid−40|+60); con = 1000 if the two half-pair
distances straddle 40 (scaled by straddle width). Corroboration: top and
bottom pairs yield the same predicate. Contradiction → deliberation re-check:
recompute means excluding outlier rows (distractor-blob rows), then decide.

**T2 colorconst.** Same lattice shape; witnesses are per-quarter von Kries
normalized means (mean_c·1000/max_c per channel, integer, same as A) with
per-quarter white-patch maxima; threshold 150; predicate REL_SAME →
judgment SAME_SURFACE, REL_DIFF → DIFFERENT. Same corroboration / re-check
(re-check: alternate white-patch = 95th-percentile instead of max).

**T3 shapetrans.** Witness w1: fill-ratio area/(πR²) per-mille from
checkerboard-even pixels; w2: same from checkerboard-odd pixels (two
non-overlapping spans of the same region); w3: radial profile — 16 rays from
centroid, exit-radius interval (max−min)/mean per-mille. Class event from
fill-ratio interval midpoint vs prototypes (circle 1000, square 637, triangle
414): nearest wins; sup from margin to nearest other prototype; alternatives
= other two classes with support. con > 0 if w1/w2 classes disagree or radial
class ≠ fill class. Re-check: exclude rows 30–44 (occlusion band) and
recompute; fallback adaptive brightness threshold. Corroboration: w1 and w2
agree on class.

**T4 pitchdisc.** ONSET events from block-energy envelope (320-sample blocks,
10% of max): expect exactly 2 tone spans (A, B) + gap; con if span count ≠ 2.
Per span: f0 interval via coarse autocorrelation on stride-8 subsample, lags
covering 100–800 Hz, quantized to 2% bins. Relation: F0_HIGHER if
A_hi < B_lo; F0_LOWER if B_hi < A_lo; F0_SAME on overlap; sup from gap/overlap
magnitude. Corroboration: first-half vs second-half of each span in the same
bin. Re-check on contradiction: fine harmonic refinement (A-style,
±3% grid, 0.1% steps, octave guard) on the conflicted span only.

**T5 timbredisc.** Two non-overlapping spans (first/second half). Per span:
coarse f0 (stride-8 autocorr), harmonic energies k=1..6 via fixed-point
sine-table projection, centroid r = 1000·ΣkE/ΣE; class per span via frozen
thresholds PURE<1075<DARK<1400<RICH<3000<BRIGHT. Class event: spans agree →
corroborated, high sup. Spans disagree → con → re-check: fundamental-locked
refined centroid with octave guard on full span. Alternatives = runner-up
classes.

**T6 motiondir.** 7 frame-pair spans. Per span: changed-pixel count (summed
channel diff > 90) + centroid displacement (dx,dy) → MOTION event with octant
interval (or DIR_STILL if |disp| < 1px and change < 5%). Direction event:
majority octant over spans; sup = 1000·agree/7; con = 1000·disagree/7.
Flicker check: ≥4 spans with change > 30% of pixels but |disp| < 1px →
contradiction (global flicker, not translation) → re-check with diff
threshold ×3 requiring coherent displacement; if still incoherent → STILL.
Two-opposite-motions → con → re-check per half-frame (left/right halves
separately); judgment = majority of coherent spans, alternatives listed.
Corroboration: ≥2 spans agree on the winning octant.

**Judgment mapping (frozen):** colordisc REL_DIFF→DIFFERENT, REL_SAME→SAME;
colorconst REL_DIFF→DIFFERENT, REL_SAME→SAME_SURFACE; shapetrans
SHAPE_*→CIRCLE/TRIANGLE/SQUARE; pitchdisc F0_*→HIGHER/LOWER/SAME; timbredisc
TIMBRE_*→PURE/BRIGHT/DARK/RICH; motiondir DIR_*→octant/STILL.

**Confidence (frozen):** base = 1000·sup/(sup+con+200); INSTALL → base;
PROVISIONAL → base·6/10; WITHHELD → base·3/10; clamp 0..1000.

**Support thresholds T_mod (frozen):** colordisc 300, colorconst 300,
shapetrans 250, pitchdisc 300, timbredisc 300, motiondir 200 (of 1000).

## 6. Memory contract (executable; frozen rules)

Per decision-relevant top event, in order:

1. **Warrant check.** Witness spans must lie inside the fixture bounds
   (addressable) AND sup ≥ T_mod. Fail → step 3 (WITHHELD).
2. **Contradiction search.** If con > 0, scan installed memories of the same
   task for incompatible judgments whose stored invariant still verifies;
   each hit creates a conflict edge (event id ↔ memory id).
3. **WITHHOLD.** sup < T_mod or con > 0 ⇒ the event CANNOT install. It enters
   the bounded provisional buffer (capacity 16, FIFO eviction) marked
   WITHHELD. It may never become permanent from this state.
4. **Deliberation on conflict.** sup ≥ T_mod but a conflict edge exists ⇒
   deliberation MUST either (a) run the deterministic span re-check (§5) and
   adopt its result, or (b) choose the robust action: the alternative
   maximizing (support − contradiction) over surviving alternatives. The
   judgment emitted is the deliberated one.
5. **Install.** An event installs as a permanent memory ONLY with
   corroboration: two non-overlapping source spans (sub-spans of one fixture,
   or spans from different fixtures in the stream) or two modalities
   producing the same normalized event structure (same predicate, attr
   intervals overlapping). Installed record: event + witness refs +
   contradiction tests (the con>0 conditions re-checkable later). Without
   corroboration a clean event stays PROVISIONAL in the buffer (may install
   later when a later span corroborates it).
6. **Retrieval gating.** When a new percept's normalized structure matches an
   installed memory's stored structure, the memory is retrieved
   (`retrieved=<id>` printed) and may raise confidence. A partial match may
   influence deliberation (tie-break toward the remembered alternative) but
   can never trigger an irreversible action alone.

**Ablated gate (B4):** `--ablate` mode runs IDENTICAL event extraction but the
gate installs every top event's judgment unconditionally (no warrant check, no
contradiction search, no corroboration requirement, no provisional buffer).
Everything else (judgment derivation) is unchanged, isolating the contract's
effect on install/withhold decisions.

## 7. CLI (frozen)

```text
h1 <task> <fixture> [--stream=ID] [--ablate]
h1 reset --stream=ID
```

- Stateless (`h1 <task> <fixture>`): harness protocol. stdout `key=value`
  lines: `approach=H1`, `task=`, `judgment=` (frozen §5 mapping, always in the
  harness VOCAB), `confidence=0..1000` (frozen formula), `ops=` (frozen
  definition), `nev=` (event records incl. alternatives), `bytes=` (event
  record bytes), `disp=` (contract disposition vs an EMPTY memory with
  within-fixture corroboration only — deterministic per input), then `ev …`
  lines (§4). Exit 0; on bad input `error=<reason>` + exit 1.
  Stateless mode exists so the frozen harness protocol (incl. its 3×
  byte-identical determinism check, which calls without `--stream`) works
  unchanged.
- Stream mode (`--stream=ID`): additionally reads/updates the persistent
  store `h1_mem_<ID>/` in the working directory (installed memories,
  provisional buffer, conflict edges), appends a hash-chained ledger entry
  (SHA-256 over `seq|stream|fixture|judgment|disp|event_ids|prev_hash`),
  prints `ledger=<64 hex>`. `reset` clears the store. Stream order is fixed
  (sorted fixture paths) and the store is reset before every measured run,
  so stream runs are deterministic.
- Memory budget: identical for A and H1 in the B2 comparison — the harness's
  shared deliberate-memory rule (`score.py::apply_memory_rule`, one code
  path) is applied to both approaches' (judgment, confidence) streams per
  task; H1's internal contract store is ADDITIONAL and reported separately
  (B4/B5).

## 8. Bars (all preregistered, applied mechanically)

- **B1 viability:** mean primary-fixture accuracy (6 tasks, equal weights) ≥ 60%.
- **B2 head-to-head:** A vs H1 on the IDENTICAL 1165-fixture benchmark.
  Kill-relevant: decision accuracy on the adversarial/misleading set
  (judgment == truth; both approaches under the harness shared memory rule)
  must be ≥ A_baseline + 10pp. Raw accuracies also reported.
- **B3 efficiency:** median per-fixture ops(H1)/ops(A) over the benchmark
  (kill: median > 35% of A ⇒ death); mean ratio and bytes-per-percept
  (H1 event bytes vs A fixture bytes) reported.
- **B4 contract proof (LOAD-BEARING):** stream the adversarial fixtures per
  task (sorted, store reset) through the contract gate and through `--ablate`.
  PASS iff the contract changes the install/withhold disposition on ≥10% of
  adversarial fixtures AND the contract's false-install count is strictly
  lower than the ablated run's. Otherwise the contract is decoration ⇒ FAIL.
- **B5 KB4:** adversarial-stream false-install rate = false INSTALLs /
  INSTALLs ≤ 10% (skeleton bar); the hypothesis kill bar is stricter
  (>5% ⇒ death) — both reported, the 5% rule governs.
- **B6 determinism:** ≥3 full benchmark runs, per-fixture stdout
  byte-identical across runs; ledger hash chain independently re-verified
  (Python recomputation from the ledger file).
- **B7 beauty:** (i) mechanism elegance vs the hypothesis's beauty claim;
  (ii) artifacts for Micah: event-lattice overlay renders (PNG) on
  representative fixtures + native witness-span audio excerpts (bit-exact
  source spans) with the brief attached. Human verdicts (double-blind audio
  90% agreement; visual realism 80% raters) are Micah's call — reported as
  PENDING-HUMAN, never silently passed.

## 9. Kill criteria

The hypothesis's own kill bar from HYPOTHESES.md, applied verbatim:

> On a preregistered adversarial audio-visual benchmark containing at least
> 10,000 percepts and at least 30% deliberately misleading high-confidence
> inputs, H1 dies if any of these conditions holds:
> - permanent false-install rate exceeds **5%**;
> - correct-install recall is below **85%**;
> - decision accuracy is not at least **10 percentage points higher** than
>   the frozen Approach A baseline under the same memory budget;
> - median percept compute exceeds **35%** of Approach A;
> - native audio replay fails a human double-blind field-recording
>   equivalence test at **90%** agreement, or visual reconstruction/imagery
>   is judged realistic by fewer than **80%** of raters.

PLUS: fork dies if B4 fails (contract is decoration) or B6 fails
(non-determinism).

Definitions for mechanical application: "permanent false-install rate" =
false INSTALLs / INSTALLs in the adversarial stream test (§7); "correct-install
recall" = installed-and-correct / all correct-judgment fixtures in that
stream; "decision accuracy" = judgment==truth rate on the adversarial set
under the shared memory rule; "median percept compute" = median per-fixture
ops ratio H1/A. The two human-test clauses are evaluated only by Micah's
verdict on the B7 artifacts; until he rules they are PENDING, not passed.
