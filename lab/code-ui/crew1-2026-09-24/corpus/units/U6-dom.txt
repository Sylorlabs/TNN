# U6 — DOM APIs (manual excerpt; source: handbook/dom-manipulation.html)

## The core pattern
- const app = document.getElementById("app");  // type: HTMLElement | null
- getElementById CAN return null — the element might not exist.
- const p = document.createElement("p");       // type: HTMLParagraphElement
  (generic inference: createElement<K extends keyof HTMLElementTagNameMap>(tagName: K)
  returns the specific element interface for known tags)
- p.textContent = "Hello, World!";
- app?.appendChild(p);  // optional chaining because app may be null

## Null discipline (strict)
- Direct use errors: app.appendChild(p) // TS18048: 'app' is possibly 'null'.
- Legal options: optional chaining (app?.appendChild(p)), an if-guard
  (if (app) { app.appendChild(p); }), or the non-null assertion (app!.appendChild(p))
  when you KNOW the element exists (e.g. your own HTML guarantees the id).

## querySelector / querySelectorAll
- document.querySelector("li")              // Element | null (first match)
- document.querySelectorAll("li")           // NodeListOf<HTMLLIElement>
- NodeListOf supports: length, item(i), forEach, numeric indexing.
- forEach gives contextual typing: items.forEach((li) => li.textContent = "...")

## Interfaces chain
- HTMLElement extends Element extends Node.
- appendChild<T extends Node>(newChild: T): T — defined on Node.

## Useful element properties
- textContent: string | null — settable text.
- className, id: string; style: CSSStyleDeclaration.
- addEventListener("click", (e) => { ... }) — e is contextually typed (MouseEvent).

## Common errors
- TS18048 'x' is possibly 'null' on getElementById/querySelector results.
- TS2339 property does not exist on 'Element' — narrow to the specific element
  type first (e.g. querySelector("input") is Element; use <HTMLInputElement> or
  querySelector<HTMLInputElement>("input") for .value).
