# U1 — BASIC TYPES (manual excerpt; source: https://www.typescriptlang.org/docs/handbook/2/everyday-types.html)
# Consulted on demand during TEACHING only. Never consulted during B1 testing.

## Primitives
- string, number, boolean (lowercase). NEVER String/Number/Boolean for types.
- number covers all numerics; there is no int/float.
- let myName: string = "Alice";   // annotation AFTER the name
- Inference: let myName = "Alice"; // inferred string, no annotation needed

## Arrays
- number[] or Array<number>. [number] is a TUPLE, not an array.

## any
- any disables type checking. Useful sparingly.
- noImplicitAny (part of --strict): implicit any is an ERROR.

## Union types
- number | string = value may be either.
- You may only use operations valid for EVERY member of the union.
- Narrow with code: if (typeof id === "string") { id.toUpperCase() } else { ... }
- Array.isArray(x) narrows string[] | string.

## Optional properties + strictNullChecks
- { first: string; last?: string } — last may be missing.
- Reading an optional property under strictNullChecks gives T | undefined.
- Must check: if (obj.last !== undefined) { ... } or obj.last?.toUpperCase()
- TS18048: "'obj.last' is possibly 'undefined'" — the compiler stops unsafe reads.

## Literal narrowing via ??
- const x = opts.xPos ?? 0; // default when undefined/null
