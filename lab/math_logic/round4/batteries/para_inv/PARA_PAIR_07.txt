# PARA_PAIR_07

Base problem: CHAIN_NL_11
Kind: paraphrase

S1. Every inhabitant of the island is a knight, who never lies, or a knave, who never tells the truth.
S2. A's statement is that B is a knave.
S3. B's statement is that A and B share a type.
S4. C's statement is that A is a knight.
S5. D's statement is that C is a knave.
S6. Work out the type of each person.

TARGET: A is a knight, B is a knave, C is a knight, and D is a knave.
