ID: LH-REC
K: record field pipe separator text line
I: A record is one line of text. Fields are separated by the | character. Field 1 is before the first |. Fields never contain |.
L: split on | to get fields; count fields; join with | to make records.

ID: LH-CMP
K: compare integer number parse greater less equal
I: Text that looks like an integer (optional minus, then digits) parses to an integer. Compare integers with greater-than, less-than, equal.
L: parse digits left to right; minus means negative.

ID: LH-CAP|FIELD
K: field transform change modify rewrite
OPS: upper | clamp | mul_fields | sub_fields | firstchar_plus | substr | format
K: upper: uppercase capital letters big text
K: clamp: clamp limit bound range between minimum maximum at
K: mul_fields: multiply times by
K: sub_fields: subtract difference minus less
K: firstchar_plus: first character initial letter prefix code suffix
K: substr: substring slice extract part portion from length
K: format: format template produce line layout arrange

ID: LH-CAP|FILTER
K: filter select keep remove drop where
OPS: field_count_eq | int_gt | int_ge | int_lt | int_lt_field | in_set
K: field_count_eq: exactly count number fields has
K: int_gt: greater than above more exceeds
K: int_ge: at least or more minimum
K: int_lt: less than below under fewer
K: int_lt_field: less than below under fewer compare field
K: in_set: one of among set list allowed

ID: LH-CAP|AGG
K: aggregate group summarize total combine
OPS: sum | count
K: sum: sum add accumulate per group by
K: count: count how many number of per group by

ID: LH-CAP|SORT
K: sort order arrange rank top
OPS: sort
K: sort: sort order by ascending descending top largest smallest rank
