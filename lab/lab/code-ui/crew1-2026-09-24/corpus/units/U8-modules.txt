# U8 — MODULES (manual excerpt; source: handbook/2/modules.html)

## What makes a module
- Any file with a top-level import or export is a MODULE (own scope).
- A file with neither is a SCRIPT (global scope).
- export {}; — turns a file into a module exporting nothing.

## ES module syntax (use this)
- export default function helloWorld() { console.log("Hello, world!"); }
- import helloWorld from "./hello.js";
- export const pi = 3.14; export function absolute(num: number) { ... }
- import { pi, phi, absolute } from "./maths.js";
- import { pi as p } from "./maths.js";            // rename
- import * as math from "./maths.js";             // namespace
- import "./maths.js";                            // side effects only
- export type Cat = { breed: string; yearOfBirth: number };
- import type { Cat, Dog } from "./animal.js";    // type-only import

## Rules
- Declarations in a module are INVISIBLE outside unless exported.
- To use something from another module you MUST import it.
- Import paths: relative "./maths.js" for your own files.
- Under --module nodenext/bundler the import specifier keeps the .js extension
  even though the source file is .ts (TS maps it).
- Mixing default + named: import RNG, { pi as p } from "./maths.js";

## Type-only imports
- import type { Cat } from "./animal.js"; — erased at compile, safe for
  transpilers; using an import-type'd VALUE as a value is TS1361.

## Common errors
- TS2306 './x' is not a module (no exports in target).
- TS2305 Module has no exported member 'y'.
- TS2459/TS1205 with re-export mistakes.
- Forgetting export: "Cannot find name" in the importing file.
